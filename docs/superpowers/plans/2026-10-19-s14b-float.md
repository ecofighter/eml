# S14b `Float` and `Num` / `Div` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an IEEE 754 `Float` type with literals, Python-style display, `Std.Float`, a raw `float` Repr boxed at `tobj`, and dedicated VM ops, and turn the Prelude's Int arithmetic into the classes `Num` and `Div` with `Int` and `Float` instances.

**Architecture:** `Float` mirrors `Int` end to end:
- an extern type row;
- a raw 64-bit Repr in `BOXED_SCALARS`;
- an `eml_rt` box object kind (`box` always allocates);
- a constant pool keyed by bits;
- dedicated arithmetic and comparison ops.

Arithmetic moves from Prelude extern functions to `extern` methods of `instance Num Int` / `instance Div Int`. Monomorphization still resolves every use to the same extern rows, so the VM keeps its dedicated ops and `RunStats` stay the same.

**Tech Stack:** Rust (`eml_extern`, `eml_syntax`, `eml_hir`, `eml_types`, `eml_core_ir`, `eml_lir`, `eml_vm`, `eml_rt` with Verus), insta, `eml_test_support`, the UI and REPL harnesses, `python3` (3.14, for reference outputs only).

**Spec:** `docs/superpowers/specs/2026-10-19-s14b-float-design.md`. The S14 design `docs/superpowers/specs/2026-10-19-s14-numeric-design.md` still applies.

## Global Constraints

- Code comments and docs are Japanese, written with the `yomiyasu:yomiyasu` skill. Comments explain why and cite `docs/` paths. CLAUDE.md stays English.
- Prelude classes, exactly:
  - `pub class Num a where (+) : a -> a -> <Panic> a; (-) : a -> a -> <Panic> a; (*) : a -> a -> <Panic> a; negate : a -> <Panic> a`
  - `pub class Div a where (/) : a -> a -> <Panic> a; (%) : a -> a -> <Panic> a`
  - Neither class has a superclass. The fixities stay as they are (`infixl 6 +, -`, `infixl 7 *, /, %`).
- Row names:
  - `Prelude.Num Int.+`, `.-`, `.*`, `.negate`; `Prelude.Div Int./`, `.%` (Purity `Panics`)
  - `Prelude.Num Float.+`, `.-`, `.*`, `.negate`; `Prelude.Div Float./`, `.%`; `Prelude.Eq Float.==`, `.!=`; `Prelude.Ord Float.compare`, `.<`, `.<=`, `.>`, `.>=`; `Prelude.Show Float.show` (Purity `Pure`)
  - the Prelude-private `Prelude.shows_minus : Float -> Bool` (`Pure`; true iff `show x` starts with `-`)
- `Float` semantics:
  - IEEE 754 binary64.
  - `/` by zero gives `inf` / `-inf` / `nan`.
  - `%` is Rust's `f64 % f64` (C `fmod`, sign of the dividend).
  - The comparison operators are IEEE. `compare` is `f64::total_cmp`.
  - Derived and tuple `Ord` instances keep generating only `compare`.
- `Show Float` is Python `repr`:
  - Take the shortest round-trip digits. Use fixed notation when the decimal exponent `e` satisfies `-4 <= e < 16`, with `.0` on integral values. Otherwise use `d[.ddd]e±XX`, with at least two exponent digits.
  - Specials are `inf`, `-inf`, `nan` (never `-nan`), and `-0.0`.
  - `show_prec d x = if d > 6 && shows_minus x then "(" ++ show x ++ ")" else show x`.
- `std/Float.em` (`Std.Float`), exactly these public items:
  - `of_int : Int -> Float`
  - `truncate`, `floor`, `ceil`, `round : Float -> <Panic> Int` (`round` is `f64::round_ties_even`)
  - `sqrt`, `abs`, `sin`, `cos`, `exp`, `log : Float -> Float`
  - `pow : Float -> Float -> Float`
  - `pi : Float = 3.141592653589793`, `infinity : Float`, `nan : Float`
  - `is_nan : Float -> Bool`
  - `to_fixed : Int -> Float -> <Panic> String`
  - `parse : String -> Option Float`
- Panic texts, exact:
  - ``"float `{repr}` does not fit in `Int`"``, where `{repr}` is the Python repr. This comes from `truncate` / `floor` / `ceil` / `round` on NaN, ±inf, or a result outside `[-2^63, 2^63)`.
  - ``"`to_fixed` takes 0 to 100 digits, not {n}"``.
  - Both are `Fault::Arith` variants, so `Fault::panics()` holds.
- `to_fixed n x` equals Python `f"{x:.{n}f}"` (correctly rounded; `inf`, `-inf`, `nan`).
- `parse` trims leading and trailing Unicode whitespace, then accepts what Rust's `f64::from_str` accepts. That covers an optional sign, decimal or exponent forms, and `inf` / `infinity` / `nan` in any case. Underscores are rejected. Anything else gives `None`.
- Float literal pattern error, exact text: ``"floating-point literals cannot be patterns; compare with `==` instead"``. It uses a new `eml_hir` code, the next free one.
- IR text form for float constants: Rust `{:?}` of the f64 (`1.5`, `1e16`, `-0.0`, `inf`, `-inf`, `NaN`). A float constant is told apart from a variable name by containing no `.` followed by a digit-only suffix, or by being one of `inf` / `-inf` / `NaN`. Settle the exact lexing in Task 2 so that `x.0` stays a variable.
- Test changes:

  - Kind 2: renamed extern rows in IR text and dumps, the regenerated `expected.txt`, the unused-`(+)` tests becoming E2009-free (give them a type), and relaxing `faulting_rows_carry_panic` (Task 3).
  - A changed stdout or stderr of an existing UI `run` test, or a changed bench `RunStats`, is a bug: stop and report.
- `eml_rt` changes pass `cargo verus verify -p eml_rt`, `verusfmt --verus-only --check $(git ls-files 'crates/eml_rt/src/*.rs')`, and the Miri trusted tests (CLAUDE.md commands).
