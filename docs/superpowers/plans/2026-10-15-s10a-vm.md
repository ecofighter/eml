# S10a VM の本体 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** LIR をレジスタ型のバイトコード (`CodeBase`) に変換し、`eml_rt` の `Ctx` の上で実行する VM を新しい crate `eml_vm` に作り、すべての `run` と `run-fail` の UI テストが CEK と同じ結果になることを確かめる。既定の `eml run` は CEK のままにする。

**Architecture:** コード生成 (`compile`) は関数ごとに、文の単位の生存から干渉グラフを作ってスロットを塗り、8 バイトの `Op` の列と、長さの変わるオペランドの表 (`operands`) を出す。定数は作業用のヒープに不死の物体として作って凍結し、実行のヒープに付ける。VM (`run`) はタスクの `Vec<Word>` の上のレジスタ窓で動く1つの `match` のループで、`M: Mode` について総称にし、ヒープと基本操作と extern は `Ctx<M>` を呼ぶ。

**Tech Stack:** Rust (edition 2024)、`eml_rt` (Verus で検証した実行時の核)、insta (インラインスナップショット)、Miri (nightly、`nix develop .#miri`)。

**Spec:** `docs/superpowers/specs/2026-10-15-s10a-vm-design.md`

## Global Constraints

- `eml_vm` の `[dependencies]` は `eml_extern`、`eml_lir`、`eml_rt` だけにする。`eml_interp` と `eml_runtime` には依存しない。この2つの crate は S10a の間変えない
- 既存のテストの期待値 (スナップショット、`crates/eml_interp/tests/bench.rs`) は変えない。足すだけにする
- `Op` の大きさは 8 バイトで、`const _: () = assert!(std::mem::size_of::<Op>() == 8);` で固定する
- スロットは `u16`、命令の位置 (`Pc`) と表の添字は `u32` である。スロットが `u16` に収まらない関数は `CompileError::TooManySlots`
- 生の `int` と `enum` の値はスロットに `Word::from_bits` で置き、`bits()` で読む。RC の命令と即値の判定は、Repr が `obj` か `tobj` の値にだけ使う
- 誤りの表示は CEK と同じ形にする: 位置があれば `{fault}\n  at {path}:{line}:{column}`、なければ ``{fault} in `{function}` ``、リークは `memory leak: objects were not freed: {n} {name}, …`、内部の誤りは `internal error: {what}`
- 実行のテストは、検査モード (`debug_heap`) で走らせる。速いモードは、検査モードの実行が期待どおりだったときだけ走らせる
- `eml_rt` を変えるタスクでは、`find target -path '*/.fingerprint/eml_rt-*' -prune -exec rm -rf {} +` の後に `cargo verus verify -p eml_rt` (0 errors) と `verusfmt --verus-only --check $(git ls-files 'crates/eml_rt/src/*.rs')` を通す

## Review Focus

- 生の `enum` の値 2 (偶数なのでポインタの形をしている) と 1 (即値の形をしている) が、`switch`、`drop`、ブロックの引数を通ること。語の形で分けると、2 で未定義の動作になり、1 で `#0` の行き先へ進む (Task 4 の `an_enum_tag_two_is_not_read_as_a_pointer`)

```rust
/// コンストラクタのフィールドの物理的な形 (docs/spec/object-model.md の「ペイロード」)。走査する語 (`obj` と `tobj`)
/// を宣言の順に並べ、その後に残りを宣言の順に並べる。VM と後の reuse analysis が同じ規則を使うように、規則はここに
/// 1つだけ置く。走査する語が 255 個以上のときにペイロードの先頭に置く数の語は `eml_rt` の形なので、ここでは数えない。
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Shape {
    /// 宣言の位置ごとの、ペイロードの中の位置。
    pub positions: Vec<u32>,
    pub scanned: u32,
    pub raw: u32,
}

impl LayoutCtor {
    pub fn shape(&self) -> Shape {
        let scanned = self.fields.iter().filter(|repr| repr.is_rc()).count() as u32;
        let (mut next_scanned, mut next_raw) = (0, scanned);
        let positions = self
            .fields
            .iter()
            .map(|repr| {
                let next = if repr.is_rc() {
                    &mut next_scanned
                } else {
                    &mut next_raw
                };
                let position = *next;
                *next += 1;
                position
            })
            .collect();
        Shape {
            positions,
            scanned,
            raw: self.fields.len() as u32 - scanned,
        }
    }
}
```

```rust
use std::sync::Arc;

use eml_lir::Program;
use eml_rt::{Control, Fast, Limits};
use eml_test_support::execute_vm;
use eml_vm::{VmError, compile, disassemble};

pub fn parse(text: &str) -> Program {
    eml_lir::parse(text).unwrap_or_else(|error| panic!("{error}"))
}

fn verified(text: &str) -> Program {
    let program = parse(text);
    eml_lir::verify(&program).unwrap_or_else(|error| panic!("{error}"));
    program
}

/// 手書きの LIR を verifier に通し、検査モードで実行する。通ったときは速いモードでも実行し、出力が同じことを確かめる。
/// 速いモードは前提を確かめないので、検査モードが通らなかった IR では走らせない (docs/spec/vm.md の「検証とテスト」)。
pub fn run_lir(text: &str) -> (String, Result<(), VmError>) {
    let program = verified(text);
    let (out, result) = execute_vm(&program, true);
    if result.is_ok() {
        let (fast_out, fast) = execute_vm(&program, false);
        assert_eq!(fast.map(|_| ()), Ok(()), "the fast mode failed");
        assert_eq!(fast_out, out, "the fast mode printed something else");
    }
    (out, result.map(|_| ()))
}

/// verifier を通さずに、検査モードだけで実行する。verifier が拒む IR で、VM 自身の見張りを確かめるテストのためである。
pub fn run_unverified(text: &str) -> (String, Result<(), VmError>) {
    let (out, result) = execute_vm(&parse(text), true);
    (out, result.map(|_| ()))
}

/// verifier を通した LIR の逆アセンブル。
pub fn disasm(text: &str) -> String {
    disasm_unverified_program(&verified(text))
}
```

```rust
//! 実行するコードの表 `CodeBase` と関数表 `FnEntry` (docs/spec/vm.md の「`CodeBase` と `FnEntry`」)。

use std::sync::Arc;

use eml_lir::Loc;
use eml_rt::{Frozen, HeapError, Mode, Word};

use crate::error::{SourceLocation, VmError};
use crate::op::{BUILTINS, Op, Pc};
use crate::vm::{Failure, Task};

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct FnEntry {
    pub name: String,
    /// 命令列の範囲 `[start, end)`。
    pub start: Pc,
    pub end: Pc,
    pub arity: u16,
    pub frame_size: u16,
}

/// 実行中は読むだけの表。後の並列 VM の worker がそのまま共有できるように、`Sync` に保つ
/// (docs/future/multicore.md の「VM の並列化の備え」の制約2)。
pub struct CodeBase<M: Mode> {
    pub(crate) functions: Vec<FnEntry>,
    pub(crate) code: Vec<Op>,
    pub(crate) operands: Vec<u32>,
    pub(crate) effect_lists: Vec<u16>,
    pub(crate) constants: Vec<Word>,
    pub(crate) region: Arc<Frozen<M>>,
    /// 命令の位置の昇順。
    pub(crate) locations: Vec<(Pc, Loc)>,
    pub(crate) files: Vec<String>,
    pub(crate) entry: u32,
    /// 入口の関数の結果を `Finish` で手放すか。`ret` が RC の Repr のときである。
    pub(crate) entry_ret_rc: bool,
}

#[derive(Debug, PartialEq, Eq)]
pub enum CompileError {
    /// 同時に要るスロットが `u16` に収まらない関数。
    TooManySlots { function: String },
    /// 定数を凍結できなかった。
    Freeze(HeapError),
}

impl<M: Mode> CodeBase<M> {
    pub fn functions(&self) -> &[FnEntry] {
        &self.functions
    }

    /// 命令の位置を含む関数。組み込みの命令はどの関数にも属さない。関数は命令の位置の順に並ぶ。
    pub(crate) fn function_at(&self, pc: Pc) -> Option<&FnEntry> {
        if pc < BUILTINS {
            return None;
        }
        let after = self.functions.partition_point(|f| f.start <= pc);
        self.functions.get(after.checked_sub(1)?)
    }

    pub(crate) fn location(&self, pc: Pc) -> Option<Loc> {
        let index = self.locations.binary_search_by_key(&pc, |&(at, _)| at).ok()?;
        Some(self.locations[index].1)
    }

    /// 誤りに関数の名前と位置を付ける。組み込みの命令で起きた誤りには、最後に戻った関数の名前を付ける
    /// (docs/spec/vm.md の「誤り、止めること、終わり」)。
    pub(crate) fn error(&self, Failure { fault, pc }: Failure, task: &Task) -> VmError {
        let function = self
            .function_at(pc)
            .or_else(|| self.function_at(task.last_ret))
            .unwrap_or(&self.functions[self.entry as usize])
            .name
            .clone();
        let at = self.location(pc).map(|loc| SourceLocation {
            path: self.files[loc.file as usize].clone(),
            line: loc.line,
            column: loc.column,
        });
        VmError::Fault {
            fault,
            function,
            at,
        }
    }
}
```

```rust
//! LIR から `CodeBase` を作る (docs/spec/vm.md)。

mod constants;
mod emit;
mod slots;

use std::sync::Arc;

use eml_lir::{Loc, Program};
use eml_rt::{Control, Mode};

use crate::code::{CodeBase, CompileError};
use crate::op::{Op, Pc};
use constants::Constants;

/// 命令とオペランドを書く先。関数をまたいで1つにする。
#[derive(Default)]
pub(crate) struct Out {
    pub(crate) code: Vec<Op>,
    pub(crate) operands: Vec<u32>,
    pub(crate) effect_lists: Vec<u16>,
    pub(crate) locations: Vec<(Pc, Loc)>,
}

impl Out {
    pub(crate) fn pc(&self) -> Pc {
        Pc::try_from(self.code.len()).expect("the code fits in u32 positions")
    }

    pub(crate) fn push(&mut self, op: Op) -> Pc {
        let pc = self.pc();
        self.code.push(op);
        pc
    }

    /// オペランドの並びを足し、その先頭の添字を返す。
    pub(crate) fn operands(&mut self, items: impl IntoIterator<Item = u32>) -> u32 {
        let at = u32::try_from(self.operands.len()).expect("the operands fit in u32 positions");
        self.operands.extend(items);
        at
    }
}

/// プログラム全体を一度に変換する。呼び出しは関数の番号で指し、VM が `FnEntry` から先頭を引くので、関数の先頭の位置が
/// 決まる前に呼び出しを書ける。
pub fn compile<M: Mode>(
    program: &Program,
    control: Arc<Control>,
) -> Result<CodeBase<M>, CompileError> {
    let mut constants = Constants::<M>::new(control);
    let strings: Vec<u32> = program
        .strings
        .iter()
        .map(|text| constants.string(text))
        .collect();
    let mut out = Out::default();
    out.push(Op::Finish);
    out.push(Op::ApplyRest);
    let mut functions = Vec::with_capacity(program.functions.len());
    for function in &program.functions {
        functions.push(emit::function(
            program,
            function,
            &strings,
            &mut constants,
            &mut out,
        )?);
    }
    let (region, constants) = constants.freeze()?;
    Ok(CodeBase {
        functions,
        code: out.code,
        operands: out.operands,
        effect_lists: out.effect_lists,
        constants,
        region,
        locations: out.locations,
        files: program.files.clone(),
        entry: program.entry.0,
        entry_ret_rc: program.function(program.entry).ret.is_rc(),
    })
}
```

```rust
        }

                w

        };
        self.push(w)
    }

        let region = self.heap.freeze().map_err(CompileError::Freeze)?;
```

```rust
//! スロットの割り当て (docs/spec/vm.md の「スロットの割り当て」)。入口の引数をスロット 0.. に固定する。

use eml_lir::LirFn;

use crate::code::CompileError;
use crate::op::Slot;

pub(crate) struct Slots {
    /// 変数の番号ごとのスロット。
    pub(crate) of: Vec<Slot>,
    /// 変数が使うスロットの数。一時のスロットはこの後に置く。
    pub(crate) colors: u16,
}

/// 入口の引数をスロット 0.. に、ほかの変数をその後に1つずつ置く。
pub(crate) fn allocate(function: &LirFn) -> Result<Slots, CompileError> {
    let mut of: Vec<Option<usize>> = vec![None; function.vars.len()];
    let mut next = 0;
    for param in function.params() {
        of[param.0 as usize] = Some(next);
        next += 1;
    }
    for slot in &mut of {
        if slot.is_none() {
            *slot = Some(next);
            next += 1;
        }
    }
    let too_many = || CompileError::TooManySlots {
        function: function.name.clone(),
    };
    let of = of
        .into_iter()
        .map(|slot| Slot::try_from(slot.expect("every variable has a slot")).map_err(|_| too_many()))
        .collect::<Result<_, _>>()?;
    Ok(Slots {
        of,
        colors: u16::try_from(next).map_err(|_| too_many())?,
    })
}
```

```rust
use crate::code::{CompileError, FnEntry};
use crate::op::{Op, Pc, Slot};

pub(crate) fn function<M: Mode>(
    program: &Program,
    function: &LirFn,
    strings: &[u32],
    constants: &mut Constants<M>,
    out: &mut Out,
) -> Result<FnEntry, CompileError> {
    let slots = allocate(function)?;
    let start = out.pc();
    let mut emitter = Emitter {
        program,
        function,
        strings,
        constants,
        out,
        slots,
        temps: 0,
        max_temps: 0,
        block_pcs: vec![0; function.blocks.len()],
        goto_patches: Vec::new(),
        operand_patches: Vec::new(),
        used: used_vars(function),
    };
    for (index, block) in function.blocks.iter().enumerate() {
        emitter.block_pcs[index] = emitter.out.pc();
        emitter.block(BlockId(index as u32));
    }
    emitter.patch();
    let too_many = || CompileError::TooManySlots {
        function: function.name.clone(),
    };
    let frame_size = u16::try_from(usize::from(emitter.slots.colors) + usize::from(emitter.max_temps))
        .map_err(|_| too_many())?;
    Ok(FnEntry {
        name: function.name.clone(),
        start,
        end: emitter.out.pc(),
        arity: u16::try_from(function.params().len()).map_err(|_| too_many())?,
        frame_size,
    })
}

/// どこかで使う変数。SSA なので、使う変数は定義の後で生きていて、使わない変数の定義は死んでいる。死んでいるフィールドは
/// 読まず、死んでいる `drop` の結果は書かない。
fn used_vars(function: &LirFn) -> Vec<bool> {
    let mut used = vec![false; function.vars.len()];
    let mut mark = |atom: Atom| {
        if let Atom::Var(var) = atom {
            used[var.0 as usize] = true;
        }
    };
    for block in &function.blocks {
        for stmt in &block.stmts {
            match stmt {
                Stmt::Dup(var) | Stmt::Decref(var) => mark(Atom::Var(*var)),
                Stmt::Release { value, fields, .. } => {
                    mark(Atom::Var(*value));
                    fields.iter().flatten().for_each(|&var| mark(Atom::Var(var)));
                }
                _ => stmt.for_each_atom(&mut mark),
            }
        }
        block.term.for_each_atom(&mut mark);
    }
    used
}

pub(crate) struct Emitter<'a, M: Mode> {
    pub(crate) program: &'a Program,
    pub(crate) function: &'a LirFn,
    pub(crate) strings: &'a [u32],
    pub(crate) constants: &'a mut Constants<M>,
    pub(crate) out: &'a mut Out,
    pub(crate) slots: Slots,
    /// 今の命令が使った一時のスロットの数。命令ごとに 0 に戻す。
    pub(crate) temps: u16,
    pub(crate) max_temps: u16,
    pub(crate) block_pcs: Vec<Pc>,
    /// 行き先のブロックを後で書く `Goto` の位置。
    pub(crate) goto_patches: Vec<(Pc, BlockId)>,
    /// 行き先のブロックを後で書くオペランドの位置。
    pub(crate) operand_patches: Vec<(usize, BlockId)>,
    pub(crate) used: Vec<bool>,
}

impl<M: Mode> Emitter<'_, M> {
    pub(crate) fn slot(&self, var: VarId) -> Slot {
        self.slots.of[var.0 as usize]
    }

    pub(crate) fn repr(&self, var: VarId) -> Repr {
        self.function.repr(var)
    }

    /// 一時のスロットを1つ取る。変数のスロットの後に置き、命令ごとに使い回す。
    pub(crate) fn temp(&mut self) -> Slot {
        let slot = self.slots.colors + self.temps;
        self.temps += 1;
        self.max_temps = self.max_temps.max(self.temps);
        slot
    }

    /// 値をスロットに置く。変数はそのスロットで、定数は一時のスロットに読み込む。`repr` は値を受ける位置の Repr で、
    /// `#N` の書き方 (生の値か即値か) を決める。
    pub(crate) fn atom(&mut self, atom: Atom, repr: Repr) -> Slot {
        match atom {
            Atom::Var(var) => self.slot(var),
            constant => {
                let slot = self.temp();
                self.load(slot, constant, repr);
                slot
            }
        }
    }

    /// 定数を `dst` に書く命令を出す。`#N` は、`enum` の位置では生の値、`tobj` の位置では即値である。
    pub(crate) fn load(&mut self, dst: Slot, constant: Atom, repr: Repr) {
        let small = |n: u32| i32::try_from(n).expect("a tag or function index fits in i32");
        let op = match constant {
            Atom::Unit => Op::LoadImm { dst, value: 0 },
            Atom::Fn(f) => Op::LoadImm {
                dst,
                value: small(f.0),
            },
            Atom::Tag(n) if repr == Repr::TObj => Op::LoadImm {
                dst,
                value: small(n),
            },
            Atom::Tag(n) => Op::LoadRaw {
                dst,
                value: small(n),
            },
            Atom::Int(n) => match i32::try_from(n) {
                Ok(value) => Op::LoadRaw { dst, value },
                Err(_) => Op::LoadConst {
                    dst,
                    index: self.constants.raw(n),
                },
            },
            Atom::Var(_) => unreachable!("load takes a constant"),
        };
        self.out.push(op);
    }

    fn block(&mut self, id: BlockId) {
        let block = self.function.block(id);
        for stmt in &block.stmts {
            self.temps = 0;
            self.stmt(id, stmt);
        }
        self.temps = 0;
        self.term(id, &block.term);
    }

    fn stmt(&mut self, _block: BlockId, stmt: &Stmt) {
        match stmt {
            Stmt::Let { var, rhs } => self.rhs(*var, rhs),
            // Task 4 と Task 5 で足し、Task 6 でこの腕を消す
            other => panic!("the VM does not compile {other:?} yet"),
        }
    }

    fn rhs(&mut self, var: VarId, rhs: &Rhs) {
        let dst = self.slot(var);
        match rhs {
            Rhs::Call {
                call: Call::Direct(f, args),
                saved: _,
            } => {
                let at = self.call_operands(*f, args);
                self.out.push(Op::Call { dst, at });
            }
            Rhs::Extern { ext, args, at } => {
                let row = ext.row();
                let slots: Vec<Slot> = args
                    .iter()
                    .zip(row.params)
                    .map(|(&arg, &repr)| self.atom(arg, repr))
                    .collect();
                let op = arithmetic(*ext, dst, &slots).unwrap_or_else(|| {
                    let at = self.out.operands(
                        [*ext as u32, slots.len() as u32]
                            .into_iter()
                            .chain(slots.iter().map(|&s| u32::from(s))),
                    );
                    Op::Extern { dst, at }
                });
                let pc = self.out.push(op);
                if let Some(loc) = at {
                    self.out.locations.push((pc, *loc));
                }
            }
            Rhs::ConstString(index) => {
                let index = self.strings[*index as usize];
                self.out.push(Op::LoadConst { dst, index });
            }
            // Task 4 と Task 5 で足し、Task 6 でこの腕を消す
            other => panic!("the VM does not compile {other:?} yet"),
        }
    }

    /// 直接の呼び出しのオペランド [関数の番号, 引数の数, 引数のスロット…]。
    pub(crate) fn call_operands(&mut self, f: eml_lir::FnIdx, args: &[Atom]) -> u32 {
        let callee = self.program.function(f);
        let slots: Vec<Slot> = args
            .iter()
            .zip(callee.params())
            .map(|(&arg, &param)| self.atom(arg, callee.repr(param)))
            .collect();
        self.out.operands(
            [f.0, slots.len() as u32]
                .into_iter()
                .chain(slots.iter().map(|&s| u32::from(s))),
        )
    }

    fn term(&mut self, block: BlockId, term: &Term) {
        match term {
            Term::Return(atom) => {
                let src = self.atom(*atom, self.function.ret);
                self.out.push(Op::Ret { src });
            }
            Term::TailCall(Call::Direct(f, args)) => {
                let at = self.call_operands(*f, args);
                self.out.push(Op::TailCall { at });
            }
            Term::Jump { target, args } => self.jump(block, *target, args),
            // Task 4 と Task 5 で足し、Task 6 でこの腕を消す
            other => panic!("the VM does not compile {other:?} yet"),
        }
    }

    /// ブロック引数への代入と、行き先への `Goto`。次のブロックへ進むだけなら `Goto` を出さない。
    pub(crate) fn jump(&mut self, from: BlockId, target: BlockId, args: &[Atom]) {
        let params = &self.function.block(target).params;
        // 並べるだけの割り当てでは、行き先の引数のスロットと実引数のスロットが重ならないので、順に写してよい。
        // Task 3 の色塗りで重なるようになるので、並列な代入として直す
        for (&param, &arg) in params.iter().zip(args) {
            let dst = self.slot(param);
            match arg {
                Atom::Var(var) if self.slot(var) == dst => {}
                Atom::Var(var) => {
                    let src = self.slot(var);
                    self.out.push(Op::Move { dst, src });
                }
                constant => self.load(dst, constant, self.repr(param)),
            }
        }
        self.goto(from, target);
    }

    pub(crate) fn goto(&mut self, from: BlockId, target: BlockId) {
        if target.0 != from.0 + 1 {
            let pc = self.out.push(Op::Goto { target: 0 });
            self.goto_patches.push((pc, target));
        }
    }

    fn patch(&mut self) {
        for &(pc, block) in &self.goto_patches {
            self.out.code[pc as usize] = Op::Goto {
                target: self.block_pcs[block.0 as usize],
            };
        }
        for &(index, block) in &self.operand_patches {
            self.out.operands[index] = self.block_pcs[block.0 as usize];
        }
    }
}

/// 算術と比較の extern の専用の命令 (docs/spec/vm.md の「基本操作と extern」)。
fn arithmetic(ext: Extern, dst: Slot, args: &[Slot]) -> Option<Op> {
    if let (Extern::IntNeg, [a]) = (ext, args) {
        return Some(Op::IntNeg { dst, a: *a });
    }
    let [a, b] = *args else { return None };
    Some(match ext {
        Extern::IntAdd => Op::IntAdd { dst, a, b },
        Extern::IntSub => Op::IntSub { dst, a, b },
        Extern::IntMul => Op::IntMul { dst, a, b },
        Extern::IntDiv => Op::IntDiv { dst, a, b },
        Extern::IntMod => Op::IntRem { dst, a, b },
        Extern::IntEq => Op::IntEq { dst, a, b },
        Extern::IntNe => Op::IntNe { dst, a, b },
        Extern::IntLt => Op::IntLt { dst, a, b },
        Extern::IntLe => Op::IntLe { dst, a, b },
        Extern::IntGt => Op::IntGt { dst, a, b },
        Extern::IntGe => Op::IntGe { dst, a, b },
        Extern::IntCompare => Op::IntCompare { dst, a, b },
        Extern::BoolEq => Op::BoolEq { dst, a, b },
        Extern::BoolNe => Op::BoolNe { dst, a, b },
        _ => return None,
    })
}
```

`*ext as u32` は `Extern` の宣言の順の番号である。VM は `Extern::ALL[row]` で引く。`Extern::ALL` の順が宣言の順と同じでなければ、Task 2 の Step 6 で `crates/eml_vm/tests/run.rs` に `assert!(Extern::ALL.iter().enumerate().all(|(i, &e)| e as usize == i))` のテストを足して確かめ、違えば `Extern::ALL.iter().position(|&e| e == ext)` を使う。

```rust
//! 命令を実行するループ (docs/spec/vm.md)。状態は `Ctx` と `Task` だけに置き、安全点をまたいで外に持たない。呼び出しの
//! スタックを Rust の再帰でなく `Task` のデータに持つので、後の協調的なタスクの切り替えでタスクごとに取り替えられる
//! (docs/future/multicore.md の「VM の並列化の備え」の制約5)。

use eml_extern::Extern;
use eml_rt::{Ctx, Mode, Word, externs};

use crate::RunCounts;
use crate::code::CodeBase;
use crate::error::VmFault;
use crate::op::{FINISH, Op, Pc, Slot};

/// 1つのタスクの実行の状態。
pub struct Task {
    pub(crate) stack: Vec<Word>,
    pub(crate) pc: Pc,
    pub(crate) base: usize,
    pub(crate) frame_size: usize,
    /// 最後に戻った関数の `Ret` の位置。どの関数にも属さない組み込みの命令で起きた誤りに、その関数の名前を付ける。
    pub(crate) last_ret: Pc,
    /// 末尾の呼び出しと適用で、引数を今のフレームから新しいフレームへ移す間だけ置く所。
    pub(crate) scratch: Vec<Word>,
}

/// 誤りと、それが起きた命令の位置。
pub(crate) struct Failure {
    pub(crate) fault: VmFault,
    pub(crate) pc: Pc,
}

// いちばん下に置く空のフレーム。入口の関数の結果を受けるスロットを1つ持つ
const ROOT_BASE: usize = 2;
const ROOT_SIZE: usize = 1;

impl Task {
    pub(crate) fn new<M: Mode>(code: &CodeBase<M>) -> Task {
        let entry = &code.functions[code.entry as usize];
        let base = ROOT_BASE + ROOT_SIZE + 2;
        let mut stack = vec![Word::UNIT; base + usize::from(entry.frame_size)];
        stack[base - 2] = header(FINISH, 0, ROOT_SIZE);
        stack[base - 1] = Word::from_bits(ROOT_BASE);
        Task {
            stack,
            pc: entry.start,
            base,
            frame_size: usize::from(entry.frame_size),
            last_ret: FINISH,
            scratch: Vec::new(),
        }
    }

    pub(crate) fn get(&self, slot: Slot) -> Word {
        self.stack[self.base + usize::from(slot)]
    }

    pub(crate) fn set(&mut self, slot: Slot, w: Word) {
        let index = self.base + usize::from(slot);
        self.stack[index] = w;
    }

    pub(crate) fn raw(&self, slot: Slot) -> i64 {
        self.get(slot).bits() as i64
    }

    pub(crate) fn set_raw(&mut self, slot: Slot, n: i64) {
        self.set(slot, Word::from_bits(n as usize));
    }

    /// 使っている語の数。安全点の深さである (docs/spec/object-model.md の「実行の制御」)。
    pub(crate) fn depth(&self) -> usize {
        self.base + self.frame_size
    }

    pub(crate) fn reserve(&mut self, end: usize) {
        if self.stack.len() < end {
            self.stack.resize(end, Word::UNIT);
        }
    }

    /// scratch の引数を今の base のスロット 0.. に書き、`f` の先頭へ進む。見出しはそのまま使う。
    pub(crate) fn enter_in_place<M: Mode>(&mut self, code: &CodeBase<M>, f: u32) {
        let entry = &code.functions[f as usize];
        self.reserve(self.base + usize::from(entry.frame_size));
        let Task {
            stack,
            scratch,
            base,
            ..
        } = self;
        for (i, w) in scratch.drain(..).enumerate() {
            stack[*base + i] = w;
        }
        self.frame_size = usize::from(entry.frame_size);
        self.pc = entry.start;
    }

    /// 今のフレームの上に、戻り先 `ret` と結果のスロット `dst` を持つ空のフレームを作り、その base を返す。
    pub(crate) fn push_frame(&mut self, ret: Pc, dst: Slot, size: usize) -> usize {
        let base = self.base + self.frame_size + 2;
        self.reserve(base + size);
        self.stack[base - 2] = header(ret, dst, self.frame_size);
        self.stack[base - 1] = Word::from_bits(self.base);
        self.base = base;
        self.frame_size = size;
        base
    }

    /// 今のフレームを捨てて、呼び出し元の結果のスロットに `value` を書く。
    pub(crate) fn return_value(&mut self, value: Word) {
        let (pc, dst, size) = read_header(self.stack[self.base - 2]);
        self.base = self.stack[self.base - 1].bits();
        self.frame_size = size;
        self.pc = pc;
        self.set(dst, value);
    }
}

/// 見出しの1語目。戻り先、結果を書くスロット、呼び出し元の枠の大きさを1つの生の語に詰める
/// (docs/spec/vm.md の「フレーム」)。
fn header(ret: Pc, dst: Slot, caller_size: usize) -> Word {
    debug_assert!(caller_size <= usize::from(u16::MAX));
    Word::from_bits(((ret as usize) << 32) | (usize::from(dst) << 16) | caller_size)
}

fn read_header(w: Word) -> (Pc, Slot, usize) {
    let bits = w.bits();
    ((bits >> 32) as Pc, (bits >> 16) as Slot, bits & 0xFFFF)
}

pub(crate) fn run<M: Mode>(
    code: &CodeBase<M>,
    ctx: &mut Ctx<M>,
    task: &mut Task,
    counts: &mut RunCounts,
) -> Result<(), Failure> {
    loop {
        let pc = task.pc;
        match step(code, ctx, task, counts, pc) {
            Ok(true) => {}
            Ok(false) => return Ok(()),
            Err(fault) => return Err(Failure { fault, pc }),
        }
    }
}

/// 命令を1つ実行する。`Finish` に着いたら `false` を返す。
#[inline(always)]
fn step<M: Mode>(
    code: &CodeBase<M>,
    ctx: &mut Ctx<M>,
    task: &mut Task,
    counts: &mut RunCounts,
    pc: Pc,
) -> Result<bool, VmFault> {
    let _ = &counts;
    task.pc = pc + 1;
    match code.code[pc as usize] {
        Op::Move { dst, src } => task.set(dst, task.get(src)),
        Op::LoadRaw { dst, value } => task.set_raw(dst, value.into()),
        Op::LoadImm { dst, value } => task.set(dst, Word::imm(value.into())),
        Op::LoadConst { dst, index } => task.set(dst, code.constants[index as usize]),
        Op::Goto { target } => task.pc = target,
        Op::Ret { src } => {
            let value = task.get(src);
            task.last_ret = pc;
            task.return_value(value);
            ctx.poll(task.depth())?;
        }
        Op::Call { dst, at } => {
            call(code, task, dst, at);
            ctx.poll(task.depth())?;
        }
        Op::TailCall { at } => {
            let ops = &code.operands[at as usize..];
            let n = ops[1] as usize;
            task.scratch.clear();
            for &slot in &ops[2..2 + n] {
                let w = task.get(slot as Slot);
                task.scratch.push(w);
            }
            task.enter_in_place(code, ops[0]);
            ctx.poll(task.depth())?;
        }
        Op::Finish => {
            finish(code, ctx, task)?;
            return Ok(false);
        }
        // Task 5 で中身を入れる。それまではこの命令へ戻るフレームを作る命令がない
        Op::ApplyRest => return Err(VmFault::Internal("an apply-rest frame without an apply")),
        Op::IntAdd { dst, a, b } => task.set_raw(dst, externs::int_add(task.raw(a), task.raw(b))?),
        Op::IntSub { dst, a, b } => task.set_raw(dst, externs::int_sub(task.raw(a), task.raw(b))?),
        Op::IntMul { dst, a, b } => task.set_raw(dst, externs::int_mul(task.raw(a), task.raw(b))?),
        Op::IntDiv { dst, a, b } => task.set_raw(dst, externs::int_div(task.raw(a), task.raw(b))?),
        Op::IntRem { dst, a, b } => task.set_raw(dst, externs::int_rem(task.raw(a), task.raw(b))?),
        Op::IntNeg { dst, a } => task.set_raw(dst, externs::int_negate(task.raw(a))?),
        Op::IntEq { dst, a, b } => task.set_raw(dst, externs::int_eq(task.raw(a), task.raw(b))),
        Op::IntNe { dst, a, b } => task.set_raw(dst, externs::int_ne(task.raw(a), task.raw(b))),
        Op::IntLt { dst, a, b } => task.set_raw(dst, externs::int_lt(task.raw(a), task.raw(b))),
        Op::IntLe { dst, a, b } => task.set_raw(dst, externs::int_le(task.raw(a), task.raw(b))),
        Op::IntGt { dst, a, b } => task.set_raw(dst, externs::int_gt(task.raw(a), task.raw(b))),
        Op::IntGe { dst, a, b } => task.set_raw(dst, externs::int_ge(task.raw(a), task.raw(b))),
        Op::IntCompare { dst, a, b } => {
            task.set_raw(dst, externs::int_compare(task.raw(a), task.raw(b)))
        }
        Op::BoolEq { dst, a, b } => task.set_raw(dst, externs::bool_eq(task.raw(a), task.raw(b))),
        Op::BoolNe { dst, a, b } => task.set_raw(dst, externs::bool_ne(task.raw(a), task.raw(b))),
        Op::Extern { dst, at } => extern_call(code, ctx, task, dst, at)?,
    }
    Ok(true)
}

/// 呼ぶ側の上に呼ばれる側のフレームを作り、引数を写して先頭へ進む。呼ぶ側のスロットはスタックに残るので、`saved` は
/// 読まない。
fn call<M: Mode>(code: &CodeBase<M>, task: &mut Task, dst: Slot, at: u32) {
    let ops = &code.operands[at as usize..];
    let n = ops[1] as usize;
    let entry = &code.functions[ops[0] as usize];
    let caller = task.base;
    let base = task.push_frame(task.pc, dst, usize::from(entry.frame_size));
    for (i, &slot) in ops[2..2 + n].iter().enumerate() {
        task.stack[base + i] = task.stack[caller + slot as usize];
    }
    task.pc = entry.start;
}

/// 入口の関数の結果を手放す。CEK のいちばん下のフレームも、結果を手放してから終わる。
fn finish<M: Mode>(code: &CodeBase<M>, ctx: &mut Ctx<M>, task: &Task) -> Result<(), VmFault> {
    if code.entry_ret_rc {
        // 結果は入口の関数が返した、VM の持つ参照である
        unsafe { ctx.heap_mut().decref(task.get(0)) }?;
    }
    Ok(())
}

/// 算術と比較以外の extern。行の番号の `match` で `Ctx` のメソッドを呼ぶ (docs/spec/object-model.md の「extern」)。
fn extern_call<M: Mode>(
    code: &CodeBase<M>,
    ctx: &mut Ctx<M>,
    task: &mut Task,
    dst: Slot,
    at: u32,
) -> Result<(), VmFault> {
    let ops = &code.operands[at as usize..];
    let arg = |i: usize| ops[2 + i] as Slot;
    // 語の引数は、LIR の所有の規則により VM が持つ参照で、extern がそれを消費する
    unsafe {
        match Extern::ALL[ops[0] as usize] {
            Extern::Println => {
                ctx.println(task.get(arg(0)))?;
                task.set(dst, Word::UNIT);
            }
            Extern::Open => {
                let w = ctx.fs_open(task.get(arg(0)))?;
                task.set(dst, w);
            }
            Extern::ReadAll => {
                let w = ctx.fs_read_all(task.get(arg(0)))?;
                task.set(dst, w);
            }
            Extern::Close => {
                ctx.fs_close(task.get(arg(0)))?;
                task.set(dst, Word::UNIT);
            }
            Extern::IntShow => {
                let w = ctx.int_show(task.raw(arg(0)));
                task.set(dst, w);
            }
            Extern::StrConcat => {
                let w = ctx.string_append(task.get(arg(0)), task.get(arg(1)))?;
                task.set(dst, w);
            }
            Extern::StrEq => {
                let r = ctx.string_eq(task.get(arg(0)), task.get(arg(1)))?;
                task.set_raw(dst, r);
            }
            Extern::StrNe => {
                let r = ctx.string_ne(task.get(arg(0)), task.get(arg(1)))?;
                task.set_raw(dst, r);
            }
            Extern::StrCompare => {
                let r = ctx.string_compare(task.get(arg(0)), task.get(arg(1)))?;
                task.set_raw(dst, r);
            }
            Extern::StrShow => {
                let w = ctx.string_show(task.get(arg(0)))?;
                task.set(dst, w);
            }
            _ => {
                return Err(VmFault::Internal(
                    "an arithmetic extern reached the generic extern instruction",
                ));
            }
        }
    }
    Ok(())
}
```

```rust
/// セッションの `Control` を渡して実行する。割り込みと上限のテストが使う。
pub fn execute_with(
    program: &Program,
    debug_heap: bool,
    host: HostRef,
    control: Arc<Control>,
) -> Result<RunStats, VmError> {
    if debug_heap {
        run::<Checked>(program, host, control, check_heap)
    } else {
        run::<Fast>(program, host, control, |_| Ok(()))
    }
}

fn run<M: Mode>(
    program: &Program,
    host: HostRef,
    control: Arc<Control>,
    check: fn(&Ctx<M>) -> Result<(), VmError>,
) -> Result<RunStats, VmError> {
    let code = compile::<M>(program, control.clone()).map_err(|error| compile_error(program, error))?;
    let mut ctx = Ctx::<M>::new(control, host);
    // どの語も作る前に付けるので、`heap_mut` の前提 (Ctx の持つ語に触れない) を崩さない
    unsafe { ctx.heap_mut() }.attach(Arc::clone(&code.region));
    let mut task = Task::new(&code);
    let mut counts = RunCounts::default();
    let result = vm::run(&code, &mut ctx, &mut task, &mut counts);
    // 誤りを返す前にも書き出す。`> out 2>&1` のときに出力と誤りの順を保つためである
    let flushed = ctx.flush();
    result.map_err(|failure| code.error(failure, &task))?;
    flushed.map_err(|fault| {
        code.error(
            vm::Failure {
                fault: fault.into(),
                pc: task.last_ret,
            },
            &task,
        )
    })?;
    if !ctx.check_finished() {
        return Err(code.error(
            vm::Failure {
                fault: VmFault::Internal("the evidence list or a yield is left at the end"),
                pc: task.last_ret,
            },
            &task,
        ));
    }
    check(&ctx)?;
    let (c, h) = (ctx.stats(), ctx.heap().stats());
    Ok(RunStats {
        evidence_steps: c.evidence_steps,
        yields: c.yields,
        yield_frames: c.yield_frames,
        string_bytes_copied: c.string_bytes_copied,
        rc_increments: h.rc_increments,
        rc_decrements: h.rc_decrements,
        boxes: counts.boxes,
        unboxes: counts.unboxes,
        peak_objects: h.peak_live,
    })
}

fn check_heap(ctx: &Ctx<Checked>) -> Result<(), VmError> {
    let heap = ctx.heap();
    heap.check_invariants().map_err(|error| VmError::Fault {
        fault: error.into(),
        function: String::new(),
        at: None,
    })?;
    let leaks = heap.leaks();
    if leaks.is_empty() {
        Ok(())
    } else {
        Err(VmError::Leak(
            leaks
                .into_iter()
                .map(|(name, n)| (name.to_string(), n))
                .collect(),
        ))
    }
}

/// コード生成の誤りは、正しいプログラムでは起きない内部の誤りである。
fn compile_error(program: &Program, error: CompileError) -> VmError {
    let (what, function) = match error {
        CompileError::TooManySlots { function } => ("a function needs more than 65535 slots", function),
        CompileError::Freeze(_) => (
            "the constants cannot be frozen",
            program.function(program.entry).name.clone(),
        ),
    };
    VmError::Fault {
        fault: VmFault::Internal(what),
        function,
        at: None,
    }
}

impl Capture {
    pub fn contents(&self) -> String {
        let bytes = self.0.lock().unwrap_or_else(PoisonError::into_inner);

    }

    }

        Ok(())
    }
}
```

```rust
//! ブロック引数への並列な代入を、`Move` の列に直す (docs/spec/vm.md の「スロットの割り当て」)。

use crate::op::Slot;

/// 並列な代入 `dst := src` の組を、順に実行してよい `(dst, src)` の列にする。どの代入も、まだ読まれていない値を
/// 上書きしない順に並べる。輪は `scratch` を通して切る。
pub(crate) fn sequentialize(moves: &[(Slot, Slot)], scratch: Slot) -> Vec<(Slot, Slot)> {
    let mut pending: Vec<(Slot, Slot)> = moves.iter().copied().filter(|(d, s)| d != s).collect();
    let mut out = Vec::with_capacity(pending.len() + 1);
    while !pending.is_empty() {
        let ready = pending
            .iter()
            .position(|&(dst, _)| !pending.iter().any(|&(_, src)| src == dst));
        match ready {
            Some(index) => out.push(pending.swap_remove(index)),
            None => {
                // 残りはどれも、ほかの代入がまだ読む値を上書きする。1つの値を退避して輪を切る
                let (_, src) = pending[0];
                out.push((scratch, src));
                for (_, s) in &mut pending {
                    if *s == src {
                        *s = scratch;
                    }
                }
            }
        }
    }
    out
}
```

```rust
//! スロット 0.. に固定してから、残りの変数を番号の順に、隣と違ういちばん小さい色で塗る。

use std::collections::BTreeSet;

use eml_lir::liveness::{live_after_term, live_in, step_back};
use eml_lir::{Atom, LirFn, Stmt, Term, VarId};

use crate::code::CompileError;
use crate::op::Slot;

pub(crate) struct Slots {
    /// 変数の番号ごとのスロット。
    pub(crate) of: Vec<Slot>,
    /// 変数が使うスロットの数。一時のスロットはこの後に置く。
    pub(crate) colors: u16,
}

pub(crate) fn allocate(function: &LirFn) -> Result<Slots, CompileError> {
    let graph = interference(function);
    let mut color: Vec<Option<usize>> = vec![None; function.vars.len()];
    for (index, param) in function.params().iter().enumerate() {
        color[param.0 as usize] = Some(index);
    }
    let mut colors = function.params().len();
    for var in 0..function.vars.len() {
        if color[var].is_some() {
            continue;
        }
        let taken: BTreeSet<usize> = graph[var].iter().filter_map(|&n| color[n]).collect();
        let free = (0..).find(|c| !taken.contains(c)).expect("a free color exists");
        color[var] = Some(free);
        colors = colors.max(free + 1);
    }
    let too_many = || CompileError::TooManySlots {
        function: function.name.clone(),
    };
    let of = color
        .into_iter()
        .map(|c| Slot::try_from(c.expect("every variable has a color")).map_err(|_| too_many()))
        .collect::<Result<_, _>>()?;
    Ok(Slots {
        of,
        colors: u16::try_from(colors).map_err(|_| too_many())?,
    })
}

/// 変数ごとの隣。
fn interference(function: &LirFn) -> Vec<BTreeSet<usize>> {
    let mut graph = vec![BTreeSet::new(); function.vars.len()];
    let mut edge = |a: VarId, b: VarId| {
        if a != b {
            graph[a.0 as usize].insert(b.0 as usize);
            graph[b.0 as usize].insert(a.0 as usize);
        }
    };
    let live_in = live_in(function);
    for (index, block) in function.blocks.iter().enumerate() {
        // ブロックの引数は入口で同時に書くので、互いと、入口で生きている変数と干渉する
        let entry: Vec<VarId> = live_in[index].clone();
        for &param in &block.params {
            for &other in block.params.iter().chain(&entry) {
                edge(param, other);
            }
        }
        // case のフィールドは switch で書くので、互いと、行き先の入口で生きている変数と、scrutinee と干渉する。
        // scrutinee のスロットを上書きすると、残りのフィールドを読めなくなるためである
        if let Term::Switch {
            scrutinee, cases, ..
        } = &block.term
        {
            for case in cases {
                let target = &live_in[case.target.0 as usize];
                for &field in &case.fields {
                    for &other in case.fields.iter().chain(target) {
                        edge(field, other);
                    }
                    if let Atom::Var(var) = scrutinee {
                        edge(field, *var);
                    }
                }
            }
        }
        let mut live = live_after_term(function, &block.term, &live_in);
        block.term.for_each_atom(|atom| {
            if let Atom::Var(var) = atom {
                live.insert(var);
            }
        });
        for stmt in block.stmts.iter().rev() {
            // 定義は、その文の後で生きているすべての変数と干渉する。定義した変数が死んでいても同じである
            for &def in stmt.defs() {
                for &other in stmt.defs().iter().chain(&live) {
                    edge(def, other);
                }
            }
            // unpack の値は、書くフィールドと干渉する (switch の scrutinee と同じ理由)
            if let Stmt::Unpack { value, fields, .. } = stmt {
                for &field in fields {
                    edge(field, *value);
                }
            }
            step_back(stmt, &mut live);
        }
    }
    graph
}
```

```rust
    /// ブロック引数への並列な代入と、行き先への `Goto`。変数の代入を先に並べ、定数はその後に書く。定数の書き込み先が、
    /// ほかの代入がまだ読む値のスロットでありうるためである。次のブロックへ進むだけなら `Goto` を出さない。
    pub(crate) fn jump(&mut self, from: BlockId, target: BlockId, args: &[Atom]) {
        let params = self.function.block(target).params.clone();
        let mut moves = Vec::new();
        let mut constants = Vec::new();
        for (&param, &arg) in params.iter().zip(args) {
            let dst = self.slot(param);
            match arg {
                Atom::Var(var) => moves.push((dst, self.slot(var))),
                constant => constants.push((dst, constant, self.repr(param))),
            }
        }
        let scratch = self.temp();
        for (dst, src) in super::moves::sequentialize(&moves, scratch) {
            self.out.push(Op::Move { dst, src });
        }
        for (dst, constant, repr) in constants {
            self.load(dst, constant, repr);
        }
        self.goto(from, target);
    }
```

オペランドの形 (`operands[at..]`):

| 命令 | 並び |
|---|---|
| `Con` | `tag, scanned, raw, lin, n, (位置 \| RAW, スロット) × n` |
| `SwitchEnum`、`SwitchObj`、`SwitchTObj` | `m (配置のコンストラクタの数), default (NONE なら無し), 飛び先の表 × m, case の記録…`。表の t 番目は、タグ t の case の記録の `at` からの位置か、case がなければ NONE。記録は `[行き先, 確かめる走査する語の数 (NONE なら確かめない), フィールドの数, (位置 \| RAW, スロット) × フィールドの数]` |
| `SwitchInt`、`SwitchString` | `case の数, default, (key_lo, key_hi, 行き先) × case の数` |
| `Unpack` | `tag, scanned, n, (位置 \| RAW, スロット) × n` |
| `Release` | `tag, scanned, n, (位置 \| KEEP) × n` (走査する語のフィールドだけ) |

タグの switch はいつも1つの配置のタグで分けるので、タグは 0 から m - 1 に収まり、飛び先の表はいつも密である。そのため、spec の「タグが密なら飛び先の表」は、タグの switch ではいつも表になる。`key_lo` と `key_hi` は、`Int` なら値の下位と上位の 32 ビット、`String` なら `(constants の添字, 0)` である。位置は物理的な位置で、走査する語が 255 個以上の物体では数の語の分 (1) を足してある。

```rust
//! データの命令: `con`、switch、`unpack`、`release`、box (docs/spec/vm.md の「命令ごとの実行」)。

use eml_rt::{Ctx, Kind, Mode, Word};

use crate::RunCounts;
use crate::code::CodeBase;
use crate::error::VmFault;
use crate::op::{KEEP, NONE, RAW, Slot};
use crate::vm::Task;

/// 走査する語が 255 個以上の物体の、ペイロードの先頭の数の語の分 (docs/spec/object-model.md の「ヘッダ」)。
pub(crate) fn count_word(scanned: u32) -> u32 {
    u32::from(scanned >= 255)
}

/// フィールドを物理的な位置から読んでスロットに書く。読むだけなので、参照の数は変えない。
fn bind_fields<M: Mode>(
    ctx: &Ctx<M>,
    task: &mut Task,
    w: Word,
    fields: &[u32],
) -> Result<(), VmFault> {
    let heap = ctx.heap();
    for pair in fields.chunks_exact(2) {
        let (position, slot) = (pair[0], pair[1] as Slot);
        // 値は verifier を通った IR が名指した配置の物体で、フィールドは持ち主から借りて読む
        if position & RAW == 0 {
            let field = unsafe { heap.field(w, position as usize) }?;
            task.set(slot, field);
        } else {
            let raw = unsafe { heap.raw(w, (position & !RAW) as usize) }?;
            task.set_raw(slot, raw as i64);
        }
    }
    Ok(())
}

/// 検査モードで、`w` がタグ `tag` で走査する語が `scanned` 個のデータであることを確かめる。verifier の R9 は値を
/// 作った配置を追わないので、verifier を通った IR でも外れうる (docs/spec/lir.md の「構造の規則」)。
fn check_data<M: Mode>(
    ctx: &Ctx<M>,
    w: Word,
    tag: u32,
    scanned: u32,
    what: &'static str,
) -> Result<(), VmFault> {
    if !M::CHECKED {
        return Ok(());
    }
    let heap = ctx.heap();
    let ok = w.is_ptr() && {
        let meta = unsafe { heap.meta(w) }?;
        meta.kind() == Kind::Data
            && u32::from(meta.tag()) == tag
            && unsafe { heap.scanned_len(w) }? == scanned as usize
    };
    if ok { Ok(()) } else { Err(VmFault::Internal(what)) }
}

pub(crate) fn con<M: Mode>(
    code: &CodeBase<M>,
    ctx: &mut Ctx<M>,
    task: &mut Task,
    dst: Slot,
    at: u32,
) -> Result<(), VmFault> {
    let ops = &code.operands[at as usize..];
    let (tag, scanned, raw, lin, n) = (ops[0], ops[1], ops[2], ops[3] != 0, ops[4] as usize);
    // ヒープに触れるのは作る物体だけで、`Ctx` の持つ語には触れない
    let heap = unsafe { ctx.heap_mut() };
    let w = heap.alloc_data(tag as u16, scanned as usize, raw as usize, lin);
    for pair in ops[5..5 + 2 * n].chunks_exact(2) {
        let (position, value) = (pair[0], task.get(pair[1] as Slot));
        if position & RAW == 0 {
            unsafe { heap.set_field(w, position as usize, value) }?;
        } else {
            unsafe { heap.set_raw(w, (position & !RAW) as usize, value.bits() as u64) }?;
        }
    }
    task.set(dst, w);
    Ok(())
}

/// タグの switch。`w` は scrutinee の語で、`tag` は Repr に従って読んだタグである。
pub(crate) fn switch_tag<M: Mode>(
    code: &CodeBase<M>,
    ctx: &Ctx<M>,
    task: &mut Task,
    w: Word,
    tag: i64,
    at: u32,
) -> Result<(), VmFault> {
    let ops = &code.operands[at as usize..];
    let (m, default) = (ops[0] as usize, ops[1]);
    // タグは配置のタグなので、飛び先の表を1回引けば case が決まる
    let record = usize::try_from(tag)
        .ok()
        .filter(|&t| t < m)
        .map(|t| ops[2 + t])
        .filter(|&r| r != NONE);
    let Some(record) = record else {
        return take_default(task, default);
    };
    let r = &ops[record as usize..];
    let (target, check, n) = (r[0], r[1], r[2] as usize);
    if check != NONE {
        check_data(
            ctx,
            w,
            tag as u32,
            check,
            "a switch case binds a different number of fields than the value has",
        )?;
    }
    bind_fields(ctx, task, w, &r[3..3 + 2 * n])?;
    task.pc = target;
    Ok(())
}

fn take_default(task: &mut Task, default: u32) -> Result<(), VmFault> {
    if default == NONE {
        return Err(VmFault::Internal("a switch without a matching case"));
    }
    task.pc = default;
    Ok(())
}

pub(crate) fn switch_int<M: Mode>(code: &CodeBase<M>, task: &mut Task, n: i64, at: u32) -> Result<(), VmFault> {
    let ops = &code.operands[at as usize..];
    let (cases, default) = (ops[0] as usize, ops[1]);
    for case in 0..cases {
        let i = 2 + 3 * case;
        let key = i64::from(ops[i]) | (i64::from(ops[i + 1]) << 32);
        if key == n {
            task.pc = ops[i + 2];
            return Ok(());
        }
    }
    take_default(task, default)
}

pub(crate) fn switch_string<M: Mode>(
    code: &CodeBase<M>,
    ctx: &Ctx<M>,
    task: &mut Task,
    w: Word,
    at: u32,
) -> Result<(), VmFault> {
    let ops = &code.operands[at as usize..];
    let (cases, default) = (ops[0] as usize, ops[1]);
    let heap = ctx.heap();
    // scrutinee も定数も借りて読み、手放さない
    let text = unsafe { &*heap.string(w)? };
    for case in 0..cases {
        let i = 2 + 3 * case;
        let constant = unsafe { &*heap.string(code.constants[ops[i] as usize])? };
        if constant == text {
            task.pc = ops[i + 2];
            return Ok(());
        }
    }
    take_default(task, default)
}

pub(crate) fn unpack<M: Mode>(
    code: &CodeBase<M>,
    ctx: &Ctx<M>,
    task: &mut Task,
    src: Slot,
    at: u32,
) -> Result<(), VmFault> {
    let ops = &code.operands[at as usize..];
    let (tag, scanned, n) = (ops[0], ops[1], ops[2] as usize);
    let w = task.get(src);
    check_data(
        ctx,
        w,
        tag,
        scanned,
        "an unpack names a tag and number of fields the value does not have",
    )?;
    bind_fields(ctx, task, w, &ops[3..3 + 2 * n])
}

/// 形の分かっている `release` の展開 (docs/spec/object-model.md の「核の操作」)。残す変数はすでにスロットにあるので、
/// 参照の数だけを動かす。
pub(crate) fn release<M: Mode>(
    code: &CodeBase<M>,
    ctx: &mut Ctx<M>,
    task: &Task,
    src: Slot,
    at: u32,
) -> Result<(), VmFault> {
    let ops = &code.operands[at as usize..];
    let (tag, scanned, n) = (ops[0], ops[1], ops[2] as usize);
    let entries = &ops[3..3 + n];
    let w = task.get(src);
    check_data(
        ctx,
        w,
        tag,
        scanned,
        "a release names a tag and number of fields the value does not have",
    )?;
    // VM は `w` の参照を1つ持ち、残さない子はその参照と数える
    let heap = unsafe { ctx.heap_mut() };
    unsafe {
        if heap.is_last(w)? {
            for &entry in entries.iter().filter(|&&e| e & KEEP == 0) {
                let child = heap.field(w, entry as usize)?;
                heap.decref(child)?;
            }
            heap.free_block(w)?;
        } else {
            for &entry in entries.iter().filter(|&&e| e & KEEP != 0) {
                let child = heap.field(w, (entry & !KEEP) as usize)?;
                heap.dup(child)?;
            }
            heap.decref(w)?;
        }
    }
    Ok(())
}

pub(crate) fn unbox<M: Mode>(ctx: &Ctx<M>, w: Word, counts: &mut RunCounts) -> Result<i64, VmFault> {
    if M::CHECKED {
        counts.unboxes += 1;
    }
    if w.is_imm() {
        Ok(w.imm_value())
    } else {
        // ダミーは値 0 の `BigInt` なので、ここで 0 を読む (docs/spec/object-model.md の「ダミーの値」)
        Ok(unsafe { ctx.heap().unbox_int(w) }?)
    }
}
```

```rust
fn elided_decrefs(function: &LirFn) -> Vec<Option<VarId>> {
    let mut preds = vec![0usize; function.blocks.len()];
    for block in &function.blocks {
        for target in block.term.successors() {
            preds[target.0 as usize] += 1;
        }
    }
    let mut elided = vec![None; function.blocks.len()];

            scrutinee: Atom::Var(var),
            layout: Some(_),
            cases,
            default: _,
        } = &block.term
            && function.repr(*var) == Repr::TObj

                if case.fields.is_empty() && preds[case.target.0 as usize] == 1 {
                    elided[case.target.0 as usize] = Some(*var);
                }
            }
        }
    }
```

```rust
    fn switch(
        &mut self,
        block: BlockId,
        scrutinee: Atom,
        layout: Option<eml_lir::LayoutId>,
        cases: &[eml_lir::Case],
        default: Option<BlockId>,
    ) {
        use eml_lir::CasePattern;
        let Atom::Var(var) = scrutinee else {
            // 定数の scrutinee は、コード生成の時点で行き先を決める
            let target = cases
                .iter()
                .find(|case| match (case.pattern, scrutinee) {
                    (CasePattern::Tag(t), Atom::Tag(n)) => t == n,
                    (CasePattern::Int(k), Atom::Int(n)) => k == n,
                    _ => false,
                })
                .map(|case| case.target)
                .or(default)
                .expect("a constant switch has a matching case or a default");
            self.goto(block, target);
            return;
        };
        let base = self.out.operands.len();
        let mut patches = Vec::new();
        if let Some(default) = default {
            patches.push((1, default));
        }
        let src = self.slot(var);
        let (items, op) = match (cases.first().map(|case| case.pattern), layout) {
            (Some(CasePattern::Int(_) | CasePattern::String(_)), _) | (None, None) => {
                let mut items = vec![cases.len() as u32, NONE];
                for case in cases {
                    let (lo, hi) = match case.pattern {
                        CasePattern::Int(n) => (n as u32, (n >> 32) as u32),
                        CasePattern::String(index) => (self.strings[index as usize], 0),
                        CasePattern::Tag(_) => unreachable!("one switch compares one kind of case"),
                    };
                    patches.push((items.len() + 2, case.target));
                    items.extend([lo, hi, 0]);
                }
                let at = base as u32;
                let op = if matches!(cases.first().map(|c| c.pattern), Some(CasePattern::String(_))) {
                    Op::SwitchString { src, at }
                } else {
                    Op::SwitchInt { src, at }
                };
                (items, op)
            }
            (_, Some(layout)) => {
                // 配置のタグは 0 から m - 1 に収まるので、飛び先の表はいつも密である
                let ctors = &self.program.layouts[layout.0 as usize].constructors;
                let m = ctors.len();
                let mut items = vec![m as u32, NONE];
                items.extend(std::iter::repeat_n(NONE, m));
                for case in cases {
                    let CasePattern::Tag(tag) = case.pattern else {
                        unreachable!("one switch compares one kind of case")
                    };
                    let (check, fields) = if case.fields.is_empty() {
                        (NONE, Vec::new())
                    } else {
                        let ctor = eml_lir::Ctor { layout, tag };
                        (ctors[tag as usize].shape().scanned, self.field_operands(ctor, &case.fields))
                    };
                    items[2 + tag as usize] = items.len() as u32;
                    patches.push((items.len(), case.target));
                    items.extend([0, check, (fields.len() / 2) as u32]);
                    items.extend(fields);
                }
                let at = base as u32;
                let op = match self.repr(var) {
                    Repr::Enum => Op::SwitchEnum { src, at },
                    Repr::Obj => Op::SwitchObj { src, at },
                    _ => Op::SwitchTObj { src, at },
                };
                (items, op)
            }
            (Some(CasePattern::Tag(_)), None) => {
                unreachable!("a switch with tag cases names its layout (docs/spec/lir.md)")
            }
        };
        for (offset, target) in patches {
            self.operand_patches.push((base + offset, target));
        }
        self.out.operands(items);
        self.out.push(op);
    }
```

```rust
/// タグの switch の飛び先の表を、case のあるタグだけ並べる。
fn tag_cases<M: Mode>(code: &CodeBase<M>, at: u32) -> String {
    let o = &code.operands[at as usize..];
    let (m, default) = (o[0] as usize, o[1]);
    let mut parts = Vec::new();
    for tag in 0..m {
        let record = o[2 + tag];
        if record == NONE {
            continue;
        }
        let r = &o[record as usize..];
        let bound = fields(&r[3..3 + 2 * r[2] as usize]);
        parts.push(format!("#{tag} -> {} [{bound}]", r[0]));
    }
    if default != NONE {
        parts.push(format!("_ -> {default}"));
    }
    format!("{{ {} }}", parts.join(", "))
}

fn key_cases<M: Mode>(code: &CodeBase<M>, at: u32) -> String {
    let o = &code.operands[at as usize..];
    let (n, default) = (o[0] as usize, o[1]);
    let mut parts: Vec<String> = (0..n)
        .map(|case| {
            let i = 2 + 3 * case;
            let key = i64::from(o[i]) | (i64::from(o[i + 1]) << 32);
            format!("{key} -> {}", o[i + 2])
        })
        .collect();
    if default != NONE {
        parts.push(format!("_ -> {default}"));
    }
    format!("{{ {} }}", parts.join(", "))
}
```

```rust
//! 関数の値の適用とクロージャ (docs/spec/vm.md の「呼び出しと戻り」)。引数は `Task::scratch` に置いて渡す。

use eml_rt::{Ctx, Mode, Word};

use crate::code::CodeBase;
use crate::data::count_word;
use crate::error::VmFault;
use crate::op::{APPLY_REST, Pc, Slot};
use crate::vm::Task;

/// 適用の結果の行き先。
pub(crate) enum Target {
    /// 今のフレームの上に呼ばれる側を積み、戻り先 `ret` で結果を `dst` に受ける。
    Frame { ret: Pc, dst: Slot },
    /// 今のフレームを置き換える (末尾の位置)。
    Tail,
}

/// `callee` を `task.scratch` の引数に適用する。`clause` なら、引数の数はいつも入口の関数の引数の数と等しい。
/// `clause` の引数は操作の ABI の Repr (生の `int` を含む) を持つので、部分適用でクロージャの走査する語に入れては
/// ならないためである。
pub(crate) fn apply<M: Mode>(
    code: &CodeBase<M>,
    ctx: &mut Ctx<M>,
    task: &mut Task,
    callee: Word,
    target: Target,
    clause: bool,
) -> Result<(), VmFault> {
    let not_a_function = VmFault::Internal("applying a value that is not a function");
    let (f, lin) = if callee.is_imm() {
        (callee.imm_value(), false)
    } else {
        // VM は `callee` の参照を1つ持つ。中身を取り出した後、その参照を手放すか箱を空ける
        let heap = unsafe { ctx.heap_mut() };
        unsafe {
            let lin = heap.meta(callee)?.lin();
            let len = heap.scanned_len(callee)?;
            let function = heap.scanned(callee, 0)?;
            if M::CHECKED && (len == 0 || !function.is_imm()) {
                return Err(not_a_function);
            }
            let captured = (1..len).map(|i| heap.scanned(callee, i));
            let captured: Result<Vec<Word>, _> = captured.collect();
            let captured = captured?;
            if heap.is_last(callee)? {
                heap.free_block(callee)?;
            } else {
                for &w in &captured {
                    heap.dup(w)?;
                }
                heap.decref(callee)?;
            }
            task.scratch.splice(0..0, captured);
            (function.imm_value(), lin)
        }
    };
    let entry = usize::try_from(f)
        .ok()
        .and_then(|f| code.functions.get(f))
        .ok_or(not_a_function)?;
    let (f, arity, total) = (f as u32, usize::from(entry.arity), task.scratch.len());
    if clause && total != arity {
        return Err(VmFault::Internal(
            "a clause gets a different number of arguments than its function takes",
        ));
    }
    match total.cmp(&arity) {
        std::cmp::Ordering::Equal => enter(code, task, f, target),
        std::cmp::Ordering::Less => {
            let closure = make_closure(ctx, f, lin, &task.scratch)?;
            task.scratch.clear();
            deliver(task, target, closure);
        }
        std::cmp::Ordering::Greater => {
            let n = total - arity;
            let size = 2 + n;
            if size > usize::from(u16::MAX) {
                return Err(VmFault::Internal("too many arguments are left over"));
            }
            let base = match target {
                Target::Frame { ret, dst } => task.push_frame(ret, dst, size),
                Target::Tail => {
                    task.frame_size = size;
                    task.reserve(task.base + size);
                    task.base
                }
            };
            task.stack[base + 1] = Word::from_bits(n);
            for (i, w) in task.scratch.drain(arity..).enumerate() {
                task.stack[base + 2 + i] = w;
            }
            enter(code, task, f, Target::Frame { ret: APPLY_REST, dst: 0 });
        }
    }
    Ok(())
}

/// scratch の引数で `f` に入る。
fn enter<M: Mode>(code: &CodeBase<M>, task: &mut Task, f: u32, target: Target) {
    if let Target::Frame { ret, dst } = target {
        let size = usize::from(code.functions[f as usize].frame_size);
        task.push_frame(ret, dst, size);
    }
    task.enter_in_place(code, f);
}

fn deliver(task: &mut Task, target: Target, value: Word) {
    match target {
        Target::Frame { ret, dst } => {
            task.set(dst, value);
            task.pc = ret;
        }
        Target::Tail => task.return_value(value),
    }
}

/// `f` と先頭の引数からクロージャを作る (docs/spec/object-model.md の「クロージャ」)。
pub(crate) fn make_closure<M: Mode>(
    ctx: &mut Ctx<M>,
    f: u32,
    lin: bool,
    args: &[Word],
) -> Result<Word, VmFault> {
    let scanned = 1 + args.len();
    let offset = count_word(scanned as u32) as usize;
    // 作る物体だけに書き、`Ctx` の持つ語には触れない
    let heap = unsafe { ctx.heap_mut() };
    let w = heap.alloc_data(0, scanned, 0, lin);
    unsafe {
        heap.set_field(w, offset, Word::imm(f.into()))?;
        for (i, &arg) in args.iter().enumerate() {
            heap.set_field(w, offset + 1 + i, arg)?;
        }
    }
    Ok(w)
}

/// `ApplyRest` のフレームから、結果に残りの引数を適用する。このフレームの見出しを引き継ぐ末尾の適用である。
pub(crate) fn apply_rest<M: Mode>(
    code: &CodeBase<M>,
    ctx: &mut Ctx<M>,
    task: &mut Task,
) -> Result<(), VmFault> {
    let callee = task.get(0);
    let n = task.get(1).bits();
    task.scratch.clear();
    for i in 0..n {
        let w = task.get((2 + i) as Slot);
        task.scratch.push(w);
    }
    apply(code, ctx, task, callee, Target::Tail, false)
}
```

```rust
    /// 表の Repr で、先頭の evidence は `obj` である (docs/spec/lir.md の「節の呼び出し」)。
    fn value_call_operands(&mut self, call: &Call) -> u32 {
        let (callee, args, reprs): (Atom, &[Atom], Vec<Repr>) = match call {
            Call::Apply { callee, args, .. } => (*callee, args, vec![Repr::TObj; args.len()]),
            Call::Clause {
                effect,
                op,
                callee,
                args,
            } => {
                let operation = eml_lir::operation(&self.program.effects, *effect, *op);
                let reprs = std::iter::once(Repr::Obj).chain(operation.params.iter().copied()).collect();
                (*callee, args, reprs)
            }
            Call::Direct(..) => unreachable!("a direct call has its own instruction"),
        };
        let callee = self.atom(callee, Repr::TObj);
        let slots: Vec<Slot> = args
            .iter()
            .zip(reprs)
            .map(|(&arg, repr)| self.atom(arg, repr))
            .collect();
        self.out.operands(
```

```rust
//! 基本操作 (docs/spec/lir.md の「基本操作」)。どれも `Ctx` のメソッドを呼ぶ。借用の引数は `Ctx` が手放さないので、
//! VM は語を渡すだけでよい。結果が `unit` の操作は、結果のスロットに `()` を書く。

use eml_rt::{Ctx, Mode, Word};

use crate::code::CodeBase;
use crate::error::VmFault;
use crate::op::{Op, Slot};
use crate::vm::Task;

/// 基本操作の命令を実行する。基本操作でない命令なら `false` を返す。
pub(crate) fn step<M: Mode>(
    code: &CodeBase<M>,
    ctx: &mut Ctx<M>,
    task: &mut Task,
    op: Op,
) -> Result<bool, VmFault> {
    let ops = |at: u32| &code.operands[at as usize..];
    // 引数の語は、LIR の所有の規則により VM が持つ参照か借りた語で、基本操作の契約 (docs/spec/object-model.md の
    // 「基本操作の契約」) のとおりに渡す。VM は基本操作の合間に `Ctx` の持つ語に触れない
    unsafe {
        match op {
            Op::EvvGet { dst } => {
                let w = ctx.evv_get()?;
                task.set(dst, w);
            }
            Op::EvvSet { dst, l } => {
                ctx.evv_set(task.get(l))?;
                task.set(dst, Word::UNIT);
            }
            Op::EvvPush { dst, l, e } => {
                let w = ctx.evv_push(task.get(l), task.get(e))?;
                task.set(dst, w);
            }
            Op::EvvMask { dst, at } => {
                let o = ops(at);
                let list = &code.effect_lists[o[0] as usize..(o[0] + o[1]) as usize];
                let w = ctx.evv_mask(list, task.get(o[2] as Slot))?;
                task.set(dst, w);
            }
            Op::EvNew { dst, at } => {
                let o = ops(at);
                let w = ctx.ev_new(
                    o[0] as u16,
                    o[1] as usize,
                    task.get(o[2] as Slot),
                    task.get(o[3] as Slot),
                )?;
                task.set(dst, w);
            }
            Op::EvSetClause { dst, at } => {
                let o = ops(at);
                ctx.ev_set_clause(task.get(o[0] as Slot), o[1] as usize, task.get(o[2] as Slot))?;
                task.set(dst, Word::UNIT);
            }
            Op::EvRenew { dst, ev, state } => {
                let w = ctx.ev_renew(task.get(ev), task.get(state))?;
                task.set(dst, w);
            }
            Op::EvLookup { dst, effect } => {
                let w = ctx.ev_lookup(effect)?;
                task.set(dst, w);
            }
            Op::EvClause { dst, ev, op } => {
                let w = ctx.ev_clause(task.get(ev), op.into())?;
                task.set(dst, w);
            }
            Op::EvEvv { dst, ev } => {
                let w = ctx.ev_evv(task.get(ev))?;
                task.set(dst, w);
            }
            Op::EvTakeState { dst, ev } => {
                let w = ctx.ev_take_state(task.get(ev))?;
                task.set(dst, w);
            }
            Op::EvSetState { dst, ev, s } => {
                ctx.ev_set_state(task.get(ev), task.get(s))?;
                task.set(dst, Word::UNIT);
            }
            Op::Yielding { dst } => {
                let r = ctx.yielding();
                task.set_raw(dst, r);
            }
            Op::YieldStatus { dst, ev } => {
                let r = ctx.yield_status(task.get(ev));
                task.set_raw(dst, r);
            }
            Op::YieldTo { dst, at } | Op::YieldAbort { dst, at } => {
                let o = ops(at);
                let (ev, clause, k) = (task.get(o[0] as Slot), task.get(o[1] as Slot), task.get(o[2] as Slot));
                if matches!(op, Op::YieldTo { .. }) {
                    ctx.yield_to(ev, clause, k)?;
                } else {
                    ctx.yield_abort(ev, clause, k)?;
                }
                task.set(dst, Word::UNIT);
            }
            Op::YieldContTake { dst } => {
                let w = ctx.yield_cont_take()?;
                task.set(dst, w);
            }
            Op::YieldContSet { dst, k } => {
                ctx.yield_cont_set(task.get(k))?;
                task.set(dst, Word::UNIT);
            }
            Op::YieldFinish { dst } => {
                let w = ctx.yield_finish()?;
                task.set(dst, w);
            }
            Op::Dummy { dst } => {
                let w = ctx.heap().dummy();
                task.set(dst, w);
            }
            _ => return Ok(false),
        }
    }
    Ok(true)
}
```

```rust
        use eml_lir::Prim;
        let effect = |e: u32| u16::try_from(e).expect("effects fit in 16 bits (docs/spec/object-model.md)");
        let op_index = |o: u32| u16::try_from(o).expect("operations fit in 16 bits");
        match prim {
            Prim::EvvGet => Op::EvvGet { dst },
            Prim::EvvSet => Op::EvvSet { dst, l: a[0] },

            Prim::EvTakeState => Op::EvTakeState { dst, ev: a[0] },

            Prim::Yielding => Op::Yielding { dst },
            Prim::YieldStatus => Op::YieldStatus { dst, ev: a[0] },
```

```rust
/// 診断のエラーなしでコンパイルし、`debug_heap` を有効にして CEK で実行する。同じプログラムを VM でも実行し、出力と
/// 誤りの文言が CEK と同じであることを確かめる (docs/spec/vm.md の「UI テストを2つのエンジンで流す」)。
fn compile_and_execute(path: &Path, suffix: &str) -> (String, String, Result<(), RuntimeError>) {
    let session = load(path, suffix);
    let compiled = session.compile();
    let stderr = render(&compiled.diagnostics, session.files());
    let program = compiled
        .program
        .unwrap_or_else(|| panic!("unexpected errors:\n{stderr}"));
    let (sink, captured) = OutputSink::capture();
    // 入力のファイルはテストの隣に置く (docs/implementation/testing.md の「UI テスト」)
    let root = path
        .parent()
        .expect("a test file has a directory")
        .to_path_buf();
    let config = RunConfig::default()
        .with_debug_heap(true)
        .with_file_root(root.clone());
    let result = eml_cli::execute(&program, &config, sink);
    let stdout = captured.contents();
    check_on_vm(suffix, &program, &root, &stdout, &result);
    (stdout, stderr, result.map(|_| ()))
}

/// VM の検査モードで実行して CEK と比べ、一致したときだけ速いモードでも実行する。速いモードは前提を確かめないので、
/// VM の誤りが未定義の動作になって glob のテスト全体を壊しうるためである。
fn check_on_vm(
    suffix: &str,
    program: &eml_lir::Program,
    root: &Path,
    stdout: &str,
    cek: &Result<RunStats, RuntimeError>,
) {
    let run = |debug_heap| {
        let (host, out) = capture_host(root.to_path_buf());
        let result = execute_vm(program, debug_heap, host);
        (out.contents(), result)
    };
    let (vm_stdout, vm) = run(true);
    assert_eq!(vm_stdout, stdout, "{suffix}: the VM printed something else");
    match (cek, &vm) {
        (Ok(cek), Ok(vm)) => assert_same_counts(suffix, cek, vm),
        (Err(cek), Err(vm)) => assert_eq!(vm.to_string(), cek.to_string(), "{suffix}: the VM failed otherwise"),
        _ => panic!("{suffix}: the CEK gave {cek:?} but the VM gave {vm:?}"),
    }
    let (fast_stdout, fast) = run(false);
    assert_eq!(fast_stdout, stdout, "{suffix}: the fast VM printed something else");
    assert_eq!(
        fast.map(|_| ()).map_err(|error| error.to_string()),
        vm.map(|_| ()).map_err(|error| error.to_string()),
        "{suffix}: the fast VM ended otherwise"
    );
}

/// 同じ LIR の上で同じ定義を持つ6つの回数は、CEK と等しい。`rc_*` と `peak_objects` は、フレームと凍結した領域の
/// 数え方が違うので比べない (docs/spec/vm.md の「`RunStats`」)。
fn assert_same_counts(suffix: &str, cek: &RunStats, vm: &VmRunStats) {
    let pick_cek = (cek.evidence_steps, cek.yields, cek.yield_frames, cek.string_bytes_copied, cek.boxes, cek.unboxes);
    let pick_vm = (vm.evidence_steps, vm.yields, vm.yield_frames, vm.string_bytes_copied, vm.boxes, vm.unboxes);
    assert_eq!(pick_vm, pick_cek, "{suffix}: (evidence_steps, yields, yield_frames, string_bytes_copied, boxes, unboxes)");
}
```

```bash
# `$1` は `eml run` に足す引数 (空か `--vm`)。プログラムごとの命令の数の中央値を連想配列 `$2` に入れ、表を出す
measure() {
  local flag="$1"
  local -n result="$2"
  echo "| プログラム | instructions retired | 実時間 (s) |"
  echo "|---|---:|---:|"
  for file in "$root"/bench/*.em; do
    name="$(basename "$file" .em)"
    instructions=()
    seconds=()
    for _ in $(seq "$runs"); do
      # 実行時エラーで止まったら、捕まえた出力を見せて止める。表の値が欠けたまま記録しないためである
      if ! report="$( { /usr/bin/time -l "$eml" run $flag "$file" >/dev/null; } 2>&1 )"; then
        echo "bench/run.sh: $name ($flag) が失敗した" >&2
        echo "$report" >&2
        exit 1
      fi
      count="$(awk '/instructions retired/ { print $1 }' <<<"$report")"
      elapsed="$(awk '/ real / { print $1 }' <<<"$report")"
      if [[ ! "$count" =~ ^[0-9]+$ || ! "$elapsed" =~ ^[0-9]+\.[0-9]+$ ]]; then
        echo "bench/run.sh: $name の /usr/bin/time -l の出力から命令の数か実時間を読めなかった" >&2
        echo "$report" >&2
        exit 1
      fi
      instructions+=("$count")
      seconds+=("$elapsed")
    done
    result[$name]="$(median "${instructions[@]}")"
    echo "| \`$name\` | ${result[$name]} | $(median "${seconds[@]}") |"
  done
}

declare -A cek vm

echo

echo
echo "VM (S10a の間は \`eml run --vm\`)"

echo "|---|---:|---:|---:|"
for name in "${!cek[@]}"; do
  [[ "$name" == empty ]] && continue
  c=$(( ${cek[$name]} - ${cek[empty]} ))
  v=$(( ${vm[$name]} - ${vm[empty]} ))
  echo "| \`$name\` | $c | $v | $(awk "BEGIN { printf \"%.3f\", $v / $c }") |"
```
