# S11c-1 端末の REPL Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `eml repl` で、S11a の `eml_cli::Repl` を端末から使えるようにする。行の編集、複数行の入力 (`input_status` と `:{ … :}`)、`:quit` / `:help`、Ctrl-C で終わらない REPL 用の SIGINT のハンドラ、読みの中で待つプログラムの割り込み、実行の前の割り込みでの入力の取り消し、REPL の確保量の上限を入れる。

**Architecture:** `eml_syntax` は閉じていないブロックコメントで入力を続ける (Task 1)。`eml_rt` の `read_text` は、止める語が立った後の `EINTR` で読みを止める (Task 2)。`eml_cli` の lib に、行を入力にまとめる状態機械 `eml_cli::lines` (Task 3) と、`Outcome::Interrupted` と `repl_limits()` (Task 4) を足す。bin は `ctrlc` を自前の `sigaction` (`SA_RESTART` なし) に替え (Task 5)、`eml repl` の繰り返しを `rustyline` で組む (Task 6)。最後に決めたことを `docs/` に移す (Task 7)。

**Tech Stack:** Rust (edition 2024、stable 1.98.1)、`rustyline` 18.0.1 (`default-features = false`)、`libc` 0.2、Verus と vstd、Miri (`.#miri` の nightly)、`insta`。

**Spec:** `docs/superpowers/specs/2026-10-16-s11c1-terminal-design.md`

## Review Focus

spec が求めるが、各タスクの本来のテストだけでは確かめない入力のうち、利用者に効きやすいものを5つ挙げる。どれも、下の該当するタスクにテストを足してある。

1. **貼り付けた複数行**: 端末の bracketed paste では、1回の `readline` が `\n` を含む文字列を返す。空行で区切った定義と式は、別々の入力になるはずである。Task 3 の `pasted_text_is_split_into_lines`
2. **CRLF の入力**: Windows で作ったファイルをパイプで渡すと、行末に `\r` が残る。`\r` を除いて読めるはずである。Task 3 の `pasted_text_is_split_into_lines` と Task 6 の `repl_reads_crlf_input`
3. **UTF-8 でないパイプの入力**: 行を読めない誤りは、`error: cannot read input: …` を書き、`close` を呼んで 1 で終わるはずである (panic しない)。Task 6 の `repl_ends_with_one_on_unreadable_input`
4. **空行のない最後の定義**: パイプの入力が、空行を置かずに定義で終わっても評価し、その診断を見せるはずである。Task 6 の `repl_evaluates_an_unfinished_input_at_eof`
5. **検査モードの割り込みの後の `close`**: 読みの中で割り込んだ後も、検査モードの `close` はリークを報告せず、`:quit` は 0 で終わるはずである。Task 6 の `an_interrupt_stops_a_repl_input_waiting_in_a_read` を `--debug-heap` で流す

`} // verus!` の後 (`impl HostRef` の前) に足す。

```rust
/// 止める語が立った後の `Interrupted` を、`read_to_end` が読み直さない誤りに変える読み手 (docs/spec/object-model.md の
/// 「`File`」)。SIGINT のハンドラは `SA_RESTART` を外して入れるので、待っている読みは `EINTR` で戻る。止める語が
/// 立っていなければ `Interrupted` のまま返し、`read_to_end` に読み直させる。`read_buf` は stable では実装できないので、
/// `read_to_end` は空き領域を 0 で埋めてから読む。
struct StopOnInterrupt<'a> {
    reader: &'a mut (dyn BufRead + Send),
    control: &'a Control,
}

impl Read for StopOnInterrupt<'_> {
    fn read(&mut self, buf: &mut [u8]) -> io::Result<usize> {
        match self.reader.read(buf) {
            Err(e) if e.kind() == io::ErrorKind::Interrupted && self.control.stop_bits() != 0 => {
                Err(io::Error::other("stopped while reading"))
            }
            result => result,
        }
    }
}
```

````markdown
# REPL の端末

`eml repl` の端末の規則を定める。セッションの意味 (入力ごとのモジュール、名前の解決、受け付ける入力) は [モジュールと名前解決](modules.md) の「REPL のセッション」に、入力の終わりの判定は [レイアウト規則](layout.md) の「REPL の入力の終わり」に、入力の読み分けは [文法](grammar.md) の「REPL の入力」にある。

## コマンドライン

- `eml repl [--debug-heap]` でセッションを始める。`--debug-heap` は `eml run` と同じく検査モードにする
- import の根と Host の相対パスの基準は、`eml run` と同じくカレントディレクトリである
- 上限は `eml_cli::repl_limits()` が決める。深さは `eml run` と同じ 2^27 語で、確保量は物理メモリの 40% である。回復は写す間に古いヒープと写しを同時に持ち、写しは根から届く物体だけなので古いヒープより大きくならない。合わせて、`eml run` の上限と同じ 80% を目安に収める。どちらの上限も、安全点で止めるまでの間に少し超えうる目安である。物理メモリを読めない OS では上限を置かない

## 行の編集

- 標準入力が端末なら、`rustyline` で行を編集する。履歴はメモリだけに持ち、読んだ行ごとに足す。空の行と直前と同じ行は足さず、100 行まで持つ。標準出力をリダイレクトしても、プロンプトと編集の表示は端末に書く
- 標準入力が端末でなければ、1行ずつ読み、プロンプトは書かない
- 1回の読みが複数の行を返すことがある (端末の bracketed paste)。返った文字列を `\n` で行に分け、行末の `\r` を除いて、1行ずつ次の「行のまとめ方」に渡す
- `TERM` が `dumb` などの端末では、`rustyline` は行を編集せずに読む。このとき Ctrl-C は読みかけの入力を捨てない (下の「割り込み」)

## 行のまとめ方

- プロンプトは、入力の始めが `> `、入力の続きと `:{` の中が `. ` である
- 入力の終わりは、読んだ行を `\n` でつないだテキストで決める ([レイアウト規則](layout.md) の「REPL の入力の終わり」)。空行で終わった入力は、その空行を含めずに評価する
- 入力の始めの行が空白だけなら、何もせずに入力の始めのままにする。コメントだけの行は入力として評価する
- 入力の始めの行で、最初の空白でない文字が `:` なら、その行をコマンドとして読む。入力の続きの行と `:{` の中の行は、`:` で始まっても入力の本文である
- EOF では、読みかけの入力を評価してから終わる。終わっていない入力も評価して、その診断を見せる

## コマンド

コマンドの名前は、`:` の直後から最初の空白の前までの文字である。名前の後の空白でない文字が引数になる。

| コマンド | 動作 |
|---|---|
| `:quit` | セッションを終える |
| `:help` | コマンドの一覧と `:{ … :}` の使い方を標準出力に書く |
| `:{` | 次の行から、前後の空白を除くと `:}` だけになる行の前までを、1つの入力にする。空行も入力に含め、入力の終わりの判定はしない。本文が空白だけなら何もしない |

- `:quit` と `:help` は、表の名前の接頭辞で書ける。GHCi と同じく、表の順に見て最初に接頭辞が合う名前を選ぶ (`:q` は `:quit`)。表の順は `quit`、`help` である
- `{` と `}` は接頭辞で引かない。`:{` が引数を持てば誤りにする。入力の始めの `:}` は誤り (`':}' without ':{'`) である
- 名前が空なら誤り (`missing command name`)、合う名前がなければ誤り (`unknown command ':foo'`)、引数を取らないコマンドに引数があれば誤り (`':quit' takes no argument`) である。誤りは標準エラーに書き、何も評価しない
- `:{` の中で EOF になったら、`missing ':}'` を標準エラーに書き、何も評価しない

## 結果の表示

| 入力の結果 (`Outcome`) | 表示 |
|---|---|
| 診断 | 標準エラーに書く。`Repl::eval` は実行の後で診断を返すので、その入力で初めて読んだファイルの警告は、入力の出力の後に出る |
| `Empty`、`Accepted`、`Rejected` | 診断のほかに書くものはない。式の値は VM が標準出力に書く |
| `Failed` | 割り込みで止まったなら `interrupted`、ほかは `runtime error: {error}` を標準エラーに書く。位置があれば `  at path:line:column` が続く |
| `Interrupted` | 標準エラーに `interrupted` を書く |
| `Broken` | 標準エラーに `runtime error: {error}` を書き、`close` を呼ばずに終了コード 1 で終わる。後の入力はどれも実行できないためである |

- 割り込みは、止まった所によらず `interrupted` と書く。VM の中で止まったときの関数の名前 (`entry$` や `f@[Int]`) は、利用者が書いた名前でないので見せない
- VM は実行の終わりに、誤りのときも出力を書き出す。そのため、入力の出力は次のプロンプトより前に見える

## 終わり方

- `:quit` と、入力の始めでの EOF (端末では空の行での Ctrl-D) で終わる。入力の途中の EOF では、読みかけの入力を処理してから終わる
- 終わるときは `Repl::close` を呼ぶ。終了コードは 0 である。`close` が誤りを返したら (検査モードのリーク、根を手放すときの誤り)、標準エラーに `runtime error: {error}` を書いて 1 で終わる
- 入力の誤り、実行時エラー、コマンドの誤りでは終了コードを変えない。対話の中の誤りだからである
- 行を読めない誤り (端末の誤り、UTF-8 でない入力) では、標準エラーに `error: cannot read input: {error}` を書き、`close` を呼んで 1 で終わる
- 使い方の誤りは 2 である ([アーキテクチャ](../implementation/architecture.md) の「CLI と lib API」)

## 割り込み

REPL は Ctrl-C で終わらない ([VM](vm.md) の「上限と割り込み」の REPL の動き方)。Ctrl-C の扱いは unix だけのもので、ほかの OS ではハンドラを入れず、Ctrl-C は OS の既定の動作でプロセスを終わらせる。

- 行を編集する間の Ctrl-C は、読みかけの入力と `:{` の状態を捨て、入力の始めに戻す。端末を raw にする間に来た SIGINT で読みが `EINTR` で戻ったときも同じである
- 前端の検査に誤りのない入力は、実行を始める前 (lowering の後、`Machine::load` の前) に止める語を読む。割り込みが立っていれば、入力の種類によらず受け付けず、`Interrupted` にする ([モジュールと名前解決](modules.md) の「REPL のセッション」)。VM は入口では安全点を通らないので、ここで止めないと、入口から最初の呼び出しまでの extern と `root_set` が動くためである
- 実行の間の割り込みは、VM の安全点か `Fs.read_all` の中で止まり、`Failed` になる。待っている読みも、ハンドラが `SA_RESTART` を外して入れるので止まる ([オブジェクトモデル](object-model.md) の「`File`」)。最後の安全点の後に来た割り込みでは、入力は終わりまで動き、`let` の束縛もできる
- 入力を待つ間と、行を読み終えてから次の入力の始めまでに来た割り込みは、次の入力の始めの `Control::clear` が捨てる

### 残る制限

次の処理からは Ctrl-C で抜けられない。`eml run` は2回目の Ctrl-C で抜けられるが、REPL は終わらないためである。抜けるには、Ctrl-\ (SIGQUIT。既定の動作でプロセスを終わらせる) か `kill` を使う。

1. 前端の検査と回復。どちらも有限の時間で終わるので、終わるのを待つ。検査の間の割り込みは、上のとおり入力を取り消す
2. import で読むファイルが FIFO か遅いファイルのとき。std の読みが `EINTR` で読み直すためである
3. 書き手のいない FIFO を開く `Fs.open`。std の `File::open` が `EINTR` で開き直すためである。止めるには `O_NONBLOCK` で開いてから `fcntl` で戻す必要があり、`eml_rt` に `libc` の依存が要る
4. 詰まった標準出力への書き込み (`eml repl | less` で `less` を止めたときなど)。std の `write_all` が `EINTR` で書き直すためである
5. SIGINT が、止める語を見た後で `read` のシステムコールに入る前に届くと、`read` は待ち続ける。次の SIGINT の `EINTR` で止まる。防ぐには `ppoll` か self-pipe が要る
````

```rust
//! 端末の行を、REPL の入力とコマンドにまとめる (docs/spec/repl.md の「行のまとめ方」と「コマンド」)。端末に依存しない
//! 状態機械にして、行の並びを渡すだけでテストできるようにする。

use eml_syntax::{InputStatus, input_status};

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Step {
    /// 次の行を `prompt()` で読む。
    Read,
    /// 入力が終わった。`Repl::eval` に渡す。
    Eval(String),
    Command(Command),
    /// 入力の誤り。標準エラーに書き、何も評価しない。
    Error(String),
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Command {
    Quit,
    Help,
}

/// 名前の接頭辞で引くので、表の順が省略の選び方になる (docs/spec/repl.md の「コマンド」)。
const COMMANDS: &[(&str, Command)] = &[("quit", Command::Quit), ("help", Command::Help)];

#[derive(Debug, Default)]
pub struct Lines {
    /// 読みかけの入力の行。
    pending: Vec<String>,
    /// `:{` の中か。
    block: bool,
}

impl Lines {
    pub fn new() -> Lines {
        Lines::default()
    }

    /// 1行を渡す。`line` は `\n` を含まない。
    pub fn push(&mut self, line: &str) -> Step {
        if self.block {
            if line.trim() == ":}" {
                self.block = false;
                return match self.finish() {
                    Some(text) if !text.trim().is_empty() => Step::Eval(text),
                    _ => Step::Read,
                };
            }
            self.pending.push(line.to_string());
            return Step::Read;
        }
        if self.pending.is_empty() {
            let line = line.trim_start();
            if line.is_empty() {
                return Step::Read;
            }
            if let Some(command) = line.strip_prefix(':') {
                return self.command(command);
            }
        }
        self.pending.push(line.to_string());
        match input_status(&self.pending.join("\n")) {
            InputStatus::Incomplete => Step::Read,
            InputStatus::Complete => Step::Eval(self.finish().unwrap_or_default()),
        }
    }

    /// 1回の読みが返した文字列を行に分けて渡す。端末の bracketed paste は、貼り付けた複数行を1つの文字列で返す。
    /// `Lines` の状態は評価の結果によらないので、先にすべての行を渡してよい。
    pub fn push_text(&mut self, text: &str) -> Vec<Step> {
        text.split('\n')
            .map(|line| self.push(line.strip_suffix('\r').unwrap_or(line)))
            .collect()
    }

    /// Ctrl-C。読みかけの入力と `:{` の状態を捨てる。
    pub fn interrupt(&mut self) {
        self.pending.clear();
        self.block = false;
    }

    /// EOF。読みかけの入力がなければ `None` を返す。
    pub fn end(&mut self) -> Option<Step> {
        if std::mem::take(&mut self.block) {
            self.pending.clear();
            return Some(Step::Error("missing ':}'".to_string()));
        }
        self.finish().map(Step::Eval)
    }

    pub fn prompt(&self) -> &'static str {
        if self.block || !self.pending.is_empty() {
            ". "
        } else {
            "> "
        }
    }

    /// 読みかけの入力を取り出す。空行で終わった入力は、その空行を含めない (docs/spec/layout.md の
    /// 「REPL の入力の終わり」)。
    fn finish(&mut self) -> Option<String> {
        let mut lines = std::mem::take(&mut self.pending);
        if lines.len() > 1 && lines.last().is_some_and(|line| line.trim().is_empty()) {
            lines.pop();
        }
        (!lines.is_empty()).then(|| lines.join("\n"))
    }

    /// `:` の後ろを読む。名前は最初の空白の前までである。
    fn command(&mut self, rest: &str) -> Step {
        let (name, argument) = match rest.find(char::is_whitespace) {
            Some(at) => (&rest[..at], rest[at..].trim()),
            None => (rest, ""),
        };
        match name {
            "" => Step::Error("missing command name".to_string()),
            "{" if argument.is_empty() => {
                self.block = true;
                Step::Read
            }
            "{" => Step::Error("':{' takes no argument".to_string()),
            "}" => Step::Error("':}' without ':{'".to_string()),
            _ => match COMMANDS.iter().find(|(full, _)| full.starts_with(name)) {
                None => Step::Error(format!("unknown command ':{name}'")),
                Some((full, _)) if !argument.is_empty() => {
                    Step::Error(format!("':{full}' takes no argument"))
                }
                Some((_, command)) => Step::Command(*command),
            },
        }
    }
}
```

`:{` の中の空行で終わる本文 (`:{`、`1`、``、`:}`) は、`finish` が最後の空行を除く。ブロックの本文の空行は入力に含めるが、最後の空行を除いても評価は変わらない。

//! SIGINT のハンドラ (docs/spec/vm.md の「上限と割り込み」)。unix だけで入れる。`SA_RESTART` を外すので、待っている
//! 読みは `EINTR` で戻り、`Fs.read_all` が止める語を読んで止まる (docs/spec/object-model.md の「`File`」)。

use std::io;
use std::sync::atomic::{AtomicBool, Ordering};
use std::sync::{Arc, OnceLock};

use eml_cli::Control;

/// ハンドラが読む `Control`。ハンドラの中ではロックを取れないので static に置く。`OnceLock::get` は初期化の後は
/// アトミックな読みだけである。
static CONTROL: OnceLock<Arc<Control>> = OnceLock::new();
/// 止める語が立った後の SIGINT でプロセスを終わらせるか。
static EXIT_ON_REPEAT: AtomicBool = AtomicBool::new(false);

pub enum Mode {
    /// 2回目の SIGINT でその場で終わる。安全点に来ない処理から抜ける道である。
    Run,
    /// SIGINT で終わらない。抜けられない処理からは Ctrl-\ で抜ける (docs/spec/repl.md の「残る制限」)。
    Repl,
}

/// `Control` と動き方を static に置いてから、ハンドラを入れる。逆の順だと、間に来た SIGINT が `Control` を見つけられ
/// ずに捨てられる。
pub fn install(control: Arc<Control>, mode: Mode) {
    EXIT_ON_REPEAT.store(matches!(mode, Mode::Run), Ordering::Relaxed);
    assert!(
        CONTROL.set(control).is_ok(),
        "the SIGINT handler is installed once per process"
    );
    // 入れられなくてもプログラムは実行できる。その場合 Ctrl-C は既定の動作でプロセスを終わらせる
    if let Err(error) = sigaction() {
        eprintln!("warning: cannot install the SIGINT handler: {error}");
    }
}

fn sigaction() -> io::Result<()> {
    // `SA_RESTART` を入れないので、ハンドラの後で待っている読みが `EINTR` で戻る。`SA_NODEFER` を入れないので、
    // ハンドラが動く間は同じ SIGINT が塞がれ、`on_sigint` が止める語を読んでから終わるかを決める間に入れ子にならない
    let handler: extern "C" fn(libc::c_int) = on_sigint;
    // `sigaction` は構造体と空の集合のほかに前提を持たない
    let result = unsafe {
        let mut action: libc::sigaction = std::mem::zeroed();
        action.sa_sigaction = handler as libc::sighandler_t;
        action.sa_flags = 0;
        libc::sigemptyset(&mut action.sa_mask);
        libc::sigaction(libc::SIGINT, &action, std::ptr::null_mut())
    };
    if result == 0 {
        Ok(())
    } else {
        Err(io::Error::last_os_error())
    }
}

/// async-signal-safe なことだけをする。アトミックな読み書きと `_exit` で、`errno` を変える関数は呼ばない。
extern "C" fn on_sigint(_: libc::c_int) {
    let Some(control) = CONTROL.get() else {
        return;
    };
    if EXIT_ON_REPEAT.load(Ordering::Relaxed) && control.stop_bits() & Control::INTERRUPT != 0 {
        // まだ書いていない出力は捨てる (docs/spec/vm.md の「上限と割り込み」)
        unsafe { libc::_exit(130) }
    }
    control.interrupt();
}

mod interrupts {
    use std::io::{BufRead, BufReader, Read, Write};
    use std::os::unix::ffi::OsStrExt;
    use std::os::unix::fs::OpenOptionsExt;
    use std::path::Path;
    use std::process::{Child, ChildStdin, Command, Stdio};
    use std::sync::mpsc::{Receiver, channel};
    use std::time::{Duration, Instant};

    use crate::cli::{DEADLINE, kill_after_deadline, sigint};
    use crate::common::temp_project;

    /// 標準入力を開いたまま、入力を1つずつ送る `eml repl`。標準出力と標準エラーは別のスレッドで行ごとに読み続ける。
    /// パイプが詰まると子が書き込みの中で止まり、安全点に来ないためである。
    struct LiveRepl {
        child: Child,
        stdin: ChildStdin,
        out: Receiver<String>,
        err: Receiver<String>,
        deadline: Instant,
    }

    fn lines_of(stream: impl Read + Send + 'static) -> Receiver<String> {
        let (send, receive) = channel();
        std::thread::spawn(move || {
            for line in BufReader::new(stream).lines() {
                let Ok(line) = line else { break };
                if send.send(line).is_err() {
                    break;
                }
            }
        });
        receive
    }

    impl LiveRepl {
        /// 最初に `"ready"` を評価し、その表示を待つ。ハンドラを入れる前の SIGINT は既定の動作でプロセスを終わらせる
        /// ので、SIGINT は表示が出てから送る。
        fn start(dir: &Path, args: &[&str]) -> LiveRepl {
            let mut child = Command::new(env!("CARGO_BIN_EXE_eml"))
                .arg("repl")
                .args(args)
                .current_dir(dir)
                .stdin(Stdio::piped())
                .stdout(Stdio::piped())
                .stderr(Stdio::piped())
                .spawn()
                .unwrap();
            let stdin = child.stdin.take().unwrap();
            let out = lines_of(child.stdout.take().unwrap());
            let err = lines_of(child.stderr.take().unwrap());
            let mut repl = LiveRepl {
                child,
                stdin,
                out,
                err,
                deadline: Instant::now() + DEADLINE,
            };
            repl.send("\"ready\"");
            repl.expect_out("\"ready\"");
            repl
        }

        fn send(&mut self, input: &str) {
            writeln!(self.stdin, "{input}").unwrap();
            self.stdin.flush().unwrap();
        }

        /// `line` が標準出力に出るまで待つ。
        fn expect_out(&mut self, line: &str) {
            loop {
                let left = self.deadline.saturating_duration_since(Instant::now());
                match self.out.recv_timeout(left) {
                    Ok(got) if got == line => return,
                    Ok(_) => {}
                    Err(_) => kill_after_deadline(&mut self.child, &format!("`{line}` did not arrive")),
                }
            }
        }

        /// 標準エラーに `interrupted` が出るまで、100 ms ごとに SIGINT を送る。続けて届いた SIGINT は1つにまとまる
        /// ことがあり、読みに入る直前に届いた SIGINT は読みを止めない (docs/spec/repl.md の「残る制限」) ので、
        /// 送り続ける。REPL は SIGINT で終わらないので、何回送ってもよい。最後に送った SIGINT が、次の入力の始めの
        /// `clear` の後に届くと次の入力を止めるので、出た後に少し待つ。
        fn interrupt_until_reported(&mut self) {
            loop {
                sigint(&self.child);
                match self.err.recv_timeout(Duration::from_millis(100)) {
                    Ok(line) if line == "interrupted" => break,
                    _ if Instant::now() >= self.deadline => {
                        kill_after_deadline(&mut self.child, "the input was not interrupted")
                    }
                    _ => {}
                }
            }
            std::thread::sleep(Duration::from_millis(200));
        }

        /// `:quit` を送り、終了コードを返す。
        fn quit(mut self) -> Option<i32> {
            self.send(":quit");
            loop {
                if let Some(status) = self.child.try_wait().unwrap() {
                    return status.code();
                }
                if Instant::now() >= self.deadline {
                    kill_after_deadline(&mut self.child, "the session did not end");
                }
                std::thread::sleep(Duration::from_millis(10));
            }
        }
    }

    /// 出力し続ける入力を SIGINT で止めた後も、セッションは続く。
    #[test]
    fn an_interrupt_stops_a_repl_input_and_the_session_continues() {
        let dir = temp_project("cli-repl-sigint-loop", &[]);
        let mut repl = LiveRepl::start(&dir, &[]);
        // 定義を受け付けた後で SIGINT を送るので、定義が取り消されることはない
        repl.send("spin : Int -> <IO> Unit\nspin n =\n  println (show n)\n  spin (n + 1)\n\n\"defined\"");
        repl.expect_out("\"defined\"");
        repl.send("spin 0");
        repl.interrupt_until_reported();
        repl.send("\"after\"");
        repl.expect_out("\"after\"");
        let code = repl.quit();

        assert_eq!(code, Some(0));
    }

    /// 後の `close` がリークを報告しないことも確かめる (Review Focus 5)。

//! `eml repl` の繰り返し (docs/spec/repl.md)。ここは行を読み、結果を表示するだけで、行を入力にまとめるのは
//! `eml_cli::lines`、入力を評価するのは `eml_cli::Repl` である。

use std::io::{self, BufRead, IsTerminal, StdinLock};
use std::path::{Path, PathBuf};
use std::process::ExitCode;
use std::sync::Arc;

use eml_cli::lines::{Command, Lines, Step};
use eml_cli::{Control, FsProvider, Outcome, Repl, RunConfig, repl_limits, stdio_host};
use eml_diagnostics::render;
use rustyline::error::ReadlineError;
use rustyline::{Behavior, Config, DefaultEditor};

const HELP: &str = "\
Commands:
  :quit    end the session
  :help    show this list
  :{       start an input of several lines, blank lines included; a line `:}` ends it
A command may be shortened to any prefix of its name (`:q`).";

pub fn run(debug_heap: bool) -> ExitCode {
    let control = Arc::new(Control::new(repl_limits()));
    #[cfg(unix)]
    crate::sigint::install(Arc::clone(&control), crate::sigint::Mode::Repl);
    let config = RunConfig::default()
        .with_debug_heap(debug_heap)
        .with_control(control);
    // import の根と Host の相対パスは、`eml run` と同じくカレントディレクトリを基準にする
    let mut repl = Repl::new(
        &config,
        Box::new(FsProvider::new(Path::new(""))),
        "",
        stdio_host(PathBuf::new()),
    );
    let mut reader = match Reader::new() {
        Ok(reader) => reader,
        Err(error) => {
            eprintln!("error: cannot read input: {error}");
            return close(repl, ExitCode::from(1));
        }
    };
    let mut lines = Lines::new();
    loop {
        let flow = match reader.read(lines.prompt()) {
            Read::Line(text) => steps(&mut repl, lines.push_text(&text)),
            Read::Interrupted => {
                lines.interrupt();
                Flow::Continue
            }
            Read::Eof => match steps(&mut repl, lines.end()) {
                Flow::Continue => Flow::Quit,
                flow => flow,
            },
            Read::Failed(error) => {
                eprintln!("error: cannot read input: {error}");
                return close(repl, ExitCode::from(1));
            }
        };
        match flow {
            Flow::Continue => {}
            Flow::Quit => return close(repl, ExitCode::SUCCESS),
            // 続けられない誤りの後はヒープを信用できないので、`close` を呼ばない (docs/spec/repl.md の「結果の表示」)
            Flow::Broken => return ExitCode::from(1),
        }
    }
}

enum Flow {
    Continue,
    Quit,
    Broken,
}

/// 結果を順に処理する。`:quit` か続けられない誤りで止まれば、残りは捨てる。
fn steps(repl: &mut Repl, steps: impl IntoIterator<Item = Step>) -> Flow {
    for step in steps {
        let flow = match step {
            Step::Read => Flow::Continue,
            Step::Eval(text) => eval(repl, &text),
            Step::Command(Command::Quit) => Flow::Quit,
            Step::Command(Command::Help) => {
                println!("{HELP}");
                Flow::Continue
            }
            Step::Error(message) => {
                eprintln!("{message}");
                Flow::Continue
            }
        };
        if !matches!(flow, Flow::Continue) {
            return flow;
        }
    }
    Flow::Continue
}

fn eval(repl: &mut Repl, text: &str) -> Flow {
    let evaluated = repl.eval(text);
    eprint!("{}", render(&evaluated.diagnostics, &evaluated.files));
    match evaluated.outcome {
        Outcome::Empty | Outcome::Accepted | Outcome::Rejected => {}
        // 止まった所の関数の名前は利用者が書いた名前でないので、割り込みは場所を書かない (docs/spec/repl.md の
        // 「結果の表示」)
        Outcome::Interrupted => eprintln!("interrupted"),
        Outcome::Failed(error) if error.interrupted() => eprintln!("interrupted"),
        Outcome::Failed(error) => eprintln!("runtime error: {error}"),
        Outcome::Broken(error) => {
            eprintln!("runtime error: {error}");
            return Flow::Broken;
        }
    }
    Flow::Continue
}

/// 根を手放して終わる。検査モードのリークは 1 で終わらせる。
fn close(repl: Repl, code: ExitCode) -> ExitCode {
    match repl.close().leaks {
        None => code,
        Some(error) => {
            eprintln!("runtime error: {error}");
            ExitCode::from(1)
        }
    }
}

enum Reader {
    Edited(DefaultEditor),
    Piped(StdinLock<'static>),
}

enum Read {
    Line(String),
    Interrupted,
    Eof,
    Failed(String),
}

impl Reader {
    /// 標準入力が端末でなければ `rustyline` を使わない。`TERM` が `dumb` などのとき、`rustyline` はパイプからの読み
    /// でもプロンプトを書くためである (docs/spec/repl.md の「行の編集」)。
    fn new() -> rustyline::Result<Reader> {
        if !io::stdin().is_terminal() {
            return Ok(Reader::Piped(io::stdin().lock()));
        }
        let config = Config::builder().behavior(Behavior::PreferTerm).build();
        Ok(Reader::Edited(DefaultEditor::with_config(config)?))
    }

    fn read(&mut self, prompt: &str) -> Read {
        match self {
            // std の `read_line` は `EINTR` で読み直す。待つ間の SIGINT が立てた止める語は、次の入力の始めに下りる
            Reader::Piped(stdin) => {
                let mut line = String::new();
                match stdin.read_line(&mut line) {
                    Ok(0) => Read::Eof,
                    Ok(_) => {
                        if line.ends_with('\n') {
                            line.pop();
                        }
                        Read::Line(line)
                    }
                    Err(error) => Read::Failed(error.to_string()),
                }
            }
            Reader::Edited(editor) => match editor.readline(prompt) {
                Ok(line) => {
                    // 履歴に足せなくても、行は読めている
                    let _ = editor.add_history_entry(line.as_str());
                    Read::Line(line)
                }
                Err(ReadlineError::Eof) => Read::Eof,
                Err(error) if interrupted(&error) => Read::Interrupted,
                Err(error) => Read::Failed(error.to_string()),
            },
        }
    }
}

/// 編集中の Ctrl-C のほかに、`EINTR` で戻った誤りも Ctrl-C と同じに扱う。`rustyline` は端末を raw にする `tcsetattr`
/// を ISIG が立ったまま呼ぶので、その間の SIGINT で `EINTR` が返りうる。REPL は Ctrl-C で終わらない
/// (docs/spec/repl.md の「割り込み」)。
fn interrupted(error: &ReadlineError) -> bool {
    match error {
        ReadlineError::Interrupted | ReadlineError::Signal(_) => true,
        ReadlineError::Io(error) => error.kind() == io::ErrorKind::Interrupted,
        #[cfg(unix)]
        ReadlineError::Errno(errno) => *errno as i32 == libc::EINTR,
        _ => false,
    }
}
