# S11c-2 `:load` / `:reload` / `:type` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `eml repl` に `:load` / `:reload` / `:type` と `eml repl [file]` を足す。`:load` はセッションを作り直してファイルを入力 1 として読み、`:type` は式の型を、残った型変数に名前を付けて文脈とともに書く。

**Architecture:** `eml_syntax` に問い合わせの入口 `parse_query` (根 `REPL_QUERY`) を足す (Task 1)。`eml_hir` の `SessionInput` に読み方 `InputForm` (`Typed` / `File` / `Query`) を足し、`load_session` が入口のファイル名を受け、問い合わせを `InputKind::Query` の入力の関数にする (Task 2)。`eml_types` は問い合わせの入力を defaulting せずに検査し、残った制約を文脈にして、名前を付けた型の文字列を `TypedProgram::query` に入れる (Task 3)。`eml_cli::Repl` に `with_file` と `type_of` を足す (Task 4)。`eml_cli::lines` のコマンドの表を広げ (Task 5)、端末と `main.rs` で `:load` / `:reload` / `:type` と `file` の引数を扱う (Task 6)。トランスクリプトの harness がコマンドの行を読めるようにし (Task 7)、最後に残りの文書を直す (Task 8)。

**Tech Stack:** Rust (edition 2024、stable 1.98.1)、`rowan`、`insta`、`clap`。新しい依存はない。

```rust
/// `:type` の問い合わせを読む。入力の読み分けをせず、式をちょうど1つ読む。`f x = 1` も式として読み始めるので、
/// `=` で誤りになる (docs/spec/grammar.md の「REPL の入力」)。
pub(crate) fn repl_query(p: &mut Parser) {
    let m = p.start();
    if !expressions::expr(p) {
        expected(p, "an expression");
    }
    while p.at_sep() || p.at(LAYOUT_CLOSE) {
        p.bump_any();
    }
    if !p.at_eof() {
        p.error(
            codes::SYNTAX_ERROR,
            "':type' takes one expression",
            "the expression ends before this",
        );
        let rest = p.start();
        while !p.at_eof() {
            p.bump_any();
        }
        rest.complete(p, ERROR);
    }
    m.complete(p, REPL_QUERY);
}
```

```rust
/// 読み方を選んだ入力でセッションを読み、def_map と lower を流す。診断は `パス 行:列 番号 メッセージ` の行にする。
fn lower_forms(
    inputs: &[SessionInput],
    root: &str,
    entry_file: &str,
    modules: &[(&str, &str)],
) -> (Loaded, Program, Vec<String>) {
    let (loaded, mut diagnostics, _) = eml_hir::load_session(
        eml_hir::STD,
        inputs,
        root,
        entry_file,
        &MemorySource(modules),
        &ImportCache::default(),
    );
    let (def_map, found) = eml_hir::def_map(&loaded.modules);
    diagnostics.extend(found);
    let (program, found) = eml_hir::lower(&def_map, &loaded.modules);
    diagnostics.extend(found);
    sort_diagnostics(&mut diagnostics);
    let lines = diagnostics
        .iter()
        .map(|d| format!("{} {} {}", located(&loaded.files, &d.primary), d.code, d.message))
        .collect();
    (loaded, program, lines)
}

/// `:load` のファイルはファイルの文法で読み、表示のパスはファイルのパスである。モジュールの名前は `<input 1>` のまま

#[test]
fn a_file_input_is_read_as_a_file_under_its_path() {
    // `f x = 1` の形の等式は、入力の入口では先読みの規則が違うが、ファイルの文法なら item である
    let file = "pub inc : Int -> Int\ninc x = x + 1\n\nhidden : Int\nhidden = 2\n";
    let inputs = [
        SessionInput { number: 1, text: file, form: InputForm::File { path: "app/main.em" } },
        SessionInput { number: 2, text: "inc hidden", form: InputForm::Typed },
    ];
    let (loaded, program, diagnostics) = lower_forms(&inputs, "app/", "main.em", &[]);
    assert_eq!(diagnostics, Vec::<String>::new());
    let module = module_named(&loaded, "<input 1>");
    assert_eq!(loaded.files.path(program.file(module)), "app/main.em");
    assert_eq!(loaded.modules[index(module)].origin, ModuleOrigin::Session(1));
}
```

```rust
    /// ほかの型変数は式の入力と同じく `Unit` とみなし、構造的なクラスなら解けたとし、そうでなければ E2009 にする。

    pub(super) fn split_residuals(
        &mut self,
        residuals: Vec<Residual>,
        shown: &HashSet<Ty>,
    ) -> Vec<(ClassId, Ty)> {
        let mut context = Vec::new();
        let mut found = Vec::new();
        for residual in residuals {
            let mut failed = None;
            for &(class, var) in &residual.left {
                if shown.contains(&self.table.resolve(var)) {
                    context.push((class, var));
                } else if !structural(self.program, class) {
                    failed.get_or_insert(Failure::Ambiguous { root: (class, var), class });
                }
            }
            match failed {
                Some(failure) => found.push((residual.expr, residual.decl, failure)),
                None => self.bound_resolved(residual.expr, residual.decl, &residual.resolved),
            }
        }
        let diagnostics: Vec<Diagnostic> = found
            .into_iter()
            .filter_map(|(expr, decl, failure)| self.constraint_error(expr, decl, failure))
            .collect();
        self.diagnostics.extend(diagnostics);
        context
    }
```

```rust
//! `:type` の問い合わせの型を書く (docs/spec/types.md の「REPL の入力」)。

use std::collections::HashSet;

use eml_hir::{ClassId, Program};

use crate::store::TypeStore;
use crate::table::{Exporter, RowVar, Table, Tail, Ty, TyShape, VarNames};

/// 型を書く順 (矢印は引数、row のラベルの型引数、row の変数、結果) にたどった、型変数の代表と row 変数の現れ。
/// 書いた型の木の上で数えるので、共有した部分は現れるたびに数える。数える費用は書く文字列の長さに比例する。
struct Occurrences {
    types: Vec<Ty>,
    rows: Vec<(RowVar, usize)>,
}

fn occurrences(table: &Table<'_>, ty: Ty) -> Occurrences {
    let mut found = Occurrences { types: Vec::new(), rows: Vec::new() };
    walk(table, ty, &mut found);
    found
}

fn walk(table: &Table<'_>, ty: Ty, found: &mut Occurrences) {
    let ty = table.resolve(ty);
    match table.shape(ty) {
        TyShape::Var(_) => {
            if !found.types.contains(&ty) {
                found.types.push(ty);
            }
        }
        TyShape::Con(_, args) => args.iter().for_each(|&arg| walk(table, arg, found)),
        TyShape::Tuple(elements) => elements.iter().for_each(|&element| walk(table, element, found)),
        TyShape::Fn { param, row, ret, .. } => {
            walk(table, *param, found);
            let row = table.resolve_row(row);
            for label in &row.labels {
                label.args.iter().for_each(|&arg| walk(table, arg, found));
            }
            if let Tail::Var(var) = row.tail {
                match found.rows.iter_mut().find(|(seen, _)| *seen == var) {
                    Some((_, count)) => *count += 1,
                    None => found.rows.push((var, 1)),
                }
            }
            walk(table, *ret, found);
        }
        TyShape::Rigid(_) | TyShape::Error => {}
    }
}

/// 書く型に現れる型変数の代表。問い合わせの残りの制約を、文脈と `Unit` に分けるのに使う。
pub(super) fn shown_vars(table: &Table<'_>, ty: Ty) -> HashSet<Ty> {
    occurrences(table, ty).types.into_iter().collect()
}

/// `a`、`b`、`c`、`d`、`f`、…、`z`、`a1`、`b1`、…。`e` で始まる名前は row 変数のために使わない。
fn type_var_name(index: usize) -> String {
    const LETTERS: &[u8] = b"abcdfghijklmnopqrstuvwxyz";
    let letter = LETTERS[index % LETTERS.len()] as char;
    match index / LETTERS.len() {
        0 => letter.to_string(),
        round => format!("{letter}{round}"),
    }
}

fn row_var_name(index: usize) -> String {
    match index {
        0 => "e".to_string(),
        _ => format!("e{index}"),
    }
}

/// 問い合わせの型 `ty` と文脈 `context` (型変数への制約) を、`Show a => a -> String` の形に書く。
pub(super) fn render(
    program: &Program,
    table: &Table<'_>,
    ty: Ty,
    context: &[(ClassId, Ty)],
) -> String {
    let found = occurrences(table, ty);
    let mut names = VarNames::default();
    for (index, &var) in found.types.iter().enumerate() {
        names.types.insert(var, type_var_name(index));
    }
    // 1回だけ現れる row 変数は閉じた row として書く
    for (index, &(var, _)) in found.rows.iter().filter(|(_, count)| *count > 1).enumerate() {
        names.rows.insert(var, row_var_name(index));
    }
    let mut types = TypeStore::new(program);
    let id = Exporter::named(table, &mut types, &names).export(ty);
    let shown = types.display(id, &program.names).to_string();
    let constraints = context_text(program, table, &found.types, &names, context);
    match constraints.as_slice() {
        [] => shown,
        [one] => format!("{one} => {shown}"),
        many => format!("({}) => {shown}", many.join(", ")),
    }
}

/// 文脈の制約を、型変数が現れた順、クラスの表示の名前の順 (同じなら定義の順) に並べる。同じ制約と、ほかの制約の上位
/// クラスでたどれる制約は書かない。
fn context_text(
    program: &Program,
    table: &Table<'_>,
    order: &[Ty],
    names: &VarNames,
    context: &[(ClassId, Ty)],
) -> Vec<String> {
    let mut pairs: Vec<(ClassId, Ty)> = context
        .iter()
        .map(|&(class, var)| (class, table.resolve(var)))
        .collect();
    pairs.sort_by_key(|&(class, var)| (var, class));
    pairs.dedup();
    let implied = |&(class, var): &(ClassId, Ty)| {
        pairs.iter().any(|&(other, other_var)| {
            other_var == var && other != class && program.superclasses(other).contains(&class)
        })
    };
    let mut kept: Vec<(usize, String, ClassId, Ty)> = pairs
        .iter()
        .filter(|pair| !implied(pair))
        .map(|&(class, var)| {
            let position = order.iter().position(|&seen| seen == var).unwrap_or(usize::MAX);
            (position, program.names.class(class).to_string(), class, var)
        })
        .collect();
    kept.sort_by(|a, b| (a.0, &a.1, a.2).cmp(&(b.0, &b.1, b.2)));
    kept.into_iter()
        .map(|(_, class, _, var)| format!("{class} {}", names.types[&var]))
        .collect()
}
```

`Ty`、`ClassId` が `Ord` でなければ、並べる鍵を `(u32 の番号, …)` に替える (`Ty` は `ty.0`、`ClassId` は `into_raw`)。`table` の型と関数 (`Tail`、`RowVar`、`resolve_row`、`shape`) が `check` から見えなければ、`pub(crate)` の再公開を足す。`program.names.class` の戻り値が `Display` でなければ、既存の `constraint_error` の書き方に合わせる。

```rust
    /// 進めない。番号は次の入力の番号を使う。問い合わせは `CodeBase` に入らないので、同じ番号の `input$N` と食い違わない。
    /// 続けられない誤りの後のセッションでも検査する。前端だけを使い、ヒープに触れないためである
    /// (docs/spec/repl.md の「型の表示」)。
    pub fn type_of(&self, text: &str) -> Typed {

        self.control.clear();
        let mut inputs = self.session_inputs();
        inputs.push(SessionInput {
            number: self.next_input,
            text,
            form: InputForm::Query,
        });
        let (session, _) = Session::load_session(
            &inputs,
            &self.root,
            self.entry_file(),
            &*self.source,
            &self.cache,
        );

        // 線形性、網羅性、E2012 は型の文字列を作った後で報告するので、診断で決める
        let ty = if has_errors(&diagnostics) {
            None
        } else {
            checked.typed.query
        };
        Typed {
            diagnostics,
            files: session.into_files(),
            ty,
        }
    }
```

```rust
/// 行を送り、出力を待ってからファイルを書き換えるための子のプロセス。
struct Session {
    child: std::process::Child,
    stdin: std::process::ChildStdin,
    stdout: std::io::BufReader<std::process::ChildStdout>,
    stderr: std::io::BufReader<std::process::ChildStderr>,
}

impl Session {
    fn start(dir: &Path) -> Session {
        let mut child = Command::new(env!("CARGO_BIN_EXE_eml"))
            .current_dir(dir)
            .arg("repl")
            .stdin(Stdio::piped())
            .stdout(Stdio::piped())
            .stderr(Stdio::piped())
            .spawn()
            .unwrap();
        let stdin = child.stdin.take().unwrap();
        let stdout = std::io::BufReader::new(child.stdout.take().unwrap());
        let stderr = std::io::BufReader::new(child.stderr.take().unwrap());
        Session { child, stdin, stdout, stderr }
    }

    fn send(&mut self, text: &str) {
        self.stdin.write_all(text.as_bytes()).unwrap();
        self.stdin.flush().unwrap();
    }

    /// 標準出力の次の行。
    fn out_line(&mut self) -> String {
        let mut line = String::new();
        std::io::BufRead::read_line(&mut self.stdout, &mut line).unwrap();
        line
    }

    /// 標準エラーを、`needle` を含む行まで読む。
    fn wait_err(&mut self, needle: &str) {
        loop {
            let mut line = String::new();
            let read = std::io::BufRead::read_line(&mut self.stderr, &mut line).unwrap();
            assert!(read > 0, "the REPL ended before printing {needle:?}");
            if line.contains(needle) {
                return;
            }
        }
    }

    /// 標準入力を閉じて終わりを待ち、残りの標準出力と標準エラーと終了コードを返す。
    fn finish(mut self) -> (String, String, Option<i32>) {
        drop(self.stdin);
        let mut out = String::new();
        let mut err = String::new();
        std::io::Read::read_to_string(&mut self.stdout, &mut out).unwrap();
        std::io::Read::read_to_string(&mut self.stderr, &mut err).unwrap();
        let status = self.child.wait().unwrap();
        (out, err, status.code())
    }
}
```
