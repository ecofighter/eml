## Key risks / observations (facts)
1. IO is identified by FOUR independent mechanisms: lang.io (HIR/types/translate), the string "Prelude.IO" (verifier), `IoOp::from_name(op.name)` (translate), `Frame::Io` (runtime). lang_items() finds all lang items by hard-coded string names in module 0 (def_map.rs:849-884).
2. `Function::intrinsic` is defined by (module 0 && no equation); E1005 shares that predicate; `Program::arity` for intrinsics is the outer-arrow count of the signature (no extern table arity today).
3. INTRINSICS table is name-only and covers 14 operators; `==`/`!=` need per-reference type instantiation (not a plain table row); equality selection uses LangItems types (int/string/bool).
4. Once `println` etc. are ordinary functions, E1009's current trigger (clause head resolves to an operation of lang.io) disappears; `println` in clause head resolves as non-operation -> E1001 path. Tests tests/ui/check-fail/names/handle_io.em and eml_hir/tests/effects.rs:175,384,392 pin the old behaviour.
5. Core IR pretty skips operation-less effects (pretty.rs:11) and text parse indexes effects by printed order; verifier locates IO by name in that table; ~70 Core IR test lines hard-code `effect Prelude.IO { println/1, open/1, read_all/1, close/1 }`.
6. Prelude path/name hard-coded in several places: PRELUDE_PATH "Prelude.em" (shown in diagnostics; api.rs:71, load.rs tests, eml_types/tests/modules.rs expects `Prelude.em` labels), loader constants PRELUDE/MAIN, DefMap module_id(0)/(1), `ModuleSource::read(ModulePath)` single root. A `std/` tree would change displayed path and need multi-root semantic; reserved-name check (load.rs:190-202) is by dotted name only.
7. Interp `Rhs::Io` execution needs `out: &OutputSink` and `file_root` from Machine; an extern table with Rust impls must be able to reach these (machine.rs fields; RunConfig).
8. UI tests whose output includes the operation-wrapper name `op$Prelude.open` (1 snapshot) and E1009 (1 snapshot) are the only snapshots tied directly to the removed mechanisms; roadmap says "UI テストの出力が変わらない" (roadmap.md:21) -- conflicts with these two snapshots unless counted as expected-value changes.
9. docs heading 「組み込みの `IO`」 is cited from ~20 places (citation checker enforces).
