# 段階6b-2 `from` の機能 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `handle ... from ... with` で書くパラメータ付き handler と3引数の `resume` を、HIR から実行まで通す。継続の型に状態の欄を足し、E2007 と fix、省いた `return` の節の E3004、状態の持ち越しを入れる。最後に段階6b の作業用の文書を `docs/` に移して消す。

**Architecture:** 6b-1 で Core IR とランタイムの状態の通り道はできている。HIR が初期値と3引数の `resume` と節の状態の引数を作り、型検査が継続の型の状態の欄 (型とは別の推論用の変数) で `resume` の引数の数を決める。線形性のパスは初期値の使用、状態の引数、省いた `return` の節、外側の row をまたぐ状態を扱う。Core IR の変換は初期値と状態を HIR から入れる。

**Tech Stack:** Rust (edition 2024)、`insta` (インラインのスナップショット)、`cargo test`。

**Spec:** `docs/superpowers/specs/2026-10-06-stage-6b-design.md` の0章 (決めたこと)、2章 (6b-2)、3章 (文書の更新)。`docs/implementation/status.md` の「段階6b の spec への入力」の引き継ぎも読む。

## spec からの補い

- status.md の引き継ぎ「書いたのに HIR が拒否した `return` の節の後に E3004 を連鎖させない」は、今の仕組みで満たされる。拒否した節は E1010 か E1014 を出すので `Body::has_errors` が真になり、使用回数のパスは由来を記録しない (`usage.rs` の `reliable`)。新しい仕組みは足さず、Task 6 のテストで固定する
- E2007 は2か所で出す。`resume` の検査で欄を単一化して失敗したとき (spec 2.4 の文言と fix) と、それ以外の単一化で欄が食い違ったとき (`k` をラムダの引数に渡した後で状態のある `k` と出会ったときなど) である。後者は、食い違いを見つけた式を primary にし、fix を付けない。文言は Task 3 で決める
- E2007 の状態を足す fix の条件3 (名前が隠されていない) は、型検査器に変数のスコープの表がないので、同じ名前の変数で、状態の引数より後に束縛され、`resume` より前で始まるものが本体に1つでもあれば付けない、という保守的な判定にする。付けるべき場面で付けないことはあるが、誤った fix は付けない
- spec 2.3 の E3004 のラベルの型は、使用回数のパスが制約を作るときに状態の型を `Table::export` で表示した文字列を由来に入れて出す
- `eml_test_support::fixes` は、診断の行に fix の題名を続けて表示する。既存の fix のスナップショットが変わる (種類2)
- `OpClause` と `ReturnClause` に状態の引数を返す `state()` を足す。状態は `closure.params` の最後にある
- spec 2.6 の `eml_interp` のテキストの IR のテスト (状態が `perform`、`resume`、`return` を通ること、写した区間の状態) は、6b-1 で状態が `()` の形を確かめた。値を持つ状態は、Task 4 の UI テスト (`state.em` と、boxed な状態の区間を写す `state_multi.em`) で確かめる。手で Perceus の後の IR を書くより、変換と実行を通すほうが確かめる範囲が広いためである

## Review Focus

- 状態のある handler の `k` をラムダに渡し、ラムダの中で2引数の `resume` をする: E2007 が1件だけ出て、パニックしない (Task 3 に型検査のテストを置く)
