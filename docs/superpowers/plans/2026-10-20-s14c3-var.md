# S14c-3 `var`, `:=`, Indexing, `for` and `while` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Local mutable variables `var x = e` built on per-site effects, with assignment `lhs := e`, postfix indexing `x[i]`, and Prelude `for` / `while`. A sieve and a small fannkuch-redux written with `var` run with `evidence_steps: 0` and the allocations of hand-written versions that pass `MutArray`s linearly, apart from the tuple returns counted as the residual until S14e.

**Architecture:**
- Front end:
  - The parser reads the new syntax.
  - HIR lowers every `var` site to a node whose body is the rest of the block, plus a synthetic effect item `L` with no operations and no type parameters.
  - The type checker types the uses like `perform`s of `L`. After inference it classifies each variable as `Unr` or array by its type, and checks E2019, E3007 and the array-variable rules.
- Back end:
  - Translate builds a handle, synthesized clauses and a Core IR operation table per variable from that classification.
  - S14c-2's state-passing (Passing) form, widened first so that nested `var`s do not pile up pairs, removes the handles.

**Tech Stack:** Rust (`eml_syntax`, `eml_hir`, `eml_types`, `eml_core_ir`, `eml_lir`, `eml_extern`, `eml_rt`, `eml_vm`), `std/Prelude.em`, insta, `eml_test_support`, the UI and REPL harnesses, `bench/` with `crates/eml_vm/tests/bench.rs`, `bench/run.sh` (macOS).

## Review Focus

- **Recovery after a caught index `Panic`:** a `try_panic` inside an array variable's scope catches an out-of-range `x[i]`, and the program then writes and freezes the array. The variable must keep its array (checked mode: no leak, no `WrongKind`), on the EP path and on the specialized path. Test: Task 5 `var/index_panic_recovers.em`.
- **One site shared by two instances:** a polymorphic function with `var last = x` is called at `Int` and at `String`. The operation table is per site, so boxing must convert at each instance. Test: Task 5 `var/polymorphic_site.em`.
- **Two sites with the same variable name:** an outer `var x` closure is called inside an inner function's own `var x` scope, and it must read the outer `x`. Test: Task 5 `var/same_name_sites.em`.
- **Abort with a live array variable:** `exit 3` inside an array variable's scope must leak nothing in checked mode. Test: Task 5 `var/exit_inside.em`.
- **A `Float` variable on the specialized path:** a `Float` accumulator in a `for` loop with a second variable. Its tuple fields box the float; the result must be exact and leak-free. Test: Task 5 `var/float_accumulator.em`.

**Interfaces:**
- Produces (crate-private):
  - `pub(super) fn touching(program: &Program, effect: u32) -> Vec<bool>` in `touch.rs`, indexed by `FnIdx`.
    - Least fixpoint over direct calls. A function touches H when its blocks hold any of: a `Perform` of `effect`; a call with a non-empty `mask`; `Handle`, `Resume` or `Clause`; an `Apply { yields: true }`; or a `Direct` call to a touching function.
    - `path` (Passing form) adds a `Direct` target only when it is `yields` and `touching[target]`. The Passing build copies exactly the same calls; a non-touching callee is called unchanged. The Tail form is unchanged.
  - `pub(super) struct Returned { values: Vec<(Repr, Mark)> }` replaces the enum.
    - `fn returned(table: &Table, function: FnIdx, program: &Program, state: Option<(Repr, Mark)>) -> Returned`.
    - Base values: the source copy's `Returned` when `function` is a Passing copy (kept in `Table::returns: HashMap<FnIdx, Returned>`). Otherwise `[(ret, ret_mark)]`, or `[]` when `ret` is `unit`.
    - Then push the state for a stateful handler.
    - Zero values return `()`, one returns that value, and n ≥ 2 build `con (<n-1 commas>) #0(...)`.
  - `fn tuple_layout(program: &mut Program, size: usize) -> LayoutId`: looked up by name, appended as `[TObj; size]` if missing. `round` pre-adds every size its copies need, before `Copies` borrows the program.
- Prelude:
  - `for : Int -> Int -> (Int -> <e> Unit) -> <Panic | e> Unit`: calls `body i` for `lo ≤ i < hi` in order, a non-tail call followed by a tail call.
  - `while : (Unit -> <e> Bool) -> (Unit -> <e> Unit) -> <e> Unit`.
