# リファクタリング R7e-2 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Core IR の `Switch` を、リテラルの case と `default` を持つ平らな形にし、リテラルの列の `match` を1つの `Switch` に、コンストラクタの列の残りのコンストラクタを `default` にする。

**Architecture:** `CExpr::Switch { scrutinee, cases: Vec<Case>, default: Option<CExprId> }` にし、`Case { pattern: CasePattern, fields, body }`、`CasePattern { Tag(u32), Int(i64), String(u32) }` を置く。まず表し方だけを変え (出力は変わらない)、次に変換がリテラルの列と残りのコンストラクタに `default` を使うようにする。インタプリタは case を順に比べ、なければ `default` に進む。`String` の scrutinee は比べた後に手放し、`default` に進む `data` の値は分解せずに手放す。

**Tech Stack:** Rust (edition 2024)、`insta`、`cargo test`。

**Spec:** `docs/superpowers/specs/2026-10-06-refactor-r7-design.md` の 6.3、7.1〜7.4 の R7e-2 の行。

## spec からの補い

- `default` に進む `data` の値: `Switch` は scrutinee を消費する。合う case があれば今と同じく `take_or_copy` で分解してフィールドを枝に渡す。合う case がなく `default` に進むときは、分解せずに値を手放す (`decref`)。`default` はフィールドを束縛しないので、Perceus が捨てるフィールドがないためである。`default` の枝が値全体を使うなら、今の変数の枝と同じく Perceus が `Switch` の前で複製する
- `String` の scrutinee: 文字列を比べ終えたら、どの枝に進むときも手放す (spec 6.3)。`Int` と `Tag` の scrutinee は RC の対象ではない
- B2 と `default`: 分かっているタグが `cases` になく `default` があるとき、B2 は `default` を、フィールドのない枝と同じく join point に切り出す。ただし `default` には複数のタグが届きうるので、本体の引数をタグの定数に置き換えない。本体が値全体を使うなら値を引数で渡す
- verifier のリテラルの case はフィールドを持たない。`String` の case の番号は文字列定数の表の中にある
- `CasePattern` の表示 (`Display`) は、テキストの形と同じく `#N`、`N`、`"text"` にする。`String` は文字列定数の表を引くので、`pretty` と verifier の誤りの文言は `Program` から文字列を引く

## Review Focus

- `default` に進む、フィールドを持つ `data` の値 (`match` に `| Red -> … | _ -> …` と書き、`Pair a b` のようなコンストラクタが `_` に届く): 値を分解せずに手放し、`debug_heap` が漏れを報告しない (Task 1 の `eml_interp/tests/data.rs` と、Task 3 の UI テストで確かめる)
- `String` のリテラルの `match` の、`default` に進む場合と一致する場合: どちらも文字列を1回だけ手放す (Task 1 と Task 2 にテストを置く)
- `default` の枝が scrutinee の変数そのものを使う `match` (`| "a" -> … | s -> s ++ "!"`): Perceus が `Switch` の前で複製し、二重の解放にならない (Task 2 にテストを置く)
- リテラルが1000個の `match` を debug ビルドで実行する: スタックがあふれない (Task 2 にテストを置く)
- `simplify` の K1 と B2 で、分かっているタグが `default` に進む場合: K1 は `default` の本体で置き換え、B2 は `default` を join point に切り出す (Task 3 にテストを置く)

`crates/eml_core_ir/src/text.rs` の `arms` を `cases` にし、`switch` の文を `CExpr::Switch { scrutinee, cases, default }` にする。`cases` は `(Vec<Case>, Option<CExprId>)` を返す。

```rust
    fn cases(&mut self, state: &mut FnState) -> Result<(Vec<Case>, Option<CExprId>), ParseError> {
        self.expect_punct('{')?;
        let mut cases = Vec::new();
        let mut default = None;
        while !self.eat_punct('}') {
            let line = self.line();
            if self.at_word("_") {
                self.word()?;
                self.expect_word("->")?;
                if default.replace(self.chain(state)?).is_some() {
                    return Err(error(line, "a switch has two defaults"));
                }
                continue;
            }
            let pattern = self.case_pattern(state, line)?;
            let fields = if self.at_punct('(') {
                self.list('(', ')', |p| p.binder(state))?
            } else {
                Vec::new()
            };
            self.expect_word("->")?;
            let body = self.chain(state)?;
            cases.push(Case { pattern, fields, body });
        }
        Ok((cases, default))
    }

    /// `#N` はタグ、数字は `Int`、文字列は文字列定数の表に入れて `String` にする。
    fn case_pattern(&mut self, state: &mut FnState, line: u32) -> Result<CasePattern, ParseError> {
        if let Some(Tok::Str(text)) = self.peek() {
            let text = text.clone();
            self.pos += 1;
            return Ok(CasePattern::String(self.intern_string(&text)));
        }
        let word = self.word()?;
        if let Some(tag) = tag_number(&word) {
            return Ok(CasePattern::Tag(tag));
        }
        word.parse::<i64>()
            .map(CasePattern::Int)
            .map_err(|_| error(line, format!("expected a case `#N`, a number, a string or `_`, found `{word}`")))
    }
```

`at_word`、`peek`、`Tok::Str`、`error`、`line` の型は `text.rs` の既存のものに合わせる。文字列を定数の表に入れる処理は、`const "…"` を読む処理 (`string_ids` を使っている箇所) と同じものを使う。名前のある関数がなければ、その処理を `intern_string(&mut self, text: &str) -> u32` として取り出し、`const` と case の両方から呼ぶ。`state` を使わない引数は消してよい。

```rust
    /// 1つの `Switch` の case の種類がそろい、同じ case が2回なく、リテラルの case はフィールドを持たず、リテラルの
    /// `Switch` が `default` を持つこと (docs/spec/core-ir.md)。リテラルは無限にあるので、`default` がないと合わない値が
    /// 行き場を失う。
    fn switch_cases(&self, cases: &[Case], default: Option<CExprId>) -> Result<(), String> {
        let kinds: HashSet<_> = cases.iter().map(|case| discriminant(&case.pattern)).collect();
        if kinds.len() > 1 {
            return Err("a switch mixes kinds of cases".to_string());
        }
        let literal = cases.iter().any(|case| !matches!(case.pattern, CasePattern::Tag(_)));
        if literal && default.is_none() {
            return Err("a switch on literals has no default".to_string());
        }
        let mut seen = HashSet::new();
        for case in cases {
            if literal && !case.fields.is_empty() {
                return Err("a literal case binds fields".to_string());
            }
            if let CasePattern::String(index) = case.pattern
                && index as usize >= self.program.strings.len()
            {
                return Err(format!("a case refers to string constant {index}, which does not exist"));
            }
            if !seen.insert(case.pattern) {
                return Err(format!("a switch has two cases for {:?}", case.pattern));
            }
        }
        Ok(())
    }
```

```rust
    /// `Switch` の scrutinee に合う case と、その枝に入れるフィールド。scrutinee は move で受け取る。合う case のある
    /// `data` の値は、`take_or_copy` でフィールドを複製して箱を手放す。比べ終えた文字列と、`default` に進む `data` の
    /// 値は、分解せずに手放す (docs/spec/core-ir.md)。
    fn select_case<'c>(
        &mut self,
        value: Value,
        cases: &'c [Case],
    ) -> Result<(Option<&'c Case>, Vec<Value>), Fault> {
        let program = self.program;
        let find = |pattern: CasePattern| cases.iter().find(|case| case.pattern == pattern);
        match value {
            Value::Tag(tag) => Ok((find(CasePattern::Tag(tag)), Vec::new())),
            Value::Int(n) => Ok((find(CasePattern::Int(n)), Vec::new())),
            Value::Obj(obj) => {
                let found = match self.heap.get(obj).map_err(Fault::Heap)? {
                    Payload::Data { tag, .. } => find(CasePattern::Tag(*tag)),
                    Payload::Str(text) => cases.iter().find(|case| {
                        matches!(case.pattern, CasePattern::String(index)
                            if program.strings[index as usize] == *text)
                    }),
                    _ => {
                        return Err(Fault::Internal(
                            "a switch on an object that is neither data nor a string",
                        ));
                    }
                };
                if let Some(case) = found
                    && matches!(case.pattern, CasePattern::Tag(_))
                {
                    return match self.heap.take_or_copy(obj).map_err(Fault::Heap)? {
                        Payload::Data { fields, .. } => Ok((Some(case), fields)),
                        _ => Err(Fault::Internal("a switch on an object that is not data")),
                    };
                }
                self.heap.decref(obj).map_err(Fault::Heap)?;
                Ok((found, Vec::new()))
            }
            _ => Err(Fault::Internal(
                "a switch on a value that is not a tag, an integer or a string",
            )),
        }
    }
```

`crates/eml_core_ir/src/translate/pattern.rs` の `compare_literals` を次にし、`compare` と `if_equal` をなくす。doc コメントは次のものに置き換える。

```rust
    /// リテラルの欄。上の行から現れる異なるリテラルの順に case を並べた1つの `Switch` にする。case はそのリテラルで
    /// 特殊化した行列に、`default` はワイルドカードの行だけの行列に進む。リテラルは無限にあるので、網羅性の検査を
    /// 通った行列では `default` の行列が空にならない (docs/spec/exhaustiveness.md)。比べる命令の連なりにしないのは、
    /// リテラルの数だけ入れ子が深くならないようにするため (docs/superpowers/specs/2026-10-06-refactor-r7-design.md の 6.3)。
    fn compare_literals(
        &mut self,
        occurrences: &[Occurrence],
        rows: &[Row],
        column: usize,
        targets: &[Target],
    ) -> CExpr {
        let body = self.body;
        let scrutinee = occurrences[column].atom;
        let mut remaining = occurrences.to_vec();
        remaining.remove(column);
        let mut literals: Vec<&Literal> = Vec::new();
        for row in rows {
            if let Head::Literal(literal) = head(body, row.cells[column])
                && !literals.contains(&literal)
            {
                literals.push(literal);
            }
        }
        let mut cases = Vec::new();
        for literal in literals {
            let specialized: Vec<Row> = rows
                .iter()
                .filter(|row| match head(body, row.cells[column]) {
                    Head::Literal(other) => other == literal,
                    Head::Any(_) => true,
                    Head::Con(..) | Head::Tuple(_) => false,
                })
                .map(|row| row.replace(column, []))
                .collect();
            let mut inner = Vec::new();
            let last = self.decide(&remaining, specialized, targets, &mut inner);
            cases.push(Case {
                pattern: self.literal_pattern(literal),
                fields: Vec::new(),
                body: self.seq(inner, last),
            });
        }
        let otherwise: Vec<Row> = rows
            .iter()
            .filter(|row| matches!(head(body, row.cells[column]), Head::Any(_)))
            .map(|row| row.replace(column, []))
            .collect();
        let mut inner = Vec::new();
        let last = self.decide(&remaining, otherwise, targets, &mut inner);
        let default = self.seq(inner, last);
        CExpr::Switch {
            scrutinee,
            cases,
            default: Some(default),
        }
    }

    /// リテラルのパターンの case。`String` は文字列定数の表に入れる。
    fn literal_pattern(&mut self, literal: &Literal) -> CasePattern {
        match literal {
            Literal::Int(n) => CasePattern::Int(*n),
            Literal::String(text) => CasePattern::String(self.program.strings.intern(text)),
            Literal::Unit => unreachable!("`()` is a wildcard pattern, not a literal pattern"),
        }
    }
```

関数の引数 (`out` があれば) は、今の `compare_literals` の呼び出し元 (`decide`) に合わせる。使わなくなった引数と `use` (`PrimOp`、`Rhs`、`FALSE`、`TRUE` など) は clippy の指摘に従って消す。`seq` と `decide` の形は今の `compare_literals` の使い方のまま。

```rust
            let target = |(tag, fields): &(u32, Vec<Atom>)| -> Option<Option<u32>> {
                match cases.iter().find(|case| case.pattern == CasePattern::Tag(*tag)) {
                    Some(case) if case.fields.len() == fields.len() => Some(Some(*tag)),
                    Some(_) => None,
                    None => default.map(|_| None),
                }
            };
            if values.iter().all(Option::is_none) || !values.iter().flatten().all(|value| target(value).is_some()) {
                continue;
            }
```

- 切り出した join point の表 `split` のキーを `Option<u32>` にする (`Some(tag)` は case、`None` は `default`)
- case の扱いは今のまま (引数のない case は本体の引数をタグの定数に置き換え、フィールドのある case は届くものだけを切り出す)
- `default` は、分かっている値のどれかが `None` に行くときだけ切り出す。本体の引数は定数に置き換えない (複数のタグが届きうるため)。本体が引数 (値全体) を使うなら、新しい変数に置き換えて join point の引数にし、jump は値を渡す。使わなければ引数のない join point にする。新しい `Switch` の `default` は、その join point への `jump` にする
- jump の付け替えは、値の行き先のキーで `split` を引く。`default` に行く jump の引数は、値全体を渡すときだけ `[passed[0]]`、そうでなければ空にする

今の `split` の要素の作り方と、後ろで `Join` の式を組み立てる部分 (300行目より後ろ) は、キーの型だけを変えて同じ形で使う。
