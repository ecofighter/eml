# S11c-3 REPL の結果の表示器 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** REPL の式の入力の結果を型に従う表示器で書く。`Show` を持たない値も `値 : 型` で書き、関数は `<fn>` と書く。値全体の節点の数と深さと長さに上限を置き、幅に収まらない結果を括弧の位置で行に分けて字下げする。これで S11 を終える。

**Architecture:** `eml_types` は式の入力の表示の仕方を `InputDisplay::{Unit, Value, Typed(String)}` にし、「`Show` を持つか」の判定 `satisfies` を公開する (Task 1)。`eml_rt` の `Ctx` に、文字列を写して手放す `copy_string` と1行を書いて書き出す `print_line` を足し、Verus で証明する (Task 2)。`eml_vm` の `Machine` に、文字列を返す入口を実行して結果を写す `run_shown` と、1行を書く `write_line` を足す (Task 3)。`eml_cli::pretty::format` が結果を切って整形する (Task 4)。translate は `derive.rs` の値の形を型とフィールドの型から作る形に直し (Task 5)、新しい `translate/display.rs` が型ごとの表示関数 `display$N$k` を組む。入口 `entry$input$N` は `println` を呼ばずに値の文字列を返し、`Repl` がそれを整形して書く (Task 6a)。トランスクリプトと lib API のテストで振る舞いを固定し (Task 6b)、端末の幅を渡し (Task 7)、残りの文書を直す (Task 8)。

## Review Focus

spec が求めるが、spec の「テスト」の項目だけでは確かめない入力のうち、利用者に効きやすいものを5つ挙げる。どれも、下の該当するタスクにテストを足してある。

1. **構造で書く値の中の `()` と、フィールドのないコンストラクタとレコード**: `[(), ()]`、`((), f)`、`(E {}, F, f)` を書けるはずである。`()` の表示関数は値を `unit` で受け、box の挿入がそのまま通す。Task 6b の `units_and_fieldless_constructors_are_written`
2. **表示の途中の利用者の `show` の実行時エラー**: `[(Bad, f)]` の `Bad` の `show` が `1 / 0` を起こすと、instance の中の位置を指す実行時エラーになり、セッションは続き、検査モードの `close` はリークを報告しないはずである。Task 6b の `a_runtime_error_in_a_show_inside_a_display_fails_the_input`
3. **10,000 文字の境目**: ちょうど 10,000 文字の結果は切らず、10,001 文字なら ` ...` を足し、切った所で開いたままの括弧は閉じているとみなすはずである。VM の写す長さ (10,001) と `pretty` の切り方がずれると、ここで出る。Task 4 の `a_result_of_exactly_the_limit_is_kept_whole` と、Task 6b の `a_result_is_cut_after_ten_thousand_chars`
4. **全角の文字を含む結果の幅**: 幅はバイトでなく文字の数で数えるはずである。Task 4 の `width_counts_chars_not_bytes`。写す長さも文字で数える (Task 2 の `copy_string_copies_up_to_a_number_of_chars`)
5. **型の ` : T` より狭い幅**: 長い型の結果を狭い幅で書いても、要素を落とさず、` : T` を閉じ括弧の行に付けるはずである。Task 4 の `the_suffix_counts_toward_the_width` と、Task 7 の `set_width_formats_results_at_that_width` (20 より狭い幅は 20)

```rust
/// 閉じた型 `ty` で `class` の制約が完全に解けるか。型検査の `solve` と同じく、instance の文脈は頭の型引数へ写し、
/// タプルは要素へ進む。型検査が式の入力の表示の仕方を決めるのと、translate の表示器が部分ごとに書き方を決めるのが、同じ
/// 判定を使う (docs/spec/types.md の「REPL の入力」)。型の表は hash-consing なので、同じクラスと同じ型の組は1回だけ
/// 調べる。
pub fn satisfies(program: &Program, types: &TypeStore, class: ClassId, ty: TypeId) -> bool {
    let mut work = vec![(class, ty)];
    let mut seen = HashSet::new();
    while let Some((class, ty)) = work.pop() {
        if !seen.insert((class, ty)) {
            continue;
        }
        match resolve(program, types, class, ty) {
            Resolution::Instance { instance, args } => {
                for constraint in &program[instance].context {
                    let index = u32::from(constraint.var.into_raw()) as usize;
                    work.push((constraint.class, args[index]));
                }
            }
            Resolution::Tuple(elements) => {
                work.extend(elements.into_iter().map(|element| (class, element)));
            }
            Resolution::Given | Resolution::Missing => return false,
        }
    }
    true
}
```

```rust
/// `text` の先頭の `max_chars` 文字。文字の始まりを `is_char_boundary` で数えるので、多バイトの文字の途中で切らない。
fn prefix_chars(text: &str, max_chars: usize) -> (r: &str) {
    let len = text.len();
    let mut end: usize = 0;
    let mut count: usize = 0;
    // `max_chars` 文字を数えた後の、次の文字の始まりで止まる
    while end < len && (count < max_chars || !text.is_char_boundary(end))
        invariant
            end <= len,
            count <= max_chars,
        decreases len - end,
    {
        if text.is_char_boundary(end) {
            count += 1;
        }
        end += 1;
    }
    if text.is_char_boundary(end) {
        text.split_at(end).0
    } else {
        text
    }
}
```

```rust
//! REPL の結果の整形 (docs/spec/repl.md の「整形の規則」)。端末にも VM にも依存しない純粋な関数なので、`lines` と
//! 同じく feature によらず組み立てる。

/// 整形する前に残す文字の数 (docs/spec/repl.md の「上限」)。超えた結果は、ここまでを残して ` ...` を足す。
pub const LIMIT: usize = 10_000;

/// `text` を、幅 `width` に収まらない組の括弧の位置で行に分けて字下げする。`suffix` (型の ` : T` か空) は切らずに
/// 最後の行の後ろに付け、幅に収まるかの判定にも数える。
pub fn format(text: &str, suffix: &str, width: usize) -> String {
    let (text, cut) = match text.char_indices().nth(LIMIT) {
        Some((at, _)) => (&text[..at], true),
        None => (text, false),
    };
    let tail = if cut {
        format!(" ...{suffix}")
    } else {
        suffix.to_string()
    };
    let Some(tokens) = Tokens::read(text, cut) else {
        return format!("{text}{tail}");
    };
    let mut out = Layout {
        tokens: &tokens,
        width,
        tail: tail.chars().count(),
        out: String::new(),
        column: 0,
    }
    .run();
    out.push_str(&tail);
    out
}

#[derive(Clone, Copy, PartialEq, Eq)]
enum Kind {
    Open(char),
    Close(char),
    Comma,
    Space,
    /// 文字列のリテラルと、ほかの文字の並び。
    Text,
}

struct Token<'a> {
    kind: Kind,
    text: &'a str,
    /// 文字の数。全角の文字も1文字と数える。
    width: usize,
}

/// 字句に分けた結果と、組の対応。組は開き括弧の位置で引く。
struct Tokens<'a> {
    list: Vec<Token<'a>>,
    /// 開き括弧の位置から、対の閉じ括弧の位置。切った所で開いたままの組は `list.len()` で、閉じる文字を書かない。
    close: Vec<usize>,
    /// 開き括弧の位置から、組の外側のカンマの位置。
    commas: Vec<Vec<usize>>,
    /// 開き括弧の位置から、組の中に別の組があるか。
    nested: Vec<bool>,
    /// 閉じ括弧の位置から、その後に続く文字の終わり (同じ深さの次のカンマか外側の閉じ括弧の位置。なければ
    /// `list.len()`)。
    boundary: Vec<usize>,
    /// 各位置より前のトークンの文字の数の和。長さは `list.len() + 1` である。
    before: Vec<usize>,
}

impl<'a> Tokens<'a> {
    /// 整形しない文字列 (改行を含む、閉じていない文字列のリテラルがある、括弧が対にならない) なら `None` を返す。
    /// `cut` なら、終わりで開いたままの括弧と文字列のリテラルは閉じているとみなす。
    fn read(text: &'a str, cut: bool) -> Option<Tokens<'a>> {
        if text.contains(['\n', '\r']) {
            return None;
        }
        let special = |c: char| matches!(c, '(' | '[' | '{' | ')' | ']' | '}' | ',' | ' ' | '"');
        let mut list = Vec::new();
        let mut chars = text.char_indices().peekable();
        while let Some((start, c)) = chars.next() {
            let kind = match c {
                '(' | '[' | '{' => Kind::Open(c),
                ')' | ']' | '}' => Kind::Close(c),
                ',' => Kind::Comma,
                ' ' => {
                    while chars.next_if(|&(_, c)| c == ' ').is_some() {}
                    Kind::Space
                }
                '"' => {
                    let mut closed = false;
                    while let Some((_, c)) = chars.next() {
                        match c {
                            '\\' => {
                                chars.next();
                            }
                            '"' => {
                                closed = true;
                                break;
                            }
                            _ => {}
                        }
                    }
                    if !closed && !cut {
                        return None;
                    }
                    Kind::Text
                }
                _ => {
                    while chars.next_if(|&(_, c)| !special(c)).is_some() {}
                    Kind::Text
                }
            };
            let end = chars.peek().map_or(text.len(), |&(at, _)| at);
            let piece = &text[start..end];
            list.push(Token {
                kind,
                text: piece,
                width: piece.chars().count(),
            });
        }
        let n = list.len();
        let mut tokens = Tokens {
            close: vec![n; n],
            commas: vec![Vec::new(); n],
            nested: vec![false; n],
            boundary: vec![n; n],
            before: Vec::with_capacity(n + 1),
            list,
        };
        let mut sum = 0;
        tokens.before.push(0);
        for token in &tokens.list {
            sum += token.width;
            tokens.before.push(sum);
        }
        // 開いている組の開き括弧の位置と、深さごとの、後に続く文字の終わりを待つ閉じ括弧
        let mut open: Vec<usize> = Vec::new();
        let mut waiting: Vec<Vec<usize>> = vec![Vec::new()];
        for k in 0..n {
            match tokens.list[k].kind {
                Kind::Open(_) => {
                    if let Some(&outer) = open.last() {
                        tokens.nested[outer] = true;
                    }
                    open.push(k);
                    waiting.push(Vec::new());
                }
                Kind::Close(c) => {
                    let start = open.pop()?;
                    let Kind::Open(o) = tokens.list[start].kind else {
                        unreachable!("only open brackets are pushed")
                    };
                    if !matches!((o, c), ('(', ')') | ('[', ']') | ('{', '}')) {
                        return None;
                    }
                    tokens.close[start] = k;
                    for inner in waiting.pop().expect("a level per open group") {
                        tokens.boundary[inner] = k;
                    }
                    waiting.last_mut().expect("the outermost level").push(k);
                }
                Kind::Comma => {
                    if let Some(&group) = open.last() {
                        tokens.commas[group].push(k);
                    }
                    for inner in waiting.last_mut().expect("the outermost level").drain(..) {
                        tokens.boundary[inner] = k;
                    }
                }
                Kind::Space | Kind::Text => {}
            }
        }
        if !open.is_empty() && !cut {
            return None;
        }
        Some(tokens)
    }

    /// トークン `from..to` を1行に書いたときの文字の数。
    fn span(&self, from: usize, to: usize) -> usize {
        self.before[to] - self.before[from]
    }

    /// 位置 `open` の組の要素の範囲。要素の前後の空白は含めない。
    fn elements(&self, open: usize) -> Vec<(usize, usize)> {
        let mut ranges = Vec::new();
        let mut from = open + 1;
        for &comma in &self.commas[open] {
            ranges.push(self.trimmed(from, comma));
            from = comma + 1;
        }
        ranges.push(self.trimmed(from, self.close[open]));
        ranges
    }

    fn trimmed(&self, mut from: usize, mut to: usize) -> (usize, usize) {
        while from < to && self.list[from].kind == Kind::Space {
            from += 1;
        }
        while to > from && self.list[to - 1].kind == Kind::Space {
            to -= 1;
        }
        (from, to)
    }
}

/// 書く作業。入れ子が深くても Rust のスタックを使わないよう、組の中身を再帰でなくこの列でたどる。
enum Work {
    /// トークン `from..to` を順に書く。組に出会えば、書き方を決める。
    Tokens(usize, usize),
    /// 改行と字下げ、区切り、括弧をそのまま書く。
    Text(String),
}

struct Layout<'t, 'a> {
    tokens: &'t Tokens<'a>,
    width: usize,
    /// 最後の行に付ける ` ...` と `suffix` の文字の数。
    tail: usize,
    out: String,
    column: usize,
}

impl Layout<'_, '_> {
    fn run(mut self) -> String {
        let mut work = vec![Work::Tokens(0, self.tokens.list.len())];
        while let Some(item) = work.pop() {
            match item {
                Work::Text(text) => self.write(&text),
                Work::Tokens(mut k, end) => {
                    while k < end {
                        if matches!(self.tokens.list[k].kind, Kind::Open(_)) {
                            match self.group(k, end, &mut work) {
                                Some(next) => k = next,
                                None => break,
                            }
                        } else {
                            self.write(self.tokens.list[k].text);
                            k += 1;
                        }
                    }
                }
            }
        }
        self.out
    }

    /// 位置 `open` の組を書く。1行に書いたか詰めて書いたなら、組の後ろの位置を返す。分けて書くなら、組の部分と、
    /// 組の後ろから `end` までを作業の列に積んで `None` を返す。
    fn group(&mut self, open: usize, end: usize, work: &mut Vec<Work>) -> Option<usize> {
        let tokens = self.tokens;
        let n = tokens.list.len();
        let close = tokens.close[open];
        let after = (close + 1).min(n);
        if self.column + tokens.span(open, after) + self.trailing(close) <= self.width {
            self.write_span(open, after);
            return Some(after);
        }
        let open_text = tokens.list[open].text;
        let close_text = if close < n {
            tokens.list[close].text
        } else {
            ""
        };
        let elements = tokens.elements(open);
        if elements.len() == 1 {
            // 括弧の位置で分けず、中の組に同じ規則を当てる
            self.write(open_text);
            work.push(Work::Tokens(close.min(end), end));
            work.push(Work::Tokens(open + 1, close.min(end)));
            return None;
        }
        let column = self.column;
        if !tokens.nested[open] {
            self.packed(&elements, column, open_text, close_text);
            return Some(after);
        }
        work.push(Work::Tokens(after, end));
        if close < n {
            work.push(Work::Text(format!("\n{}{close_text}", " ".repeat(column))));
        }
        for (index, &(from, to)) in elements.iter().enumerate().rev() {
            work.push(Work::Tokens(from, to));
            work.push(Work::Text(if index == 0 {
                format!("{open_text} ")
            } else {
                format!("\n{}, ", " ".repeat(column))
            }));
        }
        None
    }

    /// 組を含まない要素を、幅まで詰めて並べる。収まらない要素の前で改行し、開き括弧の列から `, ` で続ける。
    fn packed(&mut self, elements: &[(usize, usize)], column: usize, open: &str, close: &str) {
        for (index, &(from, to)) in elements.iter().enumerate() {
            if index == 0 {
                self.write(open);
                self.write(" ");
            } else if self.column + 2 + self.tokens.span(from, to) <= self.width {
                self.write(", ");
            } else {
                self.write("\n");
                self.write(&" ".repeat(column));
                self.write(", ");
            }
            self.write_span(from, to);
        }
        if !close.is_empty() {
            self.write(" ");
            self.write(close);
        }
    }

    /// 閉じ括弧 `close` の後に続く、同じ行に書く文字の数。文字列の終わりまで続くなら、最後に付ける文字も数える。
    fn trailing(&self, close: usize) -> usize {
        let tokens = self.tokens;
        let n = tokens.list.len();
        if close >= n {
            return self.tail;
        }
        let boundary = tokens.boundary[close];
        let rest = tokens.span(close + 1, boundary);
        if boundary == n {
            rest + self.tail
        } else {
            rest
        }
    }

    fn write_span(&mut self, from: usize, to: usize) {
        for k in from..to {
            self.write(self.tokens.list[k].text);
        }
    }

    fn write(&mut self, text: &str) {
        match text.rfind('\n') {
            Some(at) => self.column = text[at + 1..].chars().count(),
            None => self.column += text.chars().count(),
        }
        self.out.push_str(text);
    }
}
```

````markdown
値の大きさには上限がなく、部分を共有した値 (`t(k+1) = Node t(k) t(k)`) は、小さなヒープでも巨大な木になる。そのため、OCaml のトップレベルの既定の値 (`print_depth` 100、`print_length` 300) と同じ2つの上限を置く。

- 予算: 値全体で 300 個の節点まで書く。節点は、構造で書くコンストラクタ、タプル、リスト、`<fn>`、`show_prec` で書く部分、深さで切って書く `...` の1つずつで、それぞれ予算を1つ使う。区切りと括弧は予算を使わない。予算が尽きた後の部分は、予算を使わずに `...` と書く
- リスト: リストは節点として予算を1つ使い、要素はそれぞれの節点の分を使う。要素を書く前に予算が尽きていれば、その要素から後を書かずに `...` を最後の要素として書いて閉じる (`[a, b, ...]`。1つも書いていなければ `[...]`)。残りの要素がなければそのまま閉じる。100 万個の `Int` のリストは、299 個と `...` を書く
- 深さ: 構造で書く入れ子のコンストラクタ、タプル、リストを 100 段たどった先の部分は `...` と書く。コンストラクタのフィールド、タプルの要素、リストの要素は、それを持つ値より1段深い。`List` の背骨 (`::` のつながり) は段を増やさない。利用者が定義したリストの形の型 (`data L = | LNil | LCons (Int -> Int) L`) は、背骨のコンストラクタが段を増やすので、予算か深さで切れる
- 深さで切って書く `...` も予算を1つ使う (OCaml と同じ)。そのため、深さで切れた大きなリストも、予算の分の要素で止まる
- 型の数: 1つの入力の表示器が構造で書く型は 1000 種類までで、それより多くの型をたどる値は、越えた所を `...` と書く。入れ子の型でだけ起きる
- 長さ: `show_prec` で書く部分の中には、上の上限が届かない。値の文字列が 10,000 文字を超えたら、10,000 文字までを残して ` ...` を足す (下の「整形の規則」)。VM は 10,001 文字までを写し ([VM](vm.md) の「追記」)、整形が超えたかを見分ける。型の ` : T` は切らない

### 整形の規則

結果が幅に収まらなければ、括弧の位置で行に分ける。整形は `eml_cli::pretty::format(text, suffix, width)` が行う。`suffix` は型の ` : T` か空で、切らずに結果の最後の行の後ろに付け、幅に収まるかの判定に数える。端末にも VM にも依存しない純粋な関数なので、`eml_cli::lines` と同じく feature によらず組み立てる。

- 字句: 文字列のリテラル (`"` から、`\` の後の1文字を読み飛ばして、閉じる `"` まで)、開き括弧 `(`、`[`、`{`、閉じ括弧、カンマ、空白、ほかの文字の並び
- 切る: 10,000 文字を超えたら、10,000 文字までを文字の境界で残す。残した文字列の後に ` ...` を足す
- 整形しない文字列: 改行 (`\n` か `\r`) を含む、閉じていない文字列のリテラルがある、括弧が対にならない (閉じ括弧の種類が違う、開いていない括弧を閉じる) のどれかなら、整形せずにそのまま返す (`suffix` は付ける)。ただし、10,000 文字で切った所で開いたままの括弧と文字列のリテラルは、閉じているとみなす (閉じる文字は書かない)。タブはほかの文字と同じく1文字と数える
- 組: 開き括弧から対の閉じ括弧までが1つの組である。組の要素は、組の中の外側のカンマで分けた部分で、前後の空白は含めない。カンマのない組の要素は1つである。組の前後の文字 (`P `、`Node `、組の後ろの ` :+ x`) は、組を含む要素か行の一部である
- 幅に収まるか: 組を1行に書いたとき、組の開き括弧の列から、閉じ括弧と、閉じ括弧の後に続く文字までを含めて、幅に収まるかで決める。続く文字は、閉じ括弧と同じ深さの次のカンマか、外側の閉じ括弧か、文字列の終わりまでで、文字列の終わりまでなら `suffix` (切ったときは ` ...` も) を含める。間にある組は1行に書いたときの長さで数える。文字の数で数え、全角の文字も1文字と数える
- 収まる組は1行に書く
- 収まらない組:
  - 要素が1つの組 (`(Leaf 1)`、`(-3)`、`{ f = 1 }`) は括弧の位置で分けず、括弧の中の要素の中の組に、同じ規則を当てる
  - 要素が2つ以上で、どの要素も組を含まない組は詰めて書く。`[ ` の後に最初の要素を書き、残りの要素を `, ` で区切って幅まで並べ、収まらない要素の前で改行して、開き括弧と同じ列から `, ` で続ける。最後の行の後ろに ` ]` を書く
  - ほかの組は1要素ずつ書く。開き括弧の行に `[ ` と最初の要素を書き、2つ目からの要素は、開き括弧と同じ列から `, ` で始まる行に書く。閉じ括弧は、開き括弧と同じ列の行に書く。要素の中の組は同じ規則で整える。内側の組の `, ` の行と閉じ括弧の行は、内側の組の開き括弧の列に揃う。要素の始めの列は、外側の開き括弧の列に2を足した列である
- 1行に収まらない要素 (幅より長い文字列のリテラルや、組を含まない長い文字の並び) は、分けずにそのまま書く
- 整形した結果の閉じ括弧の後に続く文字と `suffix` (`] : List P` の ` : List P`) は、閉じ括弧と同じ行に続ける。それで幅を超えても分けない
````

- [ ] **Step 2: 値を分けて読む命令を `FnBuilder` に移す**

`Generator` の `switch`、`unpack`、`field_vars`、`branch_bool`、`bind`、`call_target` を、次の `impl FnBuilder` と自由な関数 `call_target` に移す。`program.rs` が文字列の命令を `impl FnBuilder` に置くのと同じ形である。`Generator` には、`branch_eq` と `call` と `string` と `concat` を残し、移した命令を呼ぶ短いメソッドを置く。呼び出しの `self.switch(` は `self.builder.switch_on(` に、`self.unpack(` は `self.builder.unpack_constructor(` にする。

```rust
/// 生成器と表示器 (`display.rs`) が共有する、値を分けて読む命令。変数の印はどれも `unr` である。
impl FnBuilder {
    /// `scrutinee` を `constructors` の case に分ける `switch` で、今のブロックを閉じる。case ごとにフィールドの変数と
    /// 行き先のブロックを返す。`default` が真なら、ほかのコンストラクタの行き先も返す。
    pub(super) fn switch_on(
        &mut self,
        scrutinee: VarId,
        layout: LayoutId,
        constructors: &[&Constructor],
        field: &str,
        default: bool,
    ) -> (Vec<(Vec<VarId>, BlockId)>, Option<BlockId>) {
        let cases: Vec<(Vec<VarId>, BlockId)> = constructors
            .iter()
            .map(|constructor| {
                let fields = self.field_vars(constructor, field);
                (fields, self.new_block())
            })
            .collect();
        let default = default.then(|| self.new_block());
        self.terminate(Term::Switch {
            scrutinee: Atom::Var(scrutinee),
            layout: Some(layout),
            cases: constructors
                .iter()
                .zip(&cases)
                .map(|(constructor, (fields, target))| Case {
                    pattern: CasePattern::Tag(constructor.tag),
                    fields: fields.clone(),
                    target: *target,
                })
                .collect(),
            default,
        });
        (cases, default)
    }

    /// コンストラクタが1つの値を分解する。フィールドがなければ読むものがないので `unpack` を置かない。
    pub(super) fn unpack_constructor(
        &mut self,
        value: VarId,
        layout: LayoutId,
        constructor: &Constructor,
        field: &str,
    ) -> Vec<VarId> {
        let fields = self.field_vars(constructor, field);
        if !fields.is_empty() {
            self.emit(Stmt::Unpack {
                value,
                ctor: Ctor {
                    layout,
                    tag: constructor.tag,
                },
                fields: fields.clone(),
            });
        }
        fields
    }

    fn field_vars(&mut self, constructor: &Constructor, name: &str) -> Vec<VarId> {
        constructor
            .fields
            .iter()
            .map(|&repr| self.var(named(name, repr)))
            .collect()
    }

    /// 真偽値 `value` で分かれる `switch`。`layout` は `Bool` の配置である。(`False` の行き先, `True` の行き先)。
    pub(super) fn branch_bool(&mut self, value: Atom, layout: LayoutId) -> (BlockId, BlockId) {
        let (on_false, on_true) = (self.new_block(), self.new_block());
        self.terminate(Term::Switch {
            scrutinee: value,
            layout: Some(layout),
            cases: vec![
                Case {
                    pattern: CasePattern::Tag(FALSE),
                    fields: Vec::new(),
                    target: on_false,
                },
                Case {
                    pattern: CasePattern::Tag(TRUE),
                    fields: Vec::new(),
                    target: on_true,
                },
            ],
            default: None,
        });
        (on_false, on_true)
    }

    pub(super) fn bind_unr(&mut self, name: &str, repr: Repr, rhs: Rhs) -> Atom {
        let var = self.var(named(name, repr));
        self.emit(Stmt::Let { var, rhs });
        Atom::Var(var)
    }
}

/// `target` を呼ぶ。行き先の関数が受ける引数の数がメソッドの引数の数より少なければ (等式が引数を持たない instance の
/// メソッド)、返った関数の値に残りを適用する。
pub(super) fn call_target(
    builder: &mut FnBuilder,
    program: &ProgramBuilder,
    indices: &[FnIdx],
    target: Target,
    mut args: Vec<Atom>,
    ret: Repr,
) -> Atom {
    match target {
        Target::Extern(row) => builder.bind_unr(
            "t",
            ret,
            Rhs::Extern {
                ext: row,
                args,
                at: None,
            },
        ),
        Target::Function(instance) => {
            let function = indices[instance.0];
            let arity = program.arity(function);
            debug_assert!(arity <= args.len(), "a method takes all its arguments");
            let rest = args.split_off(arity);
            if rest.is_empty() {
                return builder.bind_unr("t", ret, plain_call(Call::Direct(function, args)));
            }
            let value = builder.bind_unr("t", Repr::TObj, plain_call(Call::Direct(function, args)));
            builder.bind_unr(
                "t",
                ret,
                plain_call(Call::Apply {
                    callee: value,
                    args: rest,
                    yields: false,
                }),
            )
        }
    }
}
```

`field_types` を、型引数を埋める所と、コンストラクタのフィールドの型を求める所 (`constructor_fields`) に分ける。表示器は instance のない型にも `constructor_fields` を使う。

```rust
    fn field_types(&mut self, generated: &Generated) -> Vec<Vec<TypeId>> {
        let instance = match generated.node {
            InstanceNode::Tuple(0) => return Vec::new(),
            InstanceNode::Tuple(_) => return vec![generated.args.clone()],
            InstanceNode::Declared(instance) => instance,
        };
        let ty = self.hir[instance].head;
        // `Tag` は型引数を鍵に持たない。フィールドの型は Repr にしか使わないので、足りない分は一様な型で埋める
        let mut args = generated.args.clone();
        let uniform = self.store.flexible(Lin::Poly);
        args.resize(self.hir[ty].generics.type_vars.len(), uniform);
        self.constructor_fields(ty, &args)
    }

    /// `data` の型 `ty` の型引数 `args` での、コンストラクタの宣言の順のフィールドの型。コンストラクタの宣言の型に、
    /// 型引数の名前から `args` への代入をかけて、矢印の引数として取り出す。
    fn constructor_fields(&mut self, ty: TypeDefId, args: &[TypeId]) -> Vec<Vec<TypeId>> {
        let hir = self.hir;
        let TypeDefKind::Data { constructors } = &hir[ty].kind else {
            unreachable!("only data types have constructors")
        };
        let names: Vec<String> = hir[ty]
            .generics
            .type_vars
            .values()
            .map(|var| var.name.clone())
            .collect();
        constructors
            .iter()
            .map(|&constructor| {
                let item = ValueItem::Constructor(constructor);
                let kinds = self.typed.kind_values(item, args, &self.store);
                let mut subst =
                    Substitution::new(names.iter().cloned().zip(args.iter().copied()), kinds);
                let declared = self.typed.decls[&item].ty;
                let ty = self.store.substitute(declared, &mut subst);
                split_arrows(&self.store, ty, hir[constructor].fields.len()).0
            })
            .collect()
    }
```

`check_linearity` の前に、表示器の3つのメソッドを足す。

```rust
    /// 表示器が部分の型 `ty` をどう書くか (docs/spec/core-ir.md の「表示関数」)。`depth` は部分の段、`method` は `Show` で
    /// 書くときに呼ぶメソッド (`show_prec`。入力の値そのものとリストの要素は `show`) である。構造で書く型には、初めて
    /// 見たときに表示関数を足す。段か数が上限に届けば、表示関数を作らずに `Ellipsis` にする。
    fn display_part(&mut self, ty: TypeId, depth: u32, method: MethodId) -> FoundPart {
        let hir = self.hir;
        if matches!(self.store.kind(ty), TypeKind::Fn { .. }) {
            return Part::Function;
        }
        // 文脈が型引数で解けない instance は、解決すると使えない instance を指すので、先に `satisfies` で分ける
        let show = hir.lang.show;
        let structural = !eml_types::satisfies(hir, &self.store, show, ty)
            || match eml_types::resolve(hir, &self.store, show, ty) {
                Resolution::Tuple(_) => true,
                Resolution::Instance { instance, .. } => {
                    matches!(hir[instance].origin, InstanceOrigin::Derived(_))
                        || hir[instance].head == hir.lang.list
                }
                other @ (Resolution::Given | Resolution::Missing) => {
                    unreachable!("a satisfied `Show` resolves, found {other:?}")
                }
            };
        if !structural {
            return Part::Show(self.method_target(method, &[ty], Vec::new()));
        }
        if let Some(&index) = self.display_keys.get(&ty) {
            return Part::Display(index);
        }
        if depth >= MAX_DEPTH || self.display_keys.len() >= MAX_DISPLAYS {
            return Part::Ellipsis;
        }
        let form = self.display_form(ty);
        self.found.push(Found::Display {
            number: self.display_keys.len(),
            depth,
            form,
            parts: Vec::new(),
        });
        let index = self.found.len() - 1;
        self.display_keys.insert(ty, index);
        self.queue.push_back(index);
        Part::Display(index)
    }

    fn display_form(&mut self, ty: TypeId) -> DisplayForm {
        let hir = self.hir;
        match self.store.kind(ty).clone() {
            TypeKind::Tuple(elements) => DisplayForm::Tuple(elements),
            TypeKind::Con { id, args } if id == hir.lang.list => {
                DisplayForm::List(self.constructor_fields(id, &args))
            }
            TypeKind::Con { id, args } => match hir[id].kind {
                TypeDefKind::Data { .. } => {
                    DisplayForm::Data(id, self.constructor_fields(id, &args))
                }
                // `Show` を持たない extern の型は今は `File` だけで、式の入力の結果にならない (E2016)
                TypeDefKind::Extern(_) => panic!(
                    "internal error: the displayer reaches the extern type `{}` without `Show`",
                    hir[id].name
                ),
            },
            other => unreachable!("an input value has a closed type, found {other:?}"),
        }
    }

    /// 表示関数の部分の書き方を、部分の段 (表示関数の段の次) で決める。
    fn display_parts(&mut self, index: usize) {
        let Found::Display { depth, form, .. } = &self.found[index] else {
            unreachable!("called for a display function")
        };
        let (depth, form) = (depth + 1, form.clone());
        let show_prec = core_method(self.hir, CoreMethod::ShowPrec);
        let each = |collector: &mut Self, types: &[TypeId], method| -> Vec<FoundPart> {
            types
                .iter()
                .map(|&ty| collector.display_part(ty, depth, method))
                .collect()
        };
        let parts = match &form {
            DisplayForm::Tuple(elements) => vec![each(self, elements, show_prec)],
            DisplayForm::Data(_, fields) => fields
                .iter()
                .map(|types| each(self, types, show_prec))
                .collect(),
            DisplayForm::List(fields) => {
                vec![each(self, &fields[1][..1], self.hir.lang.show_method)]
            }
        };
        let Found::Display { parts: slot, .. } = &mut self.found[index] else {
            unreachable!("checked above")
        };
        *slot = parts;
    }
```

```rust
//! REPL の式の入力の値を書く表示関数 (docs/spec/core-ir.md の「表示関数」)。`instances.rs` が入口の型から幅優先で
//! 集めた型ごとに、値を書いた文字列を `acc` の後ろに足し、残りの予算と組にして返す関数 `display$N$k` を組む。`List`
//! は背骨をたどる補助の関数 `display$N$k$rest` も組む。書き方は導出した `Show` と同じで
//! (docs/spec/declarations.md の「`deriving`」)、予算と深さの上限は docs/spec/repl.md の「上限」にある。値はいつも
//! `Unr` なので、変数の印はすべて `unr` にし、写しと解放は Perceus に任せる。

use eml_extern::Extern;
use eml_hir::Program as HirProgram;
use eml_types::TypeStore;

use crate::{Call, CoreFn, Rhs, Stmt, Term};
use eml_lir::{Atom, BlockId, Ctor, FnIdx, Mark, Repr, TUPLE, VarId, VarInfo};

use super::derive::{Constructor, Shape, ShapeOf, call_target, shape};
use super::instances::{DisplayForm, DisplayInstance, Part};
use super::program::{ProgramBuilder, plain_call};
use crate::builder::FnBuilder;

/// 値全体で書く節点の数 (docs/spec/repl.md の「上限」)。
pub(super) const BUDGET: i64 = 300;
/// 構造で書く入れ子をこの段までたどる。この段の部分は `...` と書く。
pub(super) const MAX_DEPTH: u32 = 100;
/// 1つの入力で作る表示関数の数。
pub(super) const MAX_DISPLAYS: usize = 1000;

fn named(name: &str, repr: Repr) -> VarInfo {
    super::types::named(name, repr, Mark::Unr)
}

/// 書いている途中の結果。書いた文字列と残りの予算である。
#[derive(Clone, Copy)]
struct Written {
    acc: Atom,
    budget: Atom,
}

/// 表示関数 `display$N$k(acc, budget, depth, prec, x) -> (String, Int)` を組む。`List` なら、背骨をたどる補助の関数も
/// ここで番号を取って組む。
pub(super) fn generate(
    hir: &HirProgram,
    store: &TypeStore,
    program: &mut ProgramBuilder,
    indices: &[FnIdx],
    name: &str,
    display: &DisplayInstance,
) -> CoreFn {
    let of = match &display.form {
        DisplayForm::Tuple(elements) => ShapeOf::Tuple(elements),
        DisplayForm::Data(ty, fields) => ShapeOf::Data(*ty, fields),
        DisplayForm::List(fields) => ShapeOf::Data(hir.lang.list, fields),
    };
    let shape = shape(hir, store, program, of);
    let mut builder = FnBuilder::new();
    let acc = Atom::Var(builder.param(named("acc", Repr::Obj)));
    let budget = Atom::Var(builder.param(named("budget", Repr::Int)));
    let depth = Atom::Var(builder.param(named("depth", Repr::Int)));
    let prec = Atom::Var(builder.param(named("prec", Repr::Int)));
    let x = builder.param(named("x", shape.repr));
    let mut this = Display {
        hir,
        store,
        program,
        indices,
        builder,
        child: Atom::Unit,
    };
    let at = this.enter(Written { acc, budget }, depth);
    match &display.form {
        DisplayForm::Tuple(_) => {
            let at = this.tuple(at, &shape, x, &display.parts[0]);
            this.return_pair(at);
        }
        DisplayForm::Data(..) => this.data(at, &shape, x, prec, &display.parts),
        DisplayForm::List(_) => {
            let element = display.parts[0][0];
            let rest = this.rest(name, &shape, element);
            this.list(at, &shape, x, element, rest);
        }
    }
    this.builder
        .finish(name.to_string(), false, false, Repr::Obj, Mark::Unr)
}

struct Display<'a> {
    hir: &'a HirProgram,
    store: &'a TypeStore,
    program: &'a mut ProgramBuilder,
    indices: &'a [FnIdx],
    builder: FnBuilder,
    /// 部分の段 (`depth + 1`)。関数の始めで1回だけ求める。
    child: Atom,
}

impl Display<'_> {
    /// 関数の始めの検査。予算が尽きていれば、`...` を書いて予算を使わずに返す。段が上限に届いていれば、`...` を書いて
    /// 予算を1つ使って返す。どちらでもなければ予算を1つ使い、値を書く続きのブロックに残る。
    fn enter(&mut self, at: Written, depth: Atom) -> Written {
        let budget = self.check_budget(at, |this, cut| this.return_pair(cut));
        let deep = self.int_test(Extern::IntGe, depth, i64::from(MAX_DEPTH));
        let (shallow, too_deep) = self.branch(deep);
        self.builder.reopen(too_deep);
        let cut = self.append(at.acc, "...");
        self.return_pair(Written { acc: cut, budget });
        self.builder.reopen(shallow);
        self.child = self.int_op(Extern::IntAdd, depth, 1);
        Written {
            acc: at.acc,
            budget,
        }
    }

    /// 予算が尽きていれば `...` を書いて `exit` に渡す。尽きていなければ、予算を1つ使った値を返し、その続きのブロックに
    /// 残る。
    fn check_budget(&mut self, at: Written, exit: impl FnOnce(&mut Self, Written)) -> Atom {
        let empty = self.int_test(Extern::IntEq, at.budget, 0);
        let (has_budget, no_budget) = self.branch(empty);
        self.builder.reopen(no_budget);
        let cut = self.append(at.acc, "...");
        exit(
            self,
            Written {
                acc: cut,
                budget: at.budget,
            },
        );
        self.builder.reopen(has_budget);
        self.int_op(Extern::IntSub, at.budget, 1)
    }

    /// 部分 `x` を書く。`prec` は部分に渡す優先度で、`None` はリストの要素 (`Show` の部分は `show` で書く) である。表示
    /// 関数で書く部分はその関数が予算と段を調べ、ほかの部分はここで調べる。
    fn part(&mut self, at: Written, part: Part, x: Atom, prec: Option<i64>) -> Written {
        let Part::Display(instance) = part else {
            return self.inline(at, part, x, prec);
        };
        let target = self.indices[instance.0];
        let args = vec![
            at.acc,
            at.budget,
            self.child,
            Atom::Int(prec.unwrap_or(0)),
            x,
        ];
        let pair = self.bind("r", Repr::Obj, plain_call(Call::Direct(target, args)));
        self.unpair(pair)
    }

    fn inline(&mut self, at: Written, part: Part, x: Atom, prec: Option<i64>) -> Written {
        let join = self
            .builder
            .new_label(vec![named("acc", Repr::Obj), named("budget", Repr::Int)]);
        let budget = self.check_budget(at, |this, cut| {
            this.builder.jump(join, vec![cut.acc, cut.budget]);
        });
        let deep = self.int_test(Extern::IntGe, self.child, i64::from(MAX_DEPTH));
        let (shallow, too_deep) = self.branch(deep);
        self.builder.reopen(too_deep);
        let cut = self.append(at.acc, "...");
        self.builder.jump(join, vec![cut, budget]);
        self.builder.reopen(shallow);
        let text = match part {
            Part::Show(target) => {
                let args = match prec {
                    Some(prec) => vec![Atom::Int(prec), x],
                    None => vec![x],
                };
                call_target(
                    &mut self.builder,
                    self.program,
                    self.indices,
                    target,
                    args,
                    Repr::Obj,
                )
            }
            Part::Function => self.string("<fn>"),
            Part::Ellipsis => self.string("..."),
            Part::Display(_) => unreachable!("a display part calls its function"),
        };
        let acc = self.builder.concat(at.acc, text);
        self.builder.jump(join, vec![acc, budget]);
        let joined = self
            .builder
            .resolve(join)
            .expect("three blocks reach the join");
        Written {
            acc: joined[0],
            budget: joined[1],
        }
    }

    /// `(e1, e2, …)`。要素を優先度 0 で書く。`()` は配置を持たない。
    fn tuple(&mut self, at: Written, shape: &Shape, x: VarId, parts: &[Part]) -> Written {
        let Some(layout) = shape.layout else {
            return Written {
                acc: self.append(at.acc, "()"),
                ..at
            };
        };
        let fields = self
            .builder
            .unpack_constructor(x, layout, &shape.constructors[0], "a");
        let mut at = Written {
            acc: self.append(at.acc, "("),
            ..at
        };
        for (k, (&field, &part)) in fields.iter().zip(parts).enumerate() {
            if k > 0 {
                at.acc = self.append(at.acc, ", ");
            }
            at = self.part(at, part, Atom::Var(field), Some(0));
        }
        Written {
            acc: self.append(at.acc, ")"),
            ..at
        }
    }

    fn data(&mut self, at: Written, shape: &Shape, x: VarId, prec: Atom, parts: &[Vec<Part>]) {
        let layout = shape.layout.expect("a data type has a layout");
        match shape.constructors.as_slice() {
            // `=` のない `data` は E1025 に、選択肢のない `=` は構文エラー (E0011) になる
            [] => unreachable!("a checked data type has a constructor"),
            [only] => {
                let fields = self.builder.unpack_constructor(x, layout, only, "a");
                let at = self.constructor(at, only, &fields, prec, &parts[0]);
                self.return_pair(at);
            }
            all => {
                let all: Vec<&Constructor> = all.iter().collect();
                let (cases, _) = self.builder.switch_on(x, layout, &all, "a", false);
                for ((constructor, (fields, block)), parts) in all.iter().zip(cases).zip(parts) {
                    self.builder.reopen(block);
                    let at = self.constructor(at, constructor, &fields, prec, parts);
                    self.return_pair(at);
                }
            }
        }
    }

    /// コンストラクタ1つを、導出した `Show` と同じく書く。前置のコンストラクタは引数を優先度 11 で書き、`prec > 10`
    /// で括弧に入れる。中置のコンストラクタは優先度 p の左右を p + 1 で書き、`prec > p` で括弧に入れる。名前は修飾しない。
    fn constructor(
        &mut self,
        at: Written,
        constructor: &Constructor,
        fields: &[VarId],
        prec: Atom,
        parts: &[Part],
    ) -> Written {
        if let Some(names) = &constructor.field_names {
            return self.record(at, constructor, names, fields, parts);
        }
        if fields.is_empty() {
            return Written {
                acc: self.append(at.acc, &constructor.name),
                ..at
            };
        }
        let precedence = constructor.infix.map_or(10, i64::from);
        let wrap = self.int_test(Extern::IntGt, prec, precedence);
        let mut at = Written {
            acc: self.parenthesized(at.acc, wrap, "("),
            ..at
        };
        match constructor.infix {
            Some(infix) => {
                let [left, right] = fields else {
                    unreachable!("an infix constructor has two fields")
                };
                let inner = Some(i64::from(infix) + 1);
                at = self.part(at, parts[0], Atom::Var(*left), inner);
                at.acc = self.append(at.acc, &format!(" {} ", constructor.name));
                at = self.part(at, parts[1], Atom::Var(*right), inner);
            }
            None => {
                at.acc = self.append(at.acc, &constructor.name);
                for (&field, &part) in fields.iter().zip(parts) {
                    at.acc = self.append(at.acc, " ");
                    at = self.part(at, part, Atom::Var(field), Some(11));
                }
            }
        }
        Written {
            acc: self.parenthesized(at.acc, wrap, ")"),
            ..at
        }
    }

    /// `Name { f1 = …, f2 = … }`。フィールドを優先度 0 で書き、括弧に入れない。フィールドがなければ `Name {}` と書く。
    fn record(
        &mut self,
        at: Written,
        constructor: &Constructor,
        names: &[String],
        fields: &[VarId],
        parts: &[Part],
    ) -> Written {
        if fields.is_empty() {
            return Written {
                acc: self.append(at.acc, &format!("{} {{}}", constructor.name)),
                ..at
            };
        }
        let mut at = at;
        for (k, ((field_name, &field), &part)) in names.iter().zip(fields).zip(parts).enumerate() {
            let separator = if k == 0 {
                format!("{} {{ {field_name} = ", constructor.name)
            } else {
                format!(", {field_name} = ")
            };
            at.acc = self.append(at.acc, &separator);
            at = self.part(at, part, Atom::Var(field), Some(0));
        }
        Written {
            acc: self.append(at.acc, " }"),
            ..at
        }
    }

    /// `[e1, e2, …]`。リストの節点は予算を1つ使い、背骨 (`::` のつながり) は段を増やさない。要素の前に予算が尽きて
    /// いれば `...` を最後の要素として書いて閉じる。
    fn list(&mut self, at: Written, shape: &Shape, x: VarId, element: Part, rest: FnIdx) {
        let layout = shape.layout.expect("a list has a layout");
        let all: Vec<&Constructor> = shape.constructors.iter().collect();
        let (cases, _) = self.builder.switch_on(x, layout, &all, "a", false);
        let [(_, nil), (fields, cons)] = &cases[..] else {
            unreachable!("a list has `Nil` and `::`")
        };
        self.builder.reopen(*nil);
        let acc = self.append(at.acc, "[]");
        self.return_pair(Written { acc, ..at });
        self.builder.reopen(*cons);
        let acc = self.append(at.acc, "[");
        self.element(Written { acc, ..at }, fields, element, rest);
    }

    /// `display$N$k$rest(acc, budget, child, xs)`。`xs` の要素を `, ` に続けて書き、`]` で閉じる。`child` は要素の段で
    /// ある。末尾で自分を呼ぶので、縮約が末尾呼び出しにする。
    fn rest(&mut self, name: &str, shape: &Shape, element: Part) -> FnIdx {
        let function = self.program.reserve(4);
        let mut builder = FnBuilder::new();
        let acc = Atom::Var(builder.param(named("acc", Repr::Obj)));
        let budget = Atom::Var(builder.param(named("budget", Repr::Int)));
        let child = Atom::Var(builder.param(named("child", Repr::Int)));
        let xs = builder.param(named("xs", shape.repr));
        let mut this = Display {
            hir: self.hir,
            store: self.store,
            program: &mut *self.program,
            indices: self.indices,
            builder,
            child,
        };
        let layout = shape.layout.expect("a list has a layout");
        let all: Vec<&Constructor> = shape.constructors.iter().collect();
        let (cases, _) = this.builder.switch_on(xs, layout, &all, "a", false);
        let [(_, nil), (fields, cons)] = &cases[..] else {
            unreachable!("a list has `Nil` and `::`")
        };
        this.builder.reopen(*nil);
        let closed = this.append(acc, "]");
        this.return_pair(Written {
            acc: closed,
            budget,
        });
        this.builder.reopen(*cons);
        let acc = this.append(acc, ", ");
        this.element(Written { acc, budget }, fields, element, function);
        let core = this
            .builder
            .finish(format!("{name}$rest"), false, false, Repr::Obj, Mark::Unr);
        self.program.finish(function, core);
        function
    }

    /// `::` の case の続き。予算が尽きていれば `...]` で閉じ、尽きていなければ要素を書いて、残りを `rest` に渡す。
    fn element(&mut self, at: Written, fields: &[VarId], element: Part, rest: FnIdx) {
        let [head, tail] = fields else {
            unreachable!("`::` has two fields")
        };
        let empty = self.int_test(Extern::IntEq, at.budget, 0);
        let (has_budget, no_budget) = self.branch(empty);
        self.builder.reopen(no_budget);
        let cut = self.append(at.acc, "...]");
        self.return_pair(Written { acc: cut, ..at });
        self.builder.reopen(has_budget);
        let at = self.part(at, element, Atom::Var(*head), None);
        let args = vec![at.acc, at.budget, self.child, Atom::Var(*tail)];
        let pair = self.bind("r", Repr::Obj, plain_call(Call::Direct(rest, args)));
        self.builder.terminate(Term::Return(pair));
    }

    /// `wrap` が真なら `text` を足す。
    fn parenthesized(&mut self, acc: Atom, wrap: Atom, text: &str) -> Atom {
        let join = self.builder.new_label(vec![named("acc", Repr::Obj)]);
        let (plain, wrapped) = self.branch(wrap);
        self.builder.reopen(plain);
        self.builder.jump(join, vec![acc]);
        self.builder.reopen(wrapped);
        let added = self.append(acc, text);
        self.builder.jump(join, vec![added]);
        self.builder
            .resolve(join)
            .expect("two blocks reach the join")[0]
    }

    /// 結果の組 `(acc, budget)` を返して、今のブロックを閉じる。組は2要素のタプルの配置である。
    fn return_pair(&mut self, at: Written) {
        let ctor = self.pair_ctor();
        let pair = self.bind(
            "r",
            Repr::Obj,
            Rhs::Con {
                ctor,
                args: vec![at.acc, at.budget],
            },
        );
        self.builder.terminate(Term::Return(pair));
    }

    /// 表示関数が返した組を分ける。組を手放した後の文字列は一意なので、次の連結もその場で伸ばせる。
    fn unpair(&mut self, pair: Atom) -> Written {
        let Atom::Var(value) = pair else {
            unreachable!("a call result is a variable")
        };
        let acc = self.builder.var(named("acc", Repr::Obj));
        let budget = self.builder.var(named("budget", Repr::Int));
        let ctor = self.pair_ctor();
        self.builder.emit(Stmt::Unpack {
            value,
            ctor,
            fields: vec![acc, budget],
        });
        Written {
            acc: Atom::Var(acc),
            budget: Atom::Var(budget),
        }
    }

    fn pair_ctor(&mut self) -> Ctor {
        Ctor {
            layout: self.program.tuple_layout(2),
            tag: TUPLE,
        }
    }

    /// 真偽値 `value` で分かれる。(`False` の行き先, `True` の行き先)。
    fn branch(&mut self, value: Atom) -> (BlockId, BlockId) {
        let layout = self
            .program
            .data_layout(self.hir, self.store, self.hir.lang.bool);
        self.builder.branch_bool(value, layout)
    }

    fn int_test(&mut self, ext: Extern, a: Atom, n: i64) -> Atom {
        self.bind(
            "c",
            Repr::Enum,
            Rhs::Extern {
                ext,
                args: vec![a, Atom::Int(n)],
                at: None,
            },
        )
    }

    /// 生成した関数の算術は位置を持たない。予算と段は小さい数なので、溢れない。
    fn int_op(&mut self, ext: Extern, a: Atom, n: i64) -> Atom {
        self.bind(
            "n",
            Repr::Int,
            Rhs::Extern {
                ext,
                args: vec![a, Atom::Int(n)],
                at: None,
            },
        )
    }

    fn append(&mut self, acc: Atom, text: &str) -> Atom {
        let text = self.string(text);
        self.builder.concat(acc, text)
    }

    fn string(&mut self, text: &str) -> Atom {
        self.builder.string(&mut self.program.strings, text)
    }

    fn bind(&mut self, name: &str, repr: Repr, rhs: Rhs) -> Atom {
        self.builder.bind_unr(name, repr, rhs)
    }
}
```

リストの要素の前の予算の検査 (`element`) は、`...]` で閉じるために要素を書く前に行う。要素を `inline` で書くときも、`inline` が予算を同じく調べる。この2つ目の検査は通らない道を作るが、部分の書き方を1か所にまとめるために残す。

```rust
fn entry_after(

    typed: &TypedProgram,
    entry: FunctionId,
    instances: &instances::Instances,
    indices: &[FnIdx],
```

````markdown
### 表示関数

REPL の式の入力の値は、translate が入力ごとに組む表示関数 (`translate/display.rs`) が文字列にする。書き方と上限は [REPL の端末](repl.md) の「値の書き方」と「上限」にある。

```
display$N$k (acc: String, budget: Int, depth: Int, prec: Int, x: T) -> (String, Int)
```

- 書き方の決め方: 部分の型 `T` ごとに、次の順で部分の種類 `Part` を決める
  - 関数型は `Function` (`<fn>`) である
  - `eml_types::satisfies(Show, T)` が偽なら、構造で書く (`Display`)。このとき instance を解決しない。文脈が型引数で解けないので、`resolve` が返す instance は `method_target` で使えないためである
  - `eml_types::resolve(Show, T)` が、タプル (`Resolution::Tuple`)、導出した instance (`InstanceOrigin::Derived`)、頭が `LangItems` の `list` の instance のどれかなら、構造で書く
  - ほかは `Show` で、`show_prec` の行き先を `Collector::method_target` で解決する。入力の値そのものと `List` の要素では、`show` の行き先を解決する
  - `Show` を持たない extern の型に届けば内部の誤りにする。式の入力の結果に `File` は現れないためである (E2016)
- 形: `acc` に書いた結果を後ろに足し、残りの予算と組にして返す。Prelude の `show_rest` と同じく、左辺を一意な文字列として伸ばすので、書く量に比例する時間で済む ([オブジェクトモデル](object-model.md) の「文字列の操作」)。括弧も `acc` に先に足すので、入れ子の括弧で写しが増えない。結果の組 `(String, Int)` は2要素のタプルの配置 (`obj` で、フィールドは `tobj`) で返し、呼び出し側は `unpack` で受ける。組を解放した後の文字列は一意なので、次の連結もその場で伸ばせる
- 関数の始めで、`budget` が 0 なら `...` を足して返す (予算は 0 のまま)。`depth` が 100 以上なら `...` を足し、予算を1つ使って返す。どちらでもなければ予算を1つ使って値を書く
- 部分は、それを持つ値より1段深い (`depth + 1`) ところで、上の予算と深さの検査を受ける。`Show`、`Function`、`Ellipsis` (下の段と数の上限で表示関数を作らない型。`...` と書く) の部分は関数を作らず、呼び出し側でその場に組み、検査もその場で行う。`Display(k)` の部分は、表示関数 `display$N$k` を `depth + 1` で呼ぶ。`Show` の部分は、行き先 (`show_prec prec x`、`List` の要素なら `show x`) の結果を `acc` に足す。方程式の引数がメソッドより少ない instance のメソッドは、導出の生成器の `call_target` と同じく、返った関数に残りを適用する
- タプル、`data` のコンストラクタ、レコードは、導出した `Show` と同じ優先度と括弧で組む ([宣言](declarations.md) の「`deriving`」)。値の形は、導出の生成器と同じく型とフィールドの型から作る (`derive.rs` の `shape`)。`List` は、要素をたどる補助の関数 `display$N$k$rest(acc, budget, child, xs)` で背骨をたどる。要素は `depth + 1` (`child`) で書き、要素の前に予算が尽きていれば `...` を書いて閉じる。補助の関数は自分を末尾で呼ぶので、縮約が末尾呼び出しにする
- 名前: 入力の番号 N と、入力の中で見つけた順の番号 k から作る。型から名前を作らない理由は2つある
  - 後の入力が `instance Show Box` を足すと、前からある型 (`(Box, Int -> Int)`) の書き方が変わる。名前を型だけで決めると、同じ名前で違うコードができ、「同じ名前の関数はいつも同じコードになる」規則 (上の「変換の規則」) が破れる。入力の番号は使い回さないので、表示関数はその入力にだけある
  - 入れ子の型 (`data Nest a = | NNil | NCons a (Nest (a, a))`) では、たどる型の表示が段ごとに倍に伸びる。型の表示から名前を作ると、名前を作るのに指数の時間がかかる
- 集め方: instance の集め手 (`instances.rs` の `Collector`) が、入口の型から幅優先で型をたどり、型ごとに入口からの最小の段を記録する。表示関数の型は入口の型か別の表示関数の型からだけ見つかるので、幅優先で初めて見た段が最小の段である。番号 k は幅優先で見つけた順である。部分の `show_prec` と `show` の行き先も同じ集め手が集める
  - 初めて見た段が 100 以上の型は、表示関数を作らずに `Ellipsis` にする。その型の値を書く時点の段はいつも 100 以上で、`...` しか書かないためである
  - 1つの入力で作る表示関数は 1000 個までにする。幅優先で 1000 個を超えて見つけた型は `Ellipsis` にする。入れ子のフィールドを2つ持つ型 (`data W a = | WNil | W a (W (a, Int)) (W (a, Bool))`) は段ごとに型の数が倍になり、段の上限だけでは 2^100 個の型をたどるためである。lowering は止める語を読む前に走るので、ここで止まらないと Ctrl-C でも抜けられない
- 表示関数は `Found::Display` として、導出した instance の関数の後に、見つけた順に並ぶ。`internal` でない (導出の生成器と同じ)。互いに呼び合い、値としては使わない。`yields` でない。変数の印はすべて `unr` である。表示する値はいつも `Unr` で (式の入力の結果が `Unr` でなければ E2016)、`Unr` の値の部分も `Unr` だからである。写しと解放は Perceus に任せる。中の `extern` 命令 (比較、足し算、引き算、連結) は位置を持たない。予算と段は小さい数なので、溢れない
````

````markdown
式の入力の値は、型に従う表示器 ([Core IR](core-ir.md) の「表示関数」) が文字列にする。

- 型が `Show` を持つ式の入力は、値だけを書く

- 型が `Unit` の入力は何も書かない
- 関数型の入力も、式を評価してから `<fn> : 型` を書く (式の中の `println` などは動く)

```

Box 3 : Box
> fn x -> x + 1
<fn> : Int -> Int
> [fn x -> x, inc]
[<fn>, <fn>] : List (Int -> Int)
> (1, "a", inc)
(1, "a", <fn>) : (Int, String, Int -> Int)
> P { f = inc, n = 2 }
P { f = <fn>, n = 2 } : P
> 1 + 2
3

表示器は、値の部分 (入力の値そのものを含む) ごとに、書き方を次の順で決める。

1. 型が `Show` を持たなければ (型検査が式の入力の表示の仕方を決めるのと同じ判定で、制約が完全に解けなければ)、構造で書く。`instance Show a => Show (Box a)` のもとの `Box (Int -> Int)` のように、instance はあるが文脈が型引数で解けない型も、ここに入る
2. 型が `Show` を持ち、その `Show` が導出した instance (`deriving Show`)、タプルの構造的な instance (`()` を含む)、Prelude の `List` の instance のどれかなら、構造で書く。Prelude の `List` は、型の頭が `LangItems` の `list` であることで見分けるので、セッションの利用者が定義した `List` は含まない。Prelude の `Bool`、`Ordering`、`Option`、`Result` は導出した instance なので、構造で書く
3. ほかの型 (`Int`、`String`、利用者が書いた `Show` の instance を持つ型) は、その型の `show_prec` で書く。入力の値そのものと `List` の要素は `show` で書く

構造で書く規則は導出した `Show` ([宣言](declarations.md) の「`deriving`」) と同じなので、`Show` を持つ型を構造で書いた結果は、上限で切れる所を除き、`show` の結果と同じ文字列になる。

- 関数 (handler の継続を含む) は `<fn>` と書く
- タプルは `(…, …)` と書き、要素を優先度 0 で書く
- `List` は `Show` のリストと同じく `[…, …]` と書く。空のリストは `[]` である。リストは外から渡された優先度によらず括弧で囲まず、要素を優先度 0 で書く。要素が `show_prec` で書く部分なら、Prelude の `Show (List a)` と同じく `show` で書く (優先度 0 の `show_prec` ではない)
- `data` のコンストラクタは、導出した `Show` と同じく書く。前置のコンストラクタは `Box <fn>` で、引数を優先度 11 で書く。中置のコンストラクタは `a :+ b` で、優先度 p の演算子の左右を p + 1 で書く (fixity を宣言していない中置のコンストラクタは `infixl 9`)。外から渡された優先度が前置なら 10、中置なら p を超えると括弧で囲む。レコードは `P { f = <fn> }` で、フィールドを優先度 0 で書き、括弧で囲まない
- `show_prec` で書く部分は、利用者の instance の書き方をそのまま使う。`"a"` は引用符付きで書き、負の数はコンストラクタの引数の位置で括弧に入る (`Box (-3)`)
- コンストラクタの名前は、導出した `Show` と同じく書いた名前のまま (修飾も `#N` も付けない) である。定義し直した型の古い版の値は `Circle : Shape#1` になる。表示器は、届いたどの型のコンストラクタの名前も書く。セッションの `pub` でない型も、import したモジュールの `pub` でない型も同じで、導出した `Show` と同じ扱いである
- `Show` を持たない extern の型は、今は `File` だけで、`File` の値は式の入力の結果にならない (E2016)。表示器がほかの extern の型に届けば内部の誤りにする。`Show` を持たない extern の型を足すときに書き方を決める
````

```rust
fn empty_session(config: &RunConfig, host: &HostRef, width: usize) -> Repl {
    let mut repl = Repl::new(

        Box::new(FsProvider::new(Path::new(""))),

/// 標準出力の端末の列の数。端末でないか、読めないか、0 なら 80 である (docs/spec/repl.md の「結果の表示」)。
#[cfg(unix)]
fn stdout_width() -> usize {
    if !io::stdout().is_terminal() {
        return 80;
    }
    let mut size = libc::winsize {
        ws_row: 0,
        ws_col: 0,
        ws_xpixel: 0,
        ws_ypixel: 0,
    };
    // TIOCGWINSZ は渡した `winsize` に書くだけで、ほかの前提を持たない。読めなければ -1 を返し、`size` は 0 のままである
    let read = unsafe { libc::ioctl(libc::STDOUT_FILENO, libc::TIOCGWINSZ, &mut size) };
    if read == 0 && size.ws_col > 0 {
        usize::from(size.ws_col)
    } else {
        80
    }
}

#[cfg(not(unix))]
fn stdout_width() -> usize {
    80
}
```
