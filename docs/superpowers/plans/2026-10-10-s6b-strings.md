# S6b 文字列 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 文字列の補間 `\{式}` (穴は `Show` の `display` を呼ぶ)、複数行の文字列 `"""`、raw 文字列 `r"…"` / `r#"…"#` を使えるようにし、未対応のリテラルの E0004 をすべて HIR から出す。

**Architecture:** 層ごとに下から積む。Task 1 で Prelude の `Show` に `display` を足す。Task 2 で lexer にモードのスタックを入れ、単一行の文字列とコマンドリテラルを細かいトークンに分け、パーサが `STRING_LIT`、`INTERP`、`COMMAND_LIT` を組む。HIR は、穴のある文字列とコマンドリテラルに仮の E0004 を出す。Task 3 で複数行の文字列 (E0014) と raw 文字列を入れる。Task 4 でレイアウト段の `Interp` の文脈と、穴の誤りからの回復を仕上げる。Task 5 で `ExprKind::Interpolation` を HIR、型検査、translate に通す。Task 6 で文書とベンチマークの記録を段の終わりの形にする。

**Tech Stack:** Rust (edition 2024)、logos、rowan、la-arena、insta、eml の UI テスト、`bench/run.sh`。

**Spec:** `docs/superpowers/specs/2026-10-10-s6b-strings-design.md`。spec は main にコミットしてある (4f6d29d)。計画も Task 1 の前にコミットする。実装する人は、各タスクの前に spec の該当する節を読む。

## Review Focus

spec が求めるが、どのタスクのテストも直接は確かめない形のうち、使う人が最初に踏みそうなもの。各行のテストは、対応するタスクに入れてある。

- CRLF のファイルの複数行の文字列と、その中の穴 (Windows で取り出したリポジトリ)。値に `\r` が残らず、字下げの検査も CRLF で同じに働く (Task 3 の `crlf_multiline_strings_have_lf_values`)
- 穴やエスケープに隣り合う複数バイトの文字 (`"é\{x}ü"`、字下げの足りない行の先頭が `é`)。lexer と `parts()` が文字の途中で切らない (Task 2 の `multibyte_text_around_holes`、Task 3 の `short_indent_before_a_multibyte_character`)
- 編集の途中で、任意の位置で切れたソース。穴、複数行の文字列、raw 文字列、コマンドリテラルを含むソースのどの接頭辞でも、パニックせずに lossless な木を返す (Task 3 の `every_prefix_of_the_strings_corpus_parses`)
- 深く入れ子にした穴 (`"\{"\{"\{…"}"}"}`)。スタックを溢れさせずに E0013 になる (Task 4 の `deeply_nested_holes_stop_at_the_nesting_limit`)
- 穴の中のブロックコメントや入れ子の文字列にある `{` と `}` (`"\{f "}" {- } -} x}"`)。穴の閉じを数えるときに数えない (Task 2 の `braces_in_comments_and_strings_do_not_close_a_hole`)

- 穴の中の空白は、改行の手前で切る。`Raw::Whitespace` は改行も飲み込むので、穴の中では `[ \t]` の並びだけを `WHITESPACE` にする (`\r` は、後ろが `\n` のときだけ改行の一部である)

```rust

    /// (docs/superpowers/specs/2026-10-10-s6b-strings-design.md の「改行での回復」)。
    fn close_layers(&mut self, mut reported: bool, at_eof: bool) {
        loop {
            match *self.modes.last().expect("the base mode is never popped") {
                Mode::Code { hole: None, .. } => return,
                Mode::Code { hole: Some(start), .. } => {
                    if !reported {
                        self.error(
                            codes::UNTERMINATED_STRING,
                            "unterminated string interpolation",
                            start,
                            start + 2,
                            "missing closing `}`",
                        );
                        reported = true;
                    }
                    // パーサとレイアウト段が穴の終わりを知るための、幅 0 の閉じ
                    let at = self.range(self.pos, self.pos);
                    self.tokens.push(Token { kind: INTERP_END, range: at });
                }
                Mode::String { multiline: true, .. } if !at_eof => return,
                Mode::String { start, multiline, reported: already } => {
                    if !reported && !already {
                        let (end, label, message) = if multiline {
                            (start + 3, "missing closing `\"\"\"`", "unterminated multi-line string")
                        } else {
                            (self.pos, "missing closing `\"`", "unterminated string literal")
                        };
                        self.error(codes::UNTERMINATED_STRING, message, start, end, label);
                    }
                    reported = true;
                }
                Mode::Command { start } => {
                    if !reported {
                        self.error(
                            codes::UNTERMINATED_STRING,
                            "unterminated command literal",
                            start,
                            self.pos,
                            "missing closing backtick",
                        );
                        reported = true;
                    }
                }
            }
            self.modes.pop();
        }
    }

/// 報告済みなので、`STRING_END` がなくても黙って終える。
pub(super) fn string_lit(p: &mut Parser) -> SyntaxKind {
    let (text, end, node) = if p.at(CMD_START) {
        (CMD_TEXT, CMD_END, COMMAND_LIT)
    } else {
        (STRING_TEXT, STRING_END, STRING_LIT)
    };
    p.bump_any();
    loop {
        match p.current() {
            kind if kind == text || kind == ESCAPE => p.bump_any(),
            INTERP_START => interp(p, node == COMMAND_LIT),
            _ => break,

    }

/// 穴は括弧と同じく1段に数えるので、`paren_expr` と同じく、`expr` の形で始まらない式は `op_expr` で直接読む
/// (docs/superpowers/specs/2026-10-10-s6b-strings-design.md の「深さ」)。lexer が `INTERP_END` を必ず出すので、
/// 穴はいつもそこで終わる。幅 0 の `INTERP_END` は閉じていない穴で、lexer が報告済みなので誤りを重ねない。
fn interp(p: &mut Parser, spread: bool) {
    let m = p.start();
    p.bump(INTERP_START);
    if spread {
        p.eat(DOT2);
    }
    let unclosed = |p: &Parser| p.at(INTERP_END) && p.current_text().is_empty();
    let read = if p.at_ts(EXPR_FORMS) {
        expr(p)
    } else {
        op_expr(p, false) != OpExpr::Nothing
    };
    if !read && !unclosed(p) {
        expected(p, "an expression");
    }
    if !p.at(INTERP_END) {
        if read {
            expected(p, token_name(INTERP_END));
        }

        // 文字列の外には出ない。穴の中の入れ子の文字列の穴は、対で数えて飛ばす
        let skipped = p.start();
        let mut holes = 0u32;
        while !p.at_eof() && !(holes == 0 && p.at(INTERP_END)) {
            match p.current() {
                INTERP_START => holes += 1,
                INTERP_END => holes -= 1,
                _ => {}
            }
            p.bump_any();
        }
        skipped.complete(p, ERROR);
    }
    p.eat(INTERP_END);
    m.complete(p, INTERP);
}

/// 文字列の部分。`Text` はエスケープを値に直した後の文字列である。
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum StringPart {
    Text(String),
    Hole(Option<Expr>),
}

impl StringLit {
    /// 閉じていない文字列と不正なエスケープを含む文字列は `None` を返す。どれも lexer が報告済みである。隣り合う
    /// 本文とエスケープは1つの `Text` にまとめ、空の `Text` は返さない。
    pub fn parts(&self) -> Option<Vec<StringPart>> {
        support::token(&self.syntax, SyntaxKind::STRING_END)?;
        let mut parts = Vec::new();
        let mut text = String::new();
        for element in self.syntax.children_with_tokens() {
            match element {
                NodeOrToken::Token(token) if token.kind() == SyntaxKind::STRING_TEXT => {
                    text.push_str(token.text());
                }
                NodeOrToken::Token(token) if token.kind() == SyntaxKind::ESCAPE => {
                    text.push(crate::literal::escape_value(token.text())?);
                }
                NodeOrToken::Node(node) => {
                    if let Some(interp) = Interp::cast(node) {
                        if !text.is_empty() {
                            parts.push(StringPart::Text(std::mem::take(&mut text)));
                        }
                        parts.push(StringPart::Hole(interp.expr()));
                    }
                }
                _ => {}
            }
        }
        if !text.is_empty() {
            parts.push(StringPart::Text(text));
        }
        Some(parts)
    }

    pub fn holes(&self) -> AstChildren<Interp> {
        support::children(&self.syntax)
    }
}

impl Interp {
    pub fn expr(&self) -> Option<Expr> {
        support::child(&self.syntax)
    }
}
```

```rust
/// 複数行の文字列の本文 (開きの `"""` の後ろから閉じの `"""` の手前まで) の形。`content` は値にする範囲 (開きの
/// 行の改行の後ろから、閉じの行の改行の手前まで) で、`indent` は閉じの `"""` の列である
/// (docs/superpowers/specs/2026-10-10-s6b-strings-design.md の「複数行の文字列」)。
#[derive(Debug, Clone, PartialEq, Eq)]
pub(crate) struct MultilineLayout {
    pub(crate) content: std::ops::Range<usize>,
    pub(crate) indent: usize,
}

/// 形の誤り。範囲は本文の先頭からのバイト数である。
#[derive(Debug, Clone, PartialEq, Eq)]
pub(crate) enum LayoutError {
    SameLine,
    At {
        range: std::ops::Range<usize>,
        message: &'static str,
        label: &'static str,
    },
}

pub(crate) fn multiline_layout(body: &str) -> Result<MultilineLayout, Vec<LayoutError>> {
    let Some(first_break) = body.find('\n') else {
        return Err(vec![LayoutError::SameLine]);
    };
    let mut errors: Vec<LayoutError> = opening_line_error(body).into_iter().collect();
    let last_break = body.rfind('\n').expect("the body has a line break");
    let closing = &body[last_break + 1..];
    if let Some(offset) = closing.find(|c: char| c != ' ') {
        errors.push(LayoutError::At {
            range: last_break + 1 + offset..body.len(),
            message: "unexpected text before the closing `\"\"\"`",
            label: "only spaces may precede the closing `\"\"\"`",
        });
        return Err(errors);
    }
    let indent = closing.len();
    let content_start = first_break + 1;
    let content_end = if body[..last_break].ends_with('\r') { last_break - 1 } else { last_break };
    let content = content_start..content_end.max(content_start);
    let mut line_start = content.start;
    while line_start < content.end {
        let line_end = body[line_start..content.end].find('\n').map_or(content.end, |i| line_start + i);
        let line = body[line_start..line_end].trim_end_matches('\r');
        let blank = line.chars().all(|c| c == ' ');
        if !blank && !line.starts_with(&" ".repeat(indent)) {
            let first = line.char_indices().find(|&(_, c)| c != ' ').expect("the line is not blank");
            errors.push(LayoutError::At {
                range: line_start..line_start + first.0 + first.1.len_utf8(),
                message: "line is indented less than the closing `\"\"\"`",
                label: "indent this line at least as deep as the closing `\"\"\"`",
            });
        }
        line_start = line_end + 1;
    }
    if errors.is_empty() { Ok(MultilineLayout { content, indent }) } else { Err(errors) }
}

/// 開きの `"""` の後ろの、その行の空白でない部分。閉じていない文字列でも検査するので、別に置く。
pub(crate) fn opening_line_error(body: &str) -> Option<LayoutError> {
    let line = &body[..line_len(body)];
    let offset = line.find(|c: char| c != ' ')?;
    Some(LayoutError::At {
        range: offset..line.len(),
        message: "unexpected text after the opening `\"\"\"`",
        label: "the content of a multi-line string starts on the next line",
    })
}
```

`multiline_layout` の単体テストを `literal.rs` の `#[cfg(test)] mod tests` に置く。空白だけの行が N より長いときに残りの空白を保つことは `parts()` の側で見るので、ここでは誤りの判定 (`"\n  \n  "` が `Ok` で indent 2、`"\n  x\n    "` が字下げの誤り1件、`"x"` が `SameLine`) を確かめる。

/// `RAW_STRING` の値。閉じていなければ `None` で、lexer が報告済みである。改行は `\n` にそろえる
/// (docs/superpowers/specs/2026-10-10-s6b-strings-design.md の「改行の正規化」)。
pub(crate) fn raw_value(text: &str) -> Option<String> {
    let after_r = text.strip_prefix('r')?;
    let hashes = after_r.bytes().take_while(|&b| b == b'#').count();
    let close = format!("\"{}", "#".repeat(hashes));

- 閉じの `"""` で `STRING_END` を出してモードを戻した後、本文 (`open + 3 .. close`) に `multiline_layout` をかけ、誤りを E0014 にする。`LayoutError::SameLine` の範囲は文字列全体 (開きの `"""` から閉じの `"""` の終わりまで) で、ラベルは「this multi-line string is on one line」にする。`At` の範囲は `open + 3` を足して絶対位置にする
- ファイルの終わりで閉じていない複数行の文字列は、`close_layers(_, true)` が E0002 を出す。その前に、本文 (`open + 3 ..` ファイルの終わり) に `opening_line_error` をかけ、あれば E0014 を出す。`close_layers` が報告済みの層 (`reported`) を見て E0002 を出さないのは、穴の中の `"""` の層だけである
- `multiline_string` 関数を消す
- `raw_string` は、穴の中では改行の手前で止める。閉じていなければ今の E0002「unterminated raw string」を出し、`close_layers(true, false)` で外側を黙って閉じる

- [ ] **Step 6: AST とパーサと HIR を直す**

- `ast.rs` の `StringLit::parts()` を、`STRING_START` が `"""` のとき複数行の規則で読む形にする。本文は `STRING_START` の終わりから `STRING_END` の始まりまでで、`multiline_layout` が `Err` なら `None` を返す。`Ok(layout)` なら、`content` の範囲に入るトークンだけを、範囲で切って読む。行頭では `indent` 個までの空白を落とし、`\r\n` の `\r` を落とす。`ESCAPE` と穴は行頭の状態を終える

```rust
    fn multiline_parts(&self, layout: MultilineLayout, body_start: TextSize) -> Option<Vec<StringPart>> {
        let content = TextRange::new(
            body_start + TextSize::new(layout.content.start as u32),
            body_start + TextSize::new(layout.content.end as u32),
        );
        let mut parts = Vec::new();
        let mut text = String::new();
        let (mut at_line_start, mut stripped) = (true, 0);
        for element in self.syntax.children_with_tokens() {
            let Some(range) = element.text_range().intersect(content).filter(|r| !r.is_empty()) else {
                continue;
            };
            match element {
                NodeOrToken::Token(token) if token.kind() == SyntaxKind::STRING_TEXT => {
                    let start = range.start() - token.text_range().start();
                    let slice = &token.text()[TextRange::at(start, range.len())];
                    let mut chars = slice.chars().peekable();
                    while let Some(c) = chars.next() {
                        if c == '\r' && chars.peek() == Some(&'\n') {
                            continue;
                        }
                        if at_line_start && c == ' ' && stripped < layout.indent {
                            stripped += 1;
                            continue;
                        }
                        at_line_start = c == '\n';
                        stripped = 0;
                        text.push(c);
                    }
                }
                NodeOrToken::Token(token) if token.kind() == SyntaxKind::ESCAPE => {
                    at_line_start = false;
                    text.push(crate::literal::escape_value(token.text())?);
                }
                NodeOrToken::Node(node) => {
                    if let Some(interp) = Interp::cast(node) {
                        at_line_start = false;
                        if !text.is_empty() {
                            parts.push(StringPart::Text(std::mem::take(&mut text)));
                        }
                        parts.push(StringPart::Hole(interp.expr()));
                    }
                }
                _ => {}
            }
        }
        if !text.is_empty() {
            parts.push(StringPart::Text(text));
        }
        Some(parts)
    }
```

```rust
    fn lower_string(&mut self, string: &ast::StringLit, range: TextRange) -> ExprId {
        // 閉じていない文字列、不正なエスケープ、E0014 は字句解析が報告済み。穴の中の誤りを重ねて報告しないよう、
        // 穴も lower しない
        let Some(parts) = string.parts() else {
            return self.alloc(ExprKind::Missing, range);
        };
        let mut holes = string.holes();
        let mut segments = Vec::new();
        for part in parts {
            match part {
                ast::StringPart::Text(text) => segments.push(Segment::Text(text)),
                ast::StringPart::Hole(expr) => {
                    let hole_range = holes.next().expect("every hole part has an interp").range();
                    let callee = self.alloc(
                        ExprKind::Path(Res::Item(ValueItem::Method(self.lang.display))),
                        hole_range,
                    );
                    let arg = self.lower_expr(expr, hole_range);
                    let call = self.alloc(ExprKind::Call { callee, args: vec![arg] }, hole_range);
                    segments.push(Segment::Hole(call));
                }
            }
        }
        if !segments.iter().any(|segment| matches!(segment, Segment::Hole(_))) {
            let text = segments
                .into_iter()
                .map(|segment| match segment {
                    Segment::Text(text) => text,
                    Segment::Hole(_) => unreachable!("checked above"),
                })
                .collect();
            return self.alloc(ExprKind::Literal(Literal::String(text)), range);
        }
        self.alloc(ExprKind::Interpolation(segments), range)
    }
```

`ExprKind::Call` に `args` 以外のフィールドがあれば、ほかの所が呼び出しを組む形 (`lower/ops.rs`) に合わせる。

```rust

                // 穴を評価するたびにつなぐので、穴の呼び出しをまたいで生きているのは組み立て中の文字列だけである。
                // 連結は、導出した `Show` と同じく extern を直接呼ぶ。ユーザーの `++` によらない
                // (docs/superpowers/specs/2026-10-10-s6b-strings-design.md の「translate」)
                let repr = ExternType::String.row().repr;
                let mut acc: Option<Atom> = None;
                for segment in segments {
                    let part = match segment {
                        Segment::Text(text) => {
                            let index = self.program.strings.intern(text);
                            self.bind("s", repr, Rhs::ConstString(index))
                        }
                        Segment::Hole(hole) => self.atom(*hole),
                    };
                    acc = Some(match acc {
                        None => part,
                        Some(left) => self.bind(
                            "s",
                            repr,
                            Rhs::Extern {
                                ext: Extern::StrConcat,
                                args: vec![left, part],
                                at: None,
                            },
                        ),
                    });
                }
                acc.expect("an interpolation has a hole")
            }
```
