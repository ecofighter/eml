# S2 (r3): eml_rt cross-thread heap memory model for `worker-threads`

Abbreviations: OM = docs/spec/object-model.md, MC = docs/future/multicore.md, TS = docs/implementation/testing.md, RM = docs/future/roadmap.md. Paths are under /home/user/eml. [V] = verified (how in parentheses), [I] = inferred. Changes against r1 are marked "(r2)", changes against r2 "(r3)" (conformance findings Cf-1, Cf-2, Cf-3, Cf-6, Cf-7, I-1; response table in §10).

Coordination facts taken from S1 r1 (settled for this deliverable): the stage's consumer is `par` right-child placement on an idle worker; workers 1..N-1 are spawned per run by worker 0 with `thread::scope`, each builds its own `Ctx` on the shared `Control`, and returns its `Ctx` to worker 0 at run end; worker 0 joins all, then drains every heap, runs the checked-mode checks over N heaps or recovery, drops heaps 1..N-1; REPL stays N = 1; `TransferLeak` at join stays synchronous (child publishes Release, parent reads Acquire). So the quiescent point is "all worker threads joined, every heap owned by worker 0's thread".

## 1. Conclusion

**Page layout (48-byte page head, three separately-owned parts)**
- Offset 0..24 `PageHeader` (Copy, immutable after the page is published): `class: u32, block_words: u32, sink: *const RemoteSink, bytes: usize`. `global layout PageHeader is size == 24, align == 8`.
- Offset 24..40 `PageState` (Copy, owner thread only): `index: usize, limit: usize`. `global layout PageState is size == 16, align == 8`.
- Offset 40..48 `remote: usize`: remote free-list head (small pages) or the link in the owner's remote-large list (large pages). Touched only through `AtomicUsize::from_ptr` in T14 functions; its `PointsTo<usize>` lives in `PagePerm` and is only lent to them.
- `FIRST_BLOCK = 48`. Measured effect (r2, scratch copy with a padded 48-byte head and `FIRST_BLOCK = 48`): `cargo test -p eml_rt` 750 passed, the only failure is the pinned T6 row text in trust.rs [V]; eml_vm `bench::`/`calls::`/`api::`/`par::` (129) and eml_cli `api::`/`ui::` (85) all pass unchanged [V: §7]; blocks per page shrink by at most one per class, so page counts move only at an exact page boundary, and no pinned value sits on one.
- Reason for the split: foreign readers and the remote free path read `class`/`block_words`/`sink`/`bytes` of pages they do not own, while the owner rewrites `limit` (page change) and `index` (`swap_remove`) with whole-struct `ptr_mut_write` [V: alloc.rs:1618-1625, :2395-2401]. Verus permissions write whole structs, so the owner-mutable fields need their own struct and permission.
- `PagePerm = { header: PointsTo<PageHeader>, state: PointsTo<PageState>, remote: PointsTo<usize>, dealloc, tail }`.

**`RemoteSink` (one per heap, `Box<RemoteSink>` owned by `Pages`; stable address while the heap lives)**
- `RemoteSink { count: AtomicUsize, large: AtomicUsize, pushing: AtomicU32 }`. `count` = remote frees not yet reclaimed (Relaxed hint). `large` = push-only Treiber stack of remotely-freed large pages linked through their `remote` word. `pushing` (r2, checked mode only) = pushes in flight; quiescent-point operations read it (below).
- Ownership test everywhere: `page_sink_of(h) == self.sink` (one load, one compare); replaces `index`-based `Pages::owns` [V: alloc.rs:1043-1073; callers core.rs:250, recover.rs:582]. `freeze` writes `sink = null` into every page before the chunk is published; region block ⇔ `sink.is_null()`; foreign heap block ⇔ other non-null sink.
- (r2) The sink no longer carries a `Control` pointer; "same run" is answered by the checked-mode page map below.

**(r2) Checked-mode page map = the run-wide page registry**
- `Control.pages: PageMap` (checked mode only; opaque to Verus; safe Rust): a two-level radix bitmap over page bases: `top: OnceLock<Box<[OnceLock<Box<[AtomicU64; LEAF]>>]>>` with `TOP` entries indexed by `addr >> (16 + log2(LEAF * 64))`, leaf bit `(addr >> 16) % (LEAF * 64)`. Lookup = three `OnceLock::get` (Acquire loads) + one `AtomicU64` load + bit test; no lock. Insert/remove = `fetch_or`/`fetch_and` (leaf allocation via `get_or_init`). (r3, I-1) Sizing: three levels, every table built with an array-repeat (`Box::new([const { OnceLock::new() }; N])`, one Miri operation, no element loop): `top` 256 entries indexed by page-index bits 24..32, `mid` 256 entries (bits 16..24), `leaf` 1024 `AtomicU64` = 2^16 pages (bits 0..16); page index = `addr >> 16`. Memory: 4 KiB + 4 KiB + 8 KiB per touched 4 GiB region, nothing like r2's 1 MiB. Measured under Miri Tree Borrows in a probe crate (scratchpad `pagemap-probe`): a 4096-entry top built by an element loop plus one 128 KiB leaf costs 1.49 s per `Control`, and 16384- and 65536-entry element-built tops did not finish within 9 and 30 minutes, so element-built tables of r2's size are out of the question and every table must be a repeat expression. Obligation in U3: measure the per-checked-test increase of `trusted::` under Tree Borrows after the map lands; it must stay below 0.2 s per test (every checked `trusted` test creates a `Control`), otherwise shrink `leaf` to 256 words and add a fourth level.
- Registered page := its bit is set. `fresh_page` (T1) sets the bit and `dealloc_page`/`Pages::drop` clear it when `prefix_words > 0` (checked). Frozen chunks keep their bits until `Frozen` drops (same `Control`). Fast mode never touches the map.
- Checked-mode word validation (every word-accepting operation, before any dereference): immediate → ok; else `pages.has(page_base(w))` else `Err(HeapError::UnknownPage)`; then the prefix read as today. This catches stale words into dropped heaps' pages and words from another `Control`, which r1's `(*sink).control` compare could not (it dereferenced first). `OtherRun` is dropped.
- On a registered foreign page the block must be shared (rc<0), immortal (rc 0, e.g. another heap's dummy), or local rc>0 with prefix owner == current logical worker ID (an object whose ownership `share` moved); checked mode checks the owner as today, fast mode trusts the protocol (G-S2-5).

**Free path and the local fast path**
- `dup`/`decref` fast paths (rc 2..MAX-1) do not read the page head: unchanged.
- `DecrefStep::Free` and the free chain: `Heap::free_block_at(h)` reads `page_sink_of(h)`: equal to own sink → `Pages::free(h, perm)` (existing path: reads `PageHeader.class`, pushes to the class free list / `release_large`); not equal → `remote_push(h, lend)` (foreign block, §Verification). Cost on the local path: +1 load +1 predictable compare-branch before the existing `block_header` read.
- (r2, B-1) Region and immortal blocks never reach this point: `Free` is taken only for rc == 1 and the shared last for rc == −1, and region blocks have rc 0 by the region invariant (OM 「検証」; `lemma_region_at` at mod.rs:2544 already proves "rc ≠ 0 ⇒ not region" [V]). Proof obligation stated on `free_block_at`: `requires rc_of(h) != 0`; `page_sink_of`'s T14 promise includes "non-null for every block with rc ≠ 0"; the remote branch requires `sink != null && sink != self.sink`. No runtime null check in fast mode; checked mode returns `UseAfterFree` if a null-sink block arrives with rc ≠ 0 (defensive, before any push).
- `remote_push(h, lend)` (fast mode): write `meta = FREE_META`; loop `{ old = page.remote.load(Relaxed); payload0(h) = old; CAS(page.remote, old → h, Release, Relaxed) }`; `sink.count.fetch_add(1, Relaxed)`. Checked mode: `pushing.fetch_add(1, Relaxed)` first, `mark_freed` on the prefix, the same push, `pushing.fetch_sub(1, Release)` last. The freer never touches the owner's `Class`, `list`, `quarantined`, `stats` or `Control.bytes`.
- (r2, B-6) The link word is `payload[0]`, which every block has: `object_words` makes the payload at least one word [V: mod.rs:199-209], the same word the local free list uses [V: alloc.rs:2217].
- Large block on a foreign page: `remote_large_push(page)`: `old = sink.large.load(Relaxed); page.remote.store(old, Relaxed); CAS(sink.large, old → page, Release, Relaxed)`; `count += 1` (and `pushing` as above). The freer never deallocates a foreign page.
- Push-only Treiber stacks taken by `swap` have no ABA; the AcqRel last-decref plus the Release CAS / Acquire swap publish the freer's block writes to the owner.

**Reclaim (owner thread; `&mut Heap` only)**
- `Heap::reclaim(&mut self)` (forced): `count.swap(0, Relaxed)`; walk `Pages.list`; for every page with `remote.load(Relaxed) != 0`: `head = remote.swap(0, Acquire)`, then per block: fast mode `Pages::free(h, perm)` (rewrites meta and link); checked mode: `quarantined += block_bytes`, `stats.live -= 1`, permission kept with state Freed (the `release_ref` checked branch, mod.rs:3127-3200 [V]). Then `pages = large.swap(0, Acquire)`; per page: fast mode `release_large` (`swap_remove`, `dealloc`, `refund_pages`, page-map bit cleared); checked mode: account only (large pages stay, OM:617).
- (r2, C-1/A-1) `Heap::reclaim_if_due(&mut self) -> bool`: runs `reclaim` iff `large.load(Relaxed) != 0 || count.load(Relaxed) >= REMOTE_RECLAIM (256)`. A pending remote large page always triggers, so remotely freed bytes are refunded before any accounting decision.
- Reclaim points (eml_rt has no loop):
  1. Allocator: every page acquisition (`next_page`, `alloc_large`) is preceded by `reclaim_if_due` (`Pages::try_alloc(words) -> Option` returns None iff a new page is needed; `Heap` then calls `reclaim_if_due` and `Pages::alloc`). The fast alloc path (`pop_free`, `carve`) is unchanged.
  2. (r2, C-1) `Heap::over_budget(&mut self, bytes) -> bool` wraps `Control::over_budget` with `reclaim_if_due` first; the callers at ctx/bytes.rs:937, :1049, ctx/arrays.rs:1046, host.rs:594 [V: 01a] move to it. Together with 1, no `MemoryLimit`/`over_budget` decision is taken while a remotely freed large page is pending. Miri test (b) covers it.
  3. VM before parking a worker: `Ctx::reclaim_if_due` (S4). O(pages) only when due, so parking stays cheap in ping-pong patterns (A-1).
  4. Forced `reclaim` inside every quiescent-point operation (below) and in `Drop for Heap` before `finalize_all`.
- Memory bound: at most 255 small remote blocks and no large page stay unreclaimed between triggers; the final `reclaim` on worker 0 after join makes every count exact.
- The walk is O(pages) with one Relaxed load per page, amortized against ≥256 frees or one large page. A dirty-page index is deferred (RM item; condition: the walk shows in a channel-heavy profile at `async-threads`).

**Large-object policy**: local free deallocates immediately (unchanged, OM:192). Remote frees deallocate at the owner's next `reclaim_if_due`, which runs before any page acquisition or budget check. MC:326 is narrowed to small pages.

**(r3, Cf-2) Remote-free counters (checked mode, in `Stats`, read through `Heap::stats()`)**: `remote_frees: u64` = blocks (small or large) this heap pushed into another heap's sink (incremented by the freer in `remote_push`/`remote_large_push`), `reclaimed: u64` = blocks this heap took back in `reclaim`. Both are checked-mode-only like every other `Stats` field and are not added to `RunStats` (no snapshot change); a VM test observes a remote free as `ctx0.heap().stats().remote_frees >= 1` after the join: the parent's `decref` of a result object the child allocated is always a push into heap k's sink (G-S2-3), so a test whose child returns a fresh list and whose parent drops it after the join is deterministic. The child's free of the shared closure (parent's pages) is not guaranteed to be last, so tests must not rely on `stats_k.remote_frees`.

**Memory accounting**: `Control.bytes` is charged/refunded by the page owner only. Checked `bytes_in_use = pages.bytes − quarantined` updated at reclaim. `Stats.live`/`peak_live` of heap H count blocks on H's pages; `release_ref` decrements `live`/`quarantined` only when `sink == self.sink`; reclaim does it for remote frees. Sums over heaps are exact after the final reclaim.

**Quiescent-point operations and what "safe" means (r2, B-5)**
- `reclaim`/`reclaim_if_due`: safe at any time on the owner thread. Proof obligation (T14 promise of `remote_take`): the returned addresses are pairwise distinct carved blocks of that page that are in this heap's `in_use` (ghost) and were freed by their last reference; so a block is never both in a remote chain and on a free list or reachable.
- Page walks (`live_objects`, `check_invariants`, `leaks`, `freeze`, `recover`, `Drop`) read block words that a remote free writes (`meta`, `payload[0]`, prefix). Precondition, stated once in OM 「別のスレッドからの解放」 and cited by each: no other thread holds a reference to a shared object of this heap or is inside a remote free of a block on its pages. In this stage that is exactly S1's point "all worker threads joined, every heap on worker 0's thread"; the `par` join itself only calls `transfer_back` + `retire_worker` (no walk). (r3) These take `&mut self` and call `reclaim` first; in checked mode they then return `HeapError::NotQuiescent` if `sink.pushing != 0` (detects an in-flight push, not a reference held elsewhere — stated as such).
- (r3, Cf-3) `Control::check_owned<M>(&self, heaps: &[&Heap<M>])` is the one exception: it cannot reclaim. Precondition: every heap in `heaps` has run a forced `reclaim` after the last push into its sink, and no thread touches any heap during the call. In checked mode it returns `NotQuiescent` if any heap's sink has `count != 0`, `large != 0` or `pushing != 0`: after a forced `reclaim` at a quiescent point all three are exactly 0 (`reclaim` swaps `count` and `large` to 0 and no push follows), so `count` serves here as an exact witness although it is only a hint for scheduling. This is S4's wording and is adopted.
- (r3, Cf-1) Foreign children in checked walks: at the quiescent point every heap is on this thread, so a walk may read blocks on other heaps' registered pages through the foreign lend. Rule for every checked walk (`check_reach`, S3's `check_lin_parts`, `check_owned`'s recount, `freezable`): an edge to a word `w` is judged in this order: immediate → ok; page not in `Control.pages` → `UnknownPage`; own page → today's rule (`alive(c) || in_region(c)` and the rc/`lin` conditions); region page → ok; other registered page → read the child's prefix state and rc through `foreign_lend`: prefix state freed or token → `UseAfterFree`, otherwise the same rc/`lin` conditions as for an own child (`rc(b) == 0 ⇒ rc(c) == 0`; `rc(b) < 0 && rc(c) > 0 ⇒ lin(c)`). `child_ok`'s spec gains the disjunct `self.core.foreign(c) && foreign_alive(c)`. Walks enumerate only their own pages as roots and never recurse into foreign blocks except where the rule says to read one child; S3's `check_lin_parts` descends through foreign nodes (a `lin` part may continue onto another heap's pages after `transfer_back`), so its "pops > blocks.len()" bound is replaced by the `seen` set (a node reached twice → `SharedReachesLocal`, which also gives termination). Exact text for S3's pop step: "Pop a node `c`. If `c`'s page is not registered, return `UnknownPage`. Read its prefix state and rc (own page: own permission; region page: stop, ok; other registered page: through `foreign_lend`). If the state is freed or token, return `UseAfterFree`. If `c` was already in `seen` or rc ≠ 1, return `SharedReachesLocal`. Insert `c` into `seen` and push its pointer children with rc > 0." `leaks`, `live_objects` and `owned_entries` count own pages only; `check_owned` sums the recounts of all heaps, so a transferred object on heap k's pages counts for its prefix owner wherever it lives.

**Run-wide worker-ID tables (checked mode)**
- `Control.workers: WorkerIds` (opaque to Verus, safe Rust): `next: AtomicU32`, `free: Mutex<Vec<u32>>`, `chunks: Mutex<Vec<Arc<[AtomicU64; 1024]>>>`; each checked `Heap` keeps a snapshot `Vec<Arc<[AtomicU64; 1024]>>` refreshed under the mutex only when an ID beyond it appears; the hot path is `snapshot[id >> 10][id & 1023].fetch_add/sub(1, Relaxed)`.
- `Heap::fork_worker/retire_worker/set_worker/owned_by` keep signatures and delegate; `fork_worker` = pop `free` else `next.fetch_add(1)`; `too_many_workers`/`bad_retire` as today; `admit_worker` marks an ID used in the run.
- (r2, C-4) `retire_worker(id)` precondition: every thread that changed `count[id]` since the ID was issued happens-before this call. For `par` that edge is the child's Release publication of its outcome and the parent's Acquire read (S1), followed in program order by the parent's `transfer_back`; for cells (later stage) it is the registry lock. Under it the check is exact at retirement for any N. MC:278's run-end deferral is removed.
- Recount: `Heap::check_invariants` keeps `SharedReachesLocal`/`ImmortalReachesMortal`; `OwnedMiscount` moves to `Control::check_owned<M>(&self, heaps: &[&Heap<M>]) -> Result<(), HeapError>` (recount of rc>0 live blocks by prefix owner over all given heaps' pages; quiescent). N = 1 callers pass `&[&heap]`.
- `recover` resets the table (`WorkerIds::reset`) before copying and re-admits worker 0's ID. Fast mode never touches `WorkerIds`.
- (r3, Cf-7) Lifetime: `WorkerIds` and `PageMap` live in `Control`, i.e. for the `Machine` and across runs, not in S1/S4's per-run `Run`. Reason: in the REPL (N = 1) heap 0 and its objects persist across runs, so their IDs' counts and heap 0's page bits must persist too; `Control::begin_run`/`clear` do not touch either table. Per-run behaviour: a run that ends with `retire_worker` of every ID it issued leaves `next`/`free` reusable and all counts of retired IDs at 0; a run that reported `TransferLeak` leaves the leaked count (the diagnostic is already out). `recover` is the only reset. S1's C3 text "`Run` ... S2's ID table" is to be amended to "`Control.workers` (S2)".

**Recovery over N heaps (r2: all heaps on worker 0's thread, S1)**
- Survivors are worker 0's session roots only (OM:740; registry words are per run, MC:333-336) [V].
- Order (worker 0, after joining every worker thread, holding every `Ctx`):
  1. `reclaim` on every heap (`&mut`, any order).
  2. `Ctx::recover(&mut self)` on `Ctx` 0: source test by `page_sink_of(h)`: null → frozen word kept; any non-null sink (own or foreign) → copy. Foreign blocks are read through the T14 lend. rc<0 copied as local; `lin`-bit, `Foreign`, token, non-dummy immortal, cycle → `Unrecoverable` (unchanged). Heaps 1..N-1 must be alive and untouched until this returns. On `Ok`: table reset + re-admit, roots rewritten, old heap 0 dropped inside `recover`.
  3. Drop `Ctx`/`Heap` 1..N-1 in any order (they live one run, S1). (r2) No `Heap::reset` API: nothing persists on those heaps.
- (r2, B-4) Rule that makes the order safe: `Drop for Heap` = `reclaim` (own structures only) + `finalize_all` + page deallocation. `finalize_all` only calls T3 finalizers of `Foreign` blocks on its own pages and never decrefs [V: walk.rs:330-345, "破棄処理を1回ずつ呼ぶ"]; `Foreign` values hold no words and finalizers get no heap (MC:337). So dropping a heap never reads or writes another heap's pages or sink, and a remotely-transferred object on heap k's pages is finalized exactly once, by heap k's drop. Objects freed on other heaps whose children live on heap k were already decref'd by the freer (via T2 atomics); heap k's drop deallocates pages without reading rc.
- `Unrecoverable`: nothing replaced; the `Machine` is poisoned as today. Heaps 1..N-1 are still dropped by worker 0.

**Verification and trust**
- T0 stays and is restated: "A heap's local (rc>0) objects and its allocator state are touched by one thread. Shared objects (rc<0) are touched by several threads only through T2 atomics on `rc` and read-only otherwise; the proof is sequential and takes T2's postconditions as the sequential value; the RC protocol (OM 「共有の側」) and `share`'s publication order are what make this sound." Replacing T0 with concurrent proofs (MC:546) is not in this stage (RM item `rt-concurrent-proofs`).
- (r2, C-2) Ghost state of the owner while another heap frees its block: the block stays in the owner's `dom` with state Live and its edges until `remote_take` removes it; the owner's ghost model is stale for (i) that block's state and contents and (ii) the `rc` of shared blocks. The owner can observe (i) only by a page walk (forbidden by the quiescence precondition) and (ii) only by T2 reads on shared objects (T0). The owner holds no reference to the block (the freer had the last one), so no operation of the owner is applied to it. `remote_take(page, Tracked(perms): Tracked<&mut Map<usize, BlockPerm>>, Ghost(model)) -> (Vec<*mut Header>, Ghost<Set<usize>>)` is `external_body` with `ensures final(perms) == old(perms).remove_keys(S)`, `S ⊆ old(in_use)`, each `h ∈ S` a carved block of `page`; it returns no permissions, so no permission is duplicated. The owner's model transition `freed_remotely(S)`: remove the blocks, their out-edges and ext counts; children's memory `rc` were already decremented by the freer, so `consistent` holds after the transition (for a block reused by the receiver before being freed, the model's edges are the old contents' — those are exactly the edges the receiver's `release_reuse` decremented; the new contents' children are the receiver's business as an external holder). `reclaim` then runs the verified splice loop with the permissions popped from `perms`.
- Inside `verus!` and proven: `Pages` wf with the three page parts (own pages have `sink == self.sink`, region pages null); local free; `reclaim`'s splice loop; `try_alloc`/`alloc`; `freeze` writing null sinks; `recover` over foreign sources; everything existing.
- (r2, C-5) Foreign blocks are reached through a **lend**, not an owned permission: `foreign_lend(h) -> Tracked<ForeignLend>` (opaque tracked token; proof fns `borrow(&self) -> &BlockPerm` and `borrow_mut(&mut self) -> &mut BlockPerm`, the latter only when the lend says rc>0) and `foreign_return(Tracked<ForeignLend>)`; a free hands the lend to `remote_push(h, Tracked<ForeignLend>)` instead of returning it. Every operation on a foreign block lends at entry and returns at exit, so permissions neither accumulate nor duplicate. The promise is conditional and the row says so: it holds iff G-S2-5 holds (every rc>0 object reachable from one thread; rc<0 objects written only at `rc`). A read-only view is not enough because transferred `lin` objects are mutated in place by the receiver (MC 「`Lin` の物体の所有者の移し替え」, premise row 12); the only alternative, copying transferred objects at `transfer_back`, breaks that premise. **Send/Sync surface (compile-time asserts in lib.rs)**

## 2. Rationale

- The free path already reads the page head on every free (`block_header`, alloc.rs:2195) [V]; `dup`/`decref` non-free paths never do [V: mod.rs:2477-2590].
- Header split: whole-struct owner writes at alloc.rs:1618-1625 and :2395-2401 [V]; Verus `PointsTo<T>` writes are whole-struct.
- Sink pointer over owner id + table: no table lookup on the large-free path; `Frozen` needs no reserved id; `Box` gives a stable address while `Heap` moves (`unsafe impl Send`, mod.rs:1956 [V]).
- Per-page remote lists are premise row 7; the owner has no per-class page index [V: `Class` holds `free/page/cursor/end`, alloc.rs:152-158], so reclaim walks `list`; a dirty-page index needs a double-insertion protocol (a page pushed twice corrupts its link and can cycle) and is deferred with a measurement condition.
- `reclaim_if_due` before page acquisition and budget checks: `Control::charge` raises `MEMORY` at page acquisition and `over_budget` is consulted before big allocations [V: control.rs:244-258, 01a]; running the cheap trigger right there is the only place that can prevent a false limit.
- Verus: vstd atomics are SeqCst-only; the model is sequential (TS:118, OM T0/T2) [V]; a concurrent proof is a restructuring of the whole `Core` proof.
- External-holder modelling: `ext` already counts references held outside the heap (TS 「Verus」 item 3) [V]; `share` changes only sign and owner (OM:729) [V].
- Run-wide counts: counts move only at `share`/`transfer_back`/free (OM:703) [V: count_owned sites graph.rs:711-837, mod.rs:1161, :3145]; shared objects are uncounted, so only rc>0 objects count and they are single-thread; the happens-before edge is the caller's.
- Recovery scope: roots are in worker 0's `Ctx` (MC:70, OM:740) [V]; heaps 1..N-1 are per run (S1).
- `Foreign` is `Send + 'static` so any thread may finalize (OM:100) [V]; `finalize_all` never decrefs [V: walk.rs:330].
- Page map before dereference: pages are 64 KiB aligned, so a bitmap keyed by `addr >> 16` is exact; three atomic loads per checked operation is well below the prefix/owner checks already done.

## 3. Alternatives considered and rejected

- Owner `u32` + run table indexed by heap id (MC:324 literal): table lookup on the large-free path; reserved id for `Frozen`.
- Per-class remote lists on the sink: contradicts premise row 7.
- Dirty-page stack with an `in_dirty` flag: second protocol; deferred with a measurement condition.
- `(*sink).control == self.control` as the "registered" test (r1): dereferences before validating; replaced by the page map (C-3).
- `RwLock<HashSet<usize>>` page registry: a lock and a hash per checked operation; the radix bitmap is lock-free and two loads.
- Entering foreign rc>0 blocks into the receiver's `dom` at `transfer_back`: fast mode has no hook (`transfer_back` stops at rc>0, OM:270).
- Copying transferred `lin` objects at `transfer_back` so that no foreign block is ever written: breaks premise row 12 (in-place mutation after a move) and costs O(size) per `Lin` crossing.
- `Tracked` hand-over tokens through the VM: the VM is unverified; the token proves nothing.
- Deferring `TransferLeak` to run end for N ≥ 2 (MC:278): unnecessary with run-wide atomics and the stated precondition; loses join-time diagnosis.
- Remote free deallocating large pages from the foreign thread: needs the owner's `list`/`index` and accounting.
- `recover_all(&mut [Ctx])` and `Heap::reset`: with S1's per-run heaps all owned by worker 0 at the quiescent point, `recover` on `Ctx` 0 plus plain drops suffice.
- loom, Kani: rejected by TS:95 [V].

## 4. Assumptions made

- A1 (S1): the quiescent point is "every worker thread joined; every `Ctx` on worker 0's thread". Page walks, `check_owned`, recovery and drops run only there. If false: data races on block words during walks; checked mode detects only in-flight pushes (`NotQuiescent`).
- A2 (MC invariant 5, S1 G-S1-2): every heap of a run outlives every push into its sink. If false: a push dereferences a freed `RemoteSink`/page (UB).
- A3 (S1, r2): eml code runs on workers ≥ 1 (`par` right child). The consumers are: the child frees the shared closure (parent's pages) remotely; the parent's `transfer_back` at join flips rc −1 objects on the child's pages and then mutates/frees them (pushes into the child's sink, drained by worker 0 after join); run-end checks over N heaps.
- A4 (S3): the re-send rule keeps G-S2-5. If not, T14's promise is false in fast mode; S3 must then mark or copy the offending objects.
- A5: one `Control` per run; every heap and constant-builder heap of the run uses it. Checked mode reports `UnknownPage` for a word from another `Control`.
- A6: `WorkerIds` chunks of 1024 IDs suffice (IDs are reused, OM:705).
- A7: the TSan toolchain path verified in §7 keeps working on CI's runner (same `.#miri` shell as the ASan job).
