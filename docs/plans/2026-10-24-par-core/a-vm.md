## 1. Conclusion

### Q1 Representation
- `std/Par.em`: `pub extern par : (Unit -> <never e> a) -> (Unit -> <never e> b) -> <e> (a, b)` and `pub both` in eml. Table row `Extern::Par` = `Std.Par.par`, `params [TObj, TObj]`, `param_kinds [Unr, Unr]`, `ret Repr(Obj)`, `ret_kind Unr`, `purity Pure`, no borrow, no `with_arg`; translate never emits `Rhs::Extern` for it.
- Core IR and LIR **`Call::Par { left: Atom, right: Atom, pair: Ctor, at: Option<Loc> }`** (S3 implements). Result: one `obj`, the pair object of `pair` = `Ctor { layout: tuple_layout(2), tag: TUPLE }` (two `tobj` fields). translate binds the result **directly at the tuple type** (`obj` or `struct`); box insertion adds the `obj → struct` unbox when the site's tuple is a struct (S3 Q3; the VM pair has the layout of the struct's box, lir.md:167,176 [V]). The `$externN` wrapper has the same body. **The call carries the checker's mask** (`Rhs::Call { call: Call::Par, mask }`, F1); EP wraps a masked `par` in the ordinary `evv_mask` wrapper (core-ir.md 「`mask` の包み」 [V]), so the `evv` the VM sees at `Op::Par` is already masked and the wrapper's `evv_set(w0)` restores it after the join. `Call::Par` is never a tail call, is `Abort::Always` in `eml_lir::unwind`, and lowers to **`Op::Par { dst, at }`**, operands `[left slot, right slot, tag, scanned, raw]`.
- **`Prim::ChildAbort`**: `prim child_abort(ev, f, t)`, params `[Obj, TObj, TObj]`, borrowed `[true, false, false]`, ret `Unit`, marks `[Unr, Unr, Poly] -> Unr`, `Abort::Always`; lowers to **`Op::ChildAbort { ev, f, t }`**. The VM reads the effect (`meta(ev).tag() - 1`) and the depth (state field, an immediate) from the borrowed fork evidence `ev`.
- New builtin pc **`CHILD_DONE` = 2** (`Op::ChildDone`).
- **Child evidence (F2).** Two parts:
  - *Frozen per load* (`CodeBase`): for every never-only effect `E` (S3's `never_only`: `Prelude.Panic` included, `Prelude.IO` excluded) whose `fork$E.op_i` all resolve by name in `Index.functions`, a table `Data(tag 0, scanned = #ops)` of immediates `&fork$E.op_i` (`fork_tables: HashMap<u16 /* runtime effect */, Word>`), plus one frozen **tail**: the `Panic` fork evidence `[table_Panic, imm 0, ()]` (tag n_Panic + 1) in a frozen node `[ev, ()]` (`fork_tail: Word`). Rebuilt (new frozen chunk) at every `load` that grows the resolvable set. Effects without resolvable `fork$` names are skipped (a program containing `Call::Par` has them all, S3 Q5).
  - *Per fork* (`Op::Par`): the child `evv` **mirrors the masked parent `evv`**: walk `parent_evv` (`heap.scanned(node, 0/1)`, `heap.meta(ev).tag()`), and for every evidence of a never-only effect `E` other than `Panic`, in order, with `d` = its rank among `E`'s evidences so far (0-based), allocate a fork evidence `Data(tag n_E + 1, scanned 3) = [fork_tables[E], imm d, ()]` and a node `Data(tag n_E + 1, scanned 2) = [ev, next]`, ending in `fork_tail`. If the parent has no such evidence the child `evv` is `fork_tail` itself: no allocation. Then `heap.dup(head)`, `heap.share(head, child)` (one reference for each child), so both children may `dup` it under their IDs. A mask inside a child (`probe/deepmask.em`) now removes the mirrored copies exactly as it would remove the parent's, and `evv_mask`'s precondition (enough matching evidences, ctx.rs:2686 [V]) holds because the child's `E`-list has the parent's length. Shape: `node_ok`/`ev_ok`/`table_ok` are satisfied (tag ≠ 0, 2/3 fields, table tag 0 of `dupable` immediates, state `imm d` is `droppable`, outer `()` is `dupable` [V ctx.rs:284-333]); `owned` constrains rc > 0 only [V mod.rs:1725], so frozen parts pass and shared parts are not owner-checked. object-model.md:162 gets the exception: fork evidence is never the target of `ev_take_state`/`ev_set_state` (no `prompt$` wraps it).
- Constraint 4 ("逐次の版も1つの実装") is met by `--sched sequential` running `par` through the same fork/join path; `both` is independent eml.

### Q2 Task model
- `Task` gains `evv: Word` (saved while not running), `worker: u32`, `depth_offset: usize` (parent's `depth()` at fork; 0 for main), `boundaries: Vec<JoinId>` (open boundaries, innermost last), `state: TaskState { Running, Ready, Waiting(JoinId), Unstarted(Word) }`. `depth()` = `depth_offset + base + frame_size`; `stack_limit = stack_limit(max_depth - depth_offset)`. `scratch` is empty at every safepoint; `exit`/`keep_result` are main-task only (asserted when a boundary is open); `last_ret` untouched; `base`/`frame_size`/`pc` restored by the boundary frame header like a `Ret`. `Task: Send` stays.
- `crates/eml_vm/src/sched.rs`: `Scheduler<P: Policy> { tasks: Vec<Option<Task>>, current, ready: VecDeque<TaskId>, joins: Vec<Option<JoinNode>>, policy: P, switches: u64, peak_depth: u64, main_worker: u32 }`, created per run in `Machine::run_entry`, dropped when `vm::run<M, P>(code, ctx, sched, counts)` returns; dispatch on `RunConfig.sched`.
- `JoinNode { parent, right, right_worker: u32, parent_evv: Word, fork_evv: Word, left: Option<Outcome>, right_outcome: Option<Outcome>, ret: Pc, dst: Slot }`, `enum Outcome { Value(Word), Abort { effect: u16, depth: u32, reperform: Word, tuple: Word }, Error(RuntimeError) }`. Invariant: `Scheduler`, `Task`, `JoinNode` have no `Drop` touching the heap; every word is a counted reference moved in and out exactly once by VM code; on a `Failure` they are dropped untouched and the heap is dropped (`execute`) or replaced by `recover` (REPL) after `vm::run` returns (lib.rs:213-228, 272-284 [V]). No root registration in this stage.
- Child boundary frame: `push_frame(ret, dst, 2)`, slot 0 = child result, slot 1 = raw `join_id`; left children push it on the parent's stack (`ret` = pc after `Par`, `dst` = `Par`'s `dst`), right children have it as bottom frame (`ret = FINISH`, never returned to). The body is entered with `apply(code, ctx, task, closure, [()], Target::Frame { ret: CHILD_DONE, dst: 0 })`.
- Safepoints: every `ctx.poll(task.depth())?` becomes `safepoint(ctx, task, sched)?` = `poll`, then `if sched.policy.tick() && ctx.yielding() == 0 { switch }`. `Sequential::tick` is `false` (inlined away: the sequential loop keeps today's machine code); `Seeded::tick` decrements a budget, returns `true` at 0 and reloads only when a switch happens, so a 0 hit while yielding or aborting retries at the next safepoint. Other switch points: parent blocking at a join, right child finishing, right child error. None can be in a yield (`ChildDone` returns `Internal` if `yielding() != 0`).
- Switch to `next`: `prev.evv = ctx.evv_swap(next.evv)`, then `heap.set_worker(next.worker)`, then if `next.state == Unstarted(g)`: `apply(g, [()], Frame { ret: CHILD_DONE, dst: 0 })` (under the child's ID: `take_captures` may `free_block` the child-owned closure). `prev.state = Ready` (preempted) or `Waiting(j)`; `switches += 1`.
- Depth: `poll(task.depth())` is per Task today [V vm.rs:94-96]; with `depth_offset` a right child continues from its parent's depth, so recursion through `par` is bounded by `max_depth` as `(f (), g ())` is, and live Tasks are bounded. `peak_stack` := max over Tasks of `depth_offset + stack.len()` (today's value for programs without `par`; schedule independent).

### Q3 Logical IDs and the fork/join sequence
- `Op::Par` (parent context; `evv` already masked by EP's wrapper when the call had a mask): read `f`, `g`; `child = heap.fork_worker()`; for each session root `r` (`Ctx::roots()`): `heap.share(r, child)`; `heap.share(g, child)`; build `fork_evv` from the current `evv` (Q1), `dup`, `share(fork_evv, child)`; create the right Task (`worker = child`, `evv = fork_evv`, `depth_offset = task.depth()`, `state = Unstarted(g)`, `boundaries = [j]`); `j = joins.insert(JoinNode { parent, right, right_worker: child, parent_evv: ctx.evv_swap(fork_evv), fork_evv, ret: task.pc, dst, .. })`; `push_frame(task.pc, dst, 2)`, slot 1 = j, `boundaries.push(j)`; `apply(f, [()], Frame { ret: CHILD_DONE, dst: 0 })`; `ready.push_back(right)`; `safepoint`.
- `child_done(outcome)` at `Op::ChildDone` (frame = boundary, j = slot 1, `boundaries.pop()`): right child → record `right_outcome`; `heap.decref(ctx.evv_swap(UNIT))` (the child's leftover `evv`, under the child's ID); free the Task slot; if the parent is `Waiting(j)` make it `Ready` (sequential `push_front`, seeded `push_back`); switch. Left child → record `left`; pop the boundary frame (`pc := joins[j].ret`); `heap.decref(ctx.evv_swap(parent_evv))`; if `right_outcome` is `Some` → `complete_join(j)`, else `state = Waiting(j)` and switch.
- `complete_join(j)` (parent context and ID):
  1. `left` is `Error(e)` → `Err(e)`; else `right_outcome` is `Error(e)` → `Err(e)`.
  2. `heap.transfer_back(w, right_worker)` for every right-side word (`Value(w)`, or `reperform` and `tuple`); `heap.retire_worker(right_worker)` (`TransferLeak` → broken runtime error).
  3. Left `Abort` → `decref` the right words → re-raise left. Left `Value`, right `Abort` → `decref` the left value → re-raise right. Both `Value` → `alloc_data(tag, 2, 0, lin = false)` with the two words, `task.set(dst, pair)`, `safepoint`.
  4. Re-raise `Abort { effect, depth, reperform, tuple }`: if `depth > 0`: `masked = ctx.evv_mask(&[MaskItem { effect, keep: 0, skip: depth }], current evv)`; `heap.decref(ctx.evv_swap(masked))`. Then `apply(code, ctx, task, reperform, [tuple], Frame { ret: joins[j].ret, dst })`. `reperform$E.op`'s `ev_lookup[E]` now finds the parent's handler that the child saw at rank `depth`; its `never` clause entry's `yield_abort` unwinds through the `par` frame (row exists: `Abort::Always`) to that handler's `prompt$`, which resets `evv` and frees the masked list. For `Panic` (`depth` always 0) `reperform$Prelude.Panic.panicked` runs `extern Prelude.panic(t)`, delivered to the nearest `try_panic` or reported as `VmFault::Panicked`.
  5. Free the join slot.
- Before `vm::run` returns `Err`, it calls `heap.set_worker(sched.main_worker)` so `recover` (which copies the current ID) starts the next input on the session's ID. Roots copied by `recover` are local again and get re-shared at the next fork (idempotent: marked objects stop the walk).

### Q4 Child abort protocol
- S3 generates, when the program contains `Call::Par`, for every never-only effect `E` in the program (session included; `Prelude.Panic` included) and operation `E.op` with parameters `P_1..P_k` and marks `M_1..M_k`:
  - `fork$E.op`: mark `clause E.op`, params `(ev: obj unr, a_i: P_i M_i)`, ret `obj poly`, not `yields`, not `internal`, no `split`. Body: `t` = `()` (k = 0), `a_1` (k = 1), `con TUPLE(a_1..a_k)` with `tuple_layout(k)` (k ≥ 2; `tobj` fields, box insertion boxes raw `P_i`; var mark = join of `M_i`); `prim child_abort(ev, &reperform$E.op, t)`; `return prim dummy()`.
  - `reperform$E.op`: not `internal`, not `yields`, no `split`, param `t` (`unit` / uniform `P_1` / `obj`), ret `tobj poly`, all positions uniform (applicable with one argument). Body: `unpack` if k ≥ 2, then `perform E.op(..)` (EP → `ev_lookup`/`ev_clause`/`tail clause`); `Panic`: `extern Prelude.panic(t)` without position.
  - Names from the effect table (`fork$Fail.Fail.fail`, `reperform$Prelude.Panic.panicked`); the VM resolves them by name at `load` and skips effects whose names are missing.
- `Op::ChildAbort { ev, f, t }`: `Internal("a child abort outside a par child")` if `boundaries` is empty; read `effect = meta(ev).tag() - 1`, `depth = scanned(ev, 1)` (immediate); unwind with the immortal dummy as target (matches no landing, as `exit` does [V vm.rs:911-917]); new first arm in the unwind loop: `task.pc == CHILD_DONE` → stop and `child_done(Abort { effect, depth, reperform: f, tuple: t })`. `ev` is borrowed, so nothing is dropped for it. `FINISH` with `task.exit.is_some()` while `boundaries` is non-empty is `Internal`.
- extern `Panic` in a child: `failed`/`panic` call `abort_to(Panic)`, which returns `Ok(false)` only when no evidence exists [V vm.rs:861-886]; a child always finds its own `try_panic` (pushed in front) or the `Panic` fork evidence in `fork_tail`. No VM change in `failed`.
- Error text of a child Panic no handler catches: `panicked: <message> in `reperform$Prelude.Panic.panicked``; deterministic; S4 pins it.

### Q5 Runtime errors in children
Unchanged from r2: with `boundaries` non-empty, `Stopped(Interrupted | MemoryLimit)`, `Extern(Fault::Heap(_))`, `Internal(_)` end the run at once; `Stopped(DepthLimit)` and other `Extern` faults are child errors (`code.error(failure, task)`): right child → `right_outcome = Error(e)`, Task leaves the slab (stack not unwound), parent woken if waiting; left child → `Err(e)` immediately. Resolution at the join: left error first, then right error, never rescued by a left abort or value (user decision). `exit` is unreachable in children and never runs with open joins [I]. `Op::Finish` returns `Internal("a task is left at the end")` if any non-main Task or any join is live. Leak check and REPL recovery unchanged; `TransferLeak`/`WrongOwner` are broken errors.

## 2. Rationale (changed or challenged decisions)
- F1: the checker records a mask on `par` whenever the site's row has labels in front of `e` (types.md:166 [V]; `probe/mask.em`). Reusing EP's `evv_mask` wrapper means the VM needs no mask operand: the saved `parent_evv` is the row the children's `e` denotes, so a child's abort is re-performed exactly where `both` would perform it. `par` never yields, so the wrapper's slow path is dead code, as S3 notes.
- F2: a mask inside a child skips evidences by count (lir.md 「evidence を探す」 [V]), so one marker per effect cannot survive `mask (E, 0, 1)` (`probe/deepmask.em`). Mirroring the parent's never-only evidences gives the child a list of the same shape, so masks work unchanged and no "in child" logic enters `ev_lookup`/`evv_mask`. Depth in the state field lets the parent re-perform under the same mask (`evv_mask(parent_evv, [(E, 0, d)])`), which is the only way to reach the d-th handler without a new lookup primitive. Panic is never masked (types.md:174 [V]), so a single frozen `Panic` tail suffices and the common case allocates nothing. Rejected alternatives: a frozen pool per (E, d) (d is unbounded); a VM-side search for the handler at re-raise (would duplicate `ev_lookup`); keeping the child `evv` empty with a lookup fallback (r1).
- Depth offset for right children, roots shared at fork, policy as type parameter, `fork$Panic.panicked` via the evidence protocol: as in r2.
- Tuple packing (A-2): as in r2 (k = 0 → `()`, k = 1 → the argument, k ≥ 2 → generic tuple; marks joined).

## 3. Alternatives considered and rejected
As in r2, plus the F2 alternatives above, and: a mask operand on `Op::Par` (duplicates the EP wrapper; the wrapper already restores `evv` after the join); mirroring every parent evidence (effects with resumable operations cannot be reached from a child, E2020).

## 4. Assumptions
- A1 Frozen `Data` (tables, `fork_tail`) is readable by `ev_lookup`/`ev_clause`/`evv_mask`/`apply_clause` like heap objects (specs check meta and `owned`; rc 0 passes [V]; the region access path [I]). Fallback: allocate the tables and tail per fork too.
- A2 S2 delivers `share` (move form, `receiver == worker` allowed), `transfer_back(w, from)` (flip + checked owner rewrite of rc > 0 objects owned by `from`), `fork_worker`, `retire_worker`, `evv_swap`, `recover` copying rc < 0 as local. All in S2 r2.
- A3 S3 generates `fork$`/`reperform$` for every never-only effect whenever the program contains `Call::Par` (S3 Q5), so a child never performs an effect without a fork table.
- A4 No code outside a child runs while a join is open (from `par` blocking the parent and `<never e>` excluding `IO`).
- A5 The VM may read `evv` nodes directly with `heap.scanned`/`meta` between `Ctx` operations (it already reads closures that way, apply.rs:138-150 [V]); the walk reads only, so `heap_mut`'s rule is kept.
