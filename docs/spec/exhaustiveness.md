# 網羅性

位置づけ: 規範。

パターンの網羅性と到達可能性の検査を定める。

## 検査パス

- 型推論の後に、型付き HIR の上で別のパスとして行う。アルゴリズムは Maranget の行列アルゴリズムを使う。
- 網羅されていない `match` はエラー、到達しない枝は Warning にする。
- Int と String のリテラルは無限に値があるものとして扱う。ワイルドカードか変数の枝がない限り、網羅されていないとみなす。
- `let` の左辺とラムダの引数のパターンも、反駁可能 (網羅されていない) ならエラーにする。
- 変数、`_`、`()` はどれもワイルドカードとして扱う。`Unit` の値は1つしかないためである。型を明示したパターンは、中のパターンとして扱う。
- 型が `Error` を含むパターンと scrutinee は検査しない。診断を連鎖させないためである ([診断](diagnostics.md) の「連鎖する診断の抑止」)。
- トップレベルの関数の等式は、HIR で「引数のタプルに対する `match`」1つに脱糖する。網羅性はその `match` に対して検査する ([宣言](declarations.md))。等式が1つだけの場合も同じで、反駁可能な引数のパターンは「網羅されていない等式」として報告する。

```haskell
is_error : Level -> Bool
is_error Error = True
is_error _ = False
```

この定義は、引数のタプルに対する2つの枝の `match` として検査される。

## 診断

各誤りの重大度と、診断が指す場所は [診断](diagnostics.md) の「網羅性の診断」で定める。番号の範囲は E4xxx である。

## 範囲外

or パターン、ガード、as パターンはマイルストーン1 の範囲外である ([実装の現在地](../implementation/status.md))。
