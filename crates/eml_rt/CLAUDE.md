# eml_rt

The runtime core under the VM, verified with Verus. Its specification is docs/spec/object-model.md; how it is checked is docs/implementation/testing.md の「`eml_rt` の検証」.

- A change to `eml_rt` must pass `cargo verus verify -p eml_rt` and `verusfmt --verus-only --check $(git ls-files 'crates/eml_rt/src/*.rs')` besides the tests (`cargo nextest run` or `cargo test`), `cargo clippy --all-targets -- -D warnings` and `cargo fmt`, and the bench gate `bench/rt-gate.sh <the commit before the change>` on a clean tree (macOS; docs/implementation/benchmarks.md の「命令の数の測り方」). `verusfmt` formats inside `verus!`, `cargo fmt` the rest.
- All code is inside `verus!` except the safe glue that docs/spec/object-model.md の「`unsafe` の核」 lists. What Verus does not check is the named trust list T0-T18 in the same section, pinned by `src/trust.rs`: a new FFI boundary adds a row there and a Miri test in `src/heap/tests/trusted.rs`.
- The fields native code reads are `Native` at the head of the `#[repr(C)]` `Ctx`, read only at the offsets of the `CTX_*` consts next to `Ctx`; `eml_rt` holds no `extern "C"`, asm or `catch_unwind`, and `trust.rs` checks that (docs/spec/object-model.md の「欄」).
- Object positions (header offsets, the `Data` count word and first scanned word) are written only in `src/layout.rs` and used through it (docs/spec/object-model.md の「語の位置」).
- Unit tests take the mode as a type parameter and `both_modes!` runs them in fast and checked mode; internal functions get `Tracked::assume_new()` for their permissions. Miri runs only the `trusted` module, which holds only tests that allocate on a `Heap` or `Ctx`, start threads, or cross the `Foreign`, Host or `Drop` boundary; a test that only compares the values of pure functions goes in the ordinary unit tests (`src/heap/tests/externs.rs`). Tests do not shrink under `cfg!(miri)`; large bodies use `LARGE_BODY` or `LARGE_BODY` plus a small unaligned remainder (e.g. `LARGE_BODY + 3`). Each Miri command must stay within its CPU budget, the `user` time of `/usr/bin/time -p` on an already-built tree: `trusted::` 280 s under Stacked Borrows and 365 s under Tree Borrows, about 3x the time measured on a 4-CPU Linux container, and each `trusted` test (both modes) may add 5 s under Tree Borrows to the command's `user` time (docs/implementation/testing.md の「Miri」).
- `src/heap/tests/expected.txt` pins the externs' results; an `#[ignore]` test rewrites it from `eml_rt`'s own results (docs/implementation/testing.md の「期待値の表」).
- `eml_rt` installs no signal handler; `eml_cli` owns the signal handlers (SIGINT and SIGTERM on unix, the console handler on Windows) (docs/spec/object-model.md の「実行の制御」).
